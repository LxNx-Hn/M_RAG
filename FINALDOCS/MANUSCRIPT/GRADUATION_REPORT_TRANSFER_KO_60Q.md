## 1.1 연구배경 및 목적 [스타일=절(1.1)]

검색 증강 생성(Retrieval-Augmented Generation, RAG)은 질문과 관련된 문서 구간을 외부 자료에서 검색하고, 검색한 텍스트를 생성 모델의 입력에 넣어 답변을 만드는 방법이다[1]. 모델의 학습 시점 이후에 나온 논문이나 기술 문서에 대해서도 원문을 근거로 답할 수 있어 학술 문서 질의응답에 널리 쓰인다.

RAG의 성능은 검색 단계와 생성 단계 모두에서 개선할 수 있다. 가상 문서 임베딩(Hypothetical Document Embeddings, HyDE)은 질문으로 답변 형태의 가상 문서를 먼저 생성하고, 이 문서의 임베딩으로 실제 문서를 검색한다[2]. 문맥 인식 디코딩(Context-Aware Decoding, CAD)은 검색 결과를 입력했을 때와 입력하지 않았을 때의 다음 토큰 점수를 비교하여, 검색 결과가 뒷받침하는 토큰을 더 강하게 선택하게 한다[3]. 소프트 제약 디코딩(Soft Constrained Decoding, SCD)은 목표 언어 토큰의 점수를 높이고 다른 언어 토큰의 점수를 낮추어 출력 언어를 제어한다[4].

한국어 사용자가 영어 논문을 검색할 때에는 두 가지 문제가 함께 나타난다. 첫째, 한국어 질문과 영어 원문은 같은 개념을 다른 어휘로 표현하므로, 검색기는 어휘 차이를 넘어 질문에 맞는 근거를 찾아야 한다. 둘째, 생성 모델이 영어 근거를 그대로 따라 영어로 답하는 언어 이탈(language drift)이 발생한다. HyDE는 첫째 문제와, SCD는 둘째 문제와 관련되며, CAD는 검색한 근거를 답변에 반영하는 정도와 관련된다. 세 기법은 서로 다른 모델과 과제에서 각각 제안되고 평가되었으므로, 한국어 질문과 영어 문서를 사용하는 하나의 RAG 파이프라인에서 세 기법의 효과를 함께 비교할 필요가 있다.

본 연구는 영어 학술·기술 문서를 검색하여 한국어로 답하는 고정 파이프라인 Paper-RAG를 구성하고, HyDE·CAD·SCD의 적용 여부를 조합한 8개 조건(RAG-Cube)을 같은 한국어 질의 60개에 적용하였다(그림 1-1). 각 기법을 단독으로 켰을 때의 변화와 세 기법을 조합했을 때의 효과를 답변 품질, 출력 언어, 실행 시간으로 측정하고 통계적으로 검정하였다. 이 비교는 한국어 질의로 영어 문서를 검색하는 RAG에서 어떤 기법이 어떤 지표를 얼마나 바꾸고 그 대가로 실행 시간이 얼마나 늘어나는지를 같은 조건에서 보여 주므로, 실제 시스템에 적용할 기법 조합을 정하는 근거가 된다.

## 1.2 연구범위 [스타일=절(1.1)]

검색 대상은 RAG Survey[D1], CAD[D2], RAPTOR[D3], Mi:dm K 2.5 Pro Technical Report[D4]의 영어 문서 4종이다. 문서마다 한국어 질의 15개를 작성하여 총 60개를 구성하였고, 각 질의는 지정한 문서 안에서만 검색하였다. 질의마다 8개 조건을 적용하여 생성 답변 480개를 얻었다.

RQ1. CAD와 SCD를 모두 끈 기본 조건에서, 번역과 가상 문서 생성을 포함한 HyDE 검색은 답변 관련성을 높이는가?

RQ1~RQ3은 대응 t-검정으로, RQ4는 반복측정 분산분석(ANOVA)으로 분석하였다. 나머지 품질 지표는 보조 결과로 함께 보고한다. 2장에서는 세 기법과 관련 연구를, 3장과 4장에서는 실험 설계와 구현을, 5장에서는 평가 방법과 결과를, 6장에서는 결론을 제시한다.

## 2.1 Retrieval-Augmented Generation [스타일=절(1.1)]

Lewis 외[1]의 RAG는 검색기(retriever)가 외부 문서 인덱스에서 관련 문서를 찾고, 생성기(generator)가 질의와 검색 문서를 함께 입력받아 답변을 생성하는 구조다(그림 2-1).

[그림삽입: FINALDOCS/FIGURES/LITERATURE/fig2_1_rag_independent.png | 권장폭=본문폭 100% | 정렬=가운데]

[그림 2-1] RAG의 검색기–생성기 구조 [스타일=그림제목]

본 연구에서 작성한 도식이며, Lewis 외[1]의 RAG 구조를 참고하였다.

질의를 q, 문서 집합을 D라 하면 검색기는 D에서 질의와 관련된 문서 구간을 골라 검색 결과 C_q를 만들고, 생성 모델은 q와 C_q를 입력받아 답변 y를 생성한다. 본 논문에서 검색 결과는 생성 모델에 실제로 입력한 문서 구간의 텍스트를 뜻한다.

[한글 수식 입력기 복붙용 — 최종 HWP에는 렌더링된 수식만 남김]

```text
C_q = Retrieve(q,D)
```

```text
y = LM(q,C_q)
```

## 2.2 하이브리드 검색과 재정렬 [스타일=절(1.1)]

밀집 검색은 질의와 문서 구간을 임베딩한 벡터의 유사도로, BM25 희소 검색은 두 텍스트의 어휘 일치로 관련 구간을 찾는다[5][6]. 한국어 질문과 영어 원문은 어휘가 거의 겹치지 않지만, 논문명·모델명·데이터셋명·수치처럼 두 언어에 같은 형태로 쓰이는 표기는 BM25의 검색 단서가 된다.

두 검색 결과는 가중 역순위 융합(weighted Reciprocal Rank Fusion, RRF)으로 결합한다[7]. 문서 d의 밀집 검색 순위와 BM25 순위를 각각 rank_dense(d), rank_BM25(d)라 할 때, 가중치 0.6과 0.4, 상수 k=60을 적용한 결합 점수는 다음과 같다.

[한글 수식 입력기 복붙용 — 최종 HWP에는 렌더링된 수식만 남김]

```text
RRF(d) = {0.6} over {k + rank_dense(d)} + {0.4} over {k + rank_BM25(d)}
```

결합한 후보는 재정렬 모델로 다시 정렬한다. 재정렬 모델은 질의와 후보 구간을 한 쌍으로 입력받아 관련성 점수를 계산하며, CEDR[8]처럼 문맥화된 언어 모델 표현을 순위 계산에 활용하는 방식이 대표적이다. 생성 모델은 입력 내 위치에 따라 근거를 다르게 활용할 수 있으므로[9], 재정렬 순서는 생성 모델에 입력하는 검색 결과의 배치에도 영향을 준다.

## 2.3 가상 문서 임베딩과 검색 [스타일=절(1.1)]

HyDE는 입력 질의를 바탕으로 가상 문서를 생성한 뒤, 이를 임베딩 벡터로 변환한다. 생성된 벡터로 실제 문서 집합에서 유사한 문서를 검색한다[2]. 가상 문서의 내용이 틀릴 수 있어도 답변과 비슷한 어휘와 문장 구조를 갖기 때문에, 짧은 질문을 그대로 임베딩할 때보다 관련 문서에 가까운 검색 입력을 얻을 수 있다. 가상 문서는 검색 입력으로만 쓰이고, 최종 답변의 근거는 검색한 실제 문서 구간이다(그림 2-2).

[그림삽입: FINALDOCS/FIGURES/LITERATURE/fig2_2_hyde_independent.png | 권장폭=본문폭 100% | 정렬=가운데]

[그림 2-2] HyDE의 가상 문서 기반 검색 구조 [스타일=그림제목]

본 연구에서 작성한 도식이며, Gao 외[2]의 HyDE 구조를 참고하였다.

Gao 외[2]는 관련성 레이블 없이 수행하는 검색에서 HyDE가 Contriever보다 높은 성능을 보이며, 한국어를 포함한 비영어 검색에서도 효과가 있음을 보고하였다. 본 연구에서는 한국어 질의를 영어로 번역한 뒤 영어 가상 문서를 생성하였으므로, HyDE 조건의 변화에는 번역과 가상 문서 생성의 효과가 함께 포함된다.

## 2.4 Context-Aware Decoding [스타일=절(1.1)]

CAD는 검색 결과를 포함한 입력과 제외한 입력에서 계산한 다음 토큰의 점수를 비교하는 디코딩 방법이다[3]. 두 점수의 차이가 큰 토큰은 검색 결과 때문에 선택되는 토큰이므로, 이 차이를 키우면 모델의 사전 지식보다 검색 결과의 내용을 따르는 답변이 생성된다(그림 2-3).

[그림삽입: FINALDOCS/FIGURES/LITERATURE/fig2_3_cad_independent.png | 권장폭=본문폭 100% | 정렬=가운데]

[그림 2-3] CAD의 문맥 포함·제외 로짓 결합 [스타일=그림제목]

본 연구에서 작성한 도식이며, Shi 외[3]의 CAD 로짓 결합을 참고하였다.

같은 생성 접두 시퀀스에서 검색 결과를 포함한 입력의 로짓을 z_ctx, 제외한 입력의 로짓을 z_noctx라 하면 CAD의 로짓은 다음과 같다. α는 검색 결과의 영향을 키우는 정도이며 α=0이면 일반 디코딩과 같다.

[한글 수식 입력기 복붙용 — 최종 HWP에는 렌더링된 수식만 남김]

```text
z_CAD = (1 + alpha) z_ctx - alpha z_noctx
```

Shi 외[3]는 요약 과제와, 모델의 사전 지식이 입력 문서의 내용과 충돌하는 지식 충돌 과제에서 CAD가 입력 문서를 더 충실히 반영한다고 보고하였다. CAD는 토큰마다 검색 결과를 제외한 입력을 한 번 더 계산하므로 생성 시간이 늘어난다.

## 2.5 Soft Constrained Decoding과 언어 이탈 [스타일=절(1.1)]

다국어 RAG에서는 질문과 다른 언어의 문서를 검색하면 답변이 검색 문서의 언어로 바뀌는 언어 이탈이 발생할 수 있다. Li 외[4]는 이 현상을 분석하고, 디코딩 단계에서 목표 언어 토큰의 점수를 조정하는 SCD를 제안하였다. SCD는 어휘 집합을 목표 언어 토큰, 비목표 언어 토큰과 숫자·기호 같은 중립 토큰으로 나누어 로짓을 조정한다(그림 2-4).

[그림삽입: FINALDOCS/FIGURES/LITERATURE/fig2_4_scd_independent.png | 권장폭=본문폭 100% | 정렬=가운데]

[그림 2-4] SCD의 토큰 그룹별 로짓 조정 [스타일=그림제목]

본 연구에서 작성한 도식이며, Li 외[4]의 SCD 토큰별 점수 조정을 참고하였다.

생성한 토큰 수가 Tstart 이상이 되면 목표 언어 토큰의 로짓 z_i에는 α를, 비목표 언어 토큰의 로짓에는 β를 곱하고, 중립 토큰은 그대로 둔다. 본 연구는 한국어를 목표 언어로 하여 원 논문의 곱셈식을 그대로 적용하였다.

[한글 수식 입력기 복붙용 — 한국어 목표 토큰]

```text
tilde z_i = alpha z_i
```

[한글 수식 입력기 복붙용 — 비목표 언어 토큰]

```text
tilde z_i = beta z_i
```

[한글 수식 입력기 복붙용 — 중립 토큰]

```text
tilde z_i = z_i
```

## 2.6 RAG 평가 [스타일=절(1.1)]

RAGAS(Retrieval Augmented Generation Assessment)는 RAG의 검색과 생성을 나누어 자동으로 평가하는 프레임워크다[10]. 평가 모델(LLM)이 답변을 주장 단위로 나누고 각 주장이 검색 결과에 근거하는지 판정하는 방식으로 근거 충실도(faithfulness)를 계산하며, 답변 관련성(answer relevancy), 문맥 정밀도(context precision), 문맥 재현율(context recall)도 함께 제공한다. 근거 충실도와 답변 관련성은 생성 답변을, 문맥 정밀도와 문맥 재현율은 검색 결과를 평가한다. 본 연구에서 사용한 지표별 계산 방식은 5.2절에 정리하였다.

## 2.7 관련 연구와 본 연구의 위치 [스타일=절(1.1)]

RAG의 검색 구조는 질의와 문서를 각각 임베딩하는 Dense Passage Retrieval[11]과 여러 검색 구간을 디코더에서 함께 활용하는 Fusion-in-Decoder[12]를 거쳐 발전하였다. 생성 단계에서는 출력 분포를 직접 조정하는 디코딩 기법이 연구되었다. Contrastive Decoding[13]은 큰 모델과 작은 모델의 로그확률 차이로 토큰을 선택하며, CAD는 같은 모델에서 검색 결과를 포함한 입력과 제외한 입력을 대조한다는 점에서 다르다.

검색 단위와 검색 시점을 조정하는 연구도 이어졌다. RAPTOR[14]는 문서 청크를 반복적으로 군집화하고 요약하여 계층적 검색 구조를 만들며, 본 실험의 검색 대상 문서[D3]이기도 하다. Self-RAG[15]는 검색 필요성과 생성 결과를 스스로 평가하고, Adaptive-RAG[16]는 질문의 복잡도에 따라 검색 전략을 선택한다. 검색과 생성의 구성 요소별 기법은 Zhao 외[17]와 Fan 외[18]의 조사 연구에 정리되어 있으며, 검색 모델의 성능 비교에는 BEIR[19]와 MTEB[20] 같은 공개 벤치마크가 쓰인다.

이들 연구는 검색 전략이나 디코딩 기법을 각각 개선하는 데 초점을 둔다. 본 연구는 검색·생성 백본을 고정한 채 검색 입력(HyDE)과 디코딩 제어(CAD, SCD)를 함께 바꾸어, 한국어 질의–영어 문서 환경에서 각 기법의 단독 효과와 조합 효과를 비교한다. 표 2-1에 주요 선행연구와 본 연구의 비교 질문을 정리하였다.

# 3. 시스템 설계 [스타일=장(1.)]

## 3.1 연구 및 실험 요구사항 [스타일=절(1.1)]

세 기법의 효과를 비교하려면 기법 이외의 조건이 모든 실험 조건에서 같아야 한다. 따라서 검색·재정렬·생성 모델과 공통 파라미터를 고정하고, 질의마다 검색 결과, 생성 답변, 실행 시간과 적용 파라미터를 저장하여 질의 ID로 조건 간 결과를 연결하였다.

## 3.2 아키텍처 설계 [스타일=절(1.1)]

Paper-RAG는 한국어 질의와 대상 문서를 입력받아 검색 후보를 구성하고, 선택한 문서 구간을 답변 생성 모듈에 전달한다. HyDE를 적용하면 밀집 검색의 입력이 원질의에서 가상 문서로 바뀌며, BM25 검색과 재정렬에는 항상 한국어 원질의를 사용한다. 두 검색 결과는 가중 RRF로 결합한 뒤 CrossEncoder로 재정렬하고, 상위 5개 구간을 생성 모델에 입력한다. CAD와 SCD는 생성 단계의 로짓에 적용하며, 함께 적용할 때에는 CAD로 로짓을 결합한 다음 SCD의 언어별 계수를 곱한다.

## 3.3 완전요인 실험 및 대응 비교 설계 [스타일=절(1.1)]

HyDE, CAD, SCD를 각각 미적용(0)과 적용(1)의 두 수준으로 둔 2³ 완전요인설계를 사용하였다(표 3-1). 조건명의 H, C, S는 각각 HyDE, CAD, SCD를 뜻한다. 같은 질의 60개를 8개 조건에 모두 적용하였으므로, 질의가 반복측정의 단위가 된다. 각 질의·조건의 답변은 한 번씩 생성하였다.

## 5.4 통계 분석 방법 [스타일=절(1.1)]

통계 분석에는 대응 t-검정과 반복측정 ANOVA를 사용하였다. 같은 질의 60개를 모든 조건에서 측정하였으므로, 두 조건의 비교에는 질의별 점수 차이를 검정하는 대응 t-검정을, 세 기법의 주효과와 상호작용에는 질의를 반복측정 단위로 한 반복측정 ANOVA를 적용하였다. 유의수준은 양측 0.05로 정하였다.

대응 t-검정의 귀무가설은 질의별 ON−OFF 차이의 평균이 0이라는 것이다. 질의 i의 적용 조건 점수를 s_i^ON, 미적용 조건 점수를 s_i^OFF라 하면 차이, 평균 차이와 t 통계량은 다음과 같다. s_Δ는 질의별 차이의 표본표준편차이며 자유도는 n−1이다.

```text
Delta_i = s_i^{ON} - s_i^{OFF}
```

```text
bar Delta = {1} over {n} sum_{i=1}^{n} Delta_i
```

```text
t = {bar Delta} over {s_Delta / sqrt n}
```

효과크기는 평균 차이를 차이의 표준편차로 나눈 Cohen dz로 나타내었다. RQ3에서는 한 질의에 SCD 대응쌍이 둘(CAD OFF·ON) 있으므로, 질의별로 두 차이를 먼저 평균하여 질의 하나가 표본 하나가 되도록 하였다(n=60).

반복측정 ANOVA의 각 효과는 두 수준을 가지므로 자유도는 (1, n−1)이고, 효과크기는 부분 η²=F/(F+오차 자유도)로 계산하였다. 한국어 문자 비율과 실행 시간은 8개 조건 전체로 H×C×S 3요인 ANOVA를 수행하였다. 품질 지표는 5.3절의 이유로 SCD OFF와 ON 안에서 각각 H×C 2요인 ANOVA를 수행하였다. 유의한 상호작용은 해당 조건별 단순 효과를 대응 t-검정으로 확인하였다.

RAGAS 평가값 1,920개 중 1,915개가 유효했고, 결측 5개는 모두 근거 충실도에서 발생하였다(ext_rag_003·006의 H0C1S0, ext_rag_003·005·006의 H0C0S1). 각 검정은 필요한 조건의 값이 모두 있는 질의만 사용하였으며, 이에 따라 RQ2의 표본은 58개다.

이 분석은 실험을 마친 뒤 연구 질문에 맞추어 핵심 지표를 정한 탐색적 분석이다. 여러 검정을 수행하였으므로 개별 p값은 제1종 오류가 누적될 수 있다는 점을 고려하여 해석하였다.

## 5.8 종합 논의 [스타일=절(1.1)]

세 기법 중 목표 지표에서 가장 뚜렷한 효과를 보인 것은 SCD다. SCD는 영어 근거를 입력받은 답변의 한국어 비율을 약 22%p 높였고, HyDE·CAD의 네 조합 모두에서 같은 방향의 증가가 관측되었다. CAD 미적용 조건에서 늘어난 실행 시간도 중앙값 기준 1.5~2.5초였다. 한국어 질의–영어 문서 RAG에서 한국어 답변이 필요하다면 SCD는 비용이 작은 선택지다.

HyDE는 CAD와 SCD를 모두 끈 기본 조건에서 답변 관련성을 높였다. 번역과 가상 문서로 검색 입력이 바뀌면서 질문에 더 맞는 근거가 검색되고, 답변이 질문에 더 직접 답하게 된 것으로 해석할 수 있다. 다만 CAD를 함께 적용하면 이 차이가 0.029점으로 작아졌고, 문맥 정밀도와 재현율의 차이는 각각 −0.034점과 0.000점이었다. HyDE의 효과에는 번역과 가상 문서 생성이 함께 포함되어 있으며, 실행 시간은 다른 기법 수준을 평균하여 약 7초 늘었다.

같은 검색 결과에서 CAD에 따른 근거 충실도 증가는 평균 0.029점으로 작았다. 저장 자료에서 확인되는 이유는 세 가지다. 첫째, CAD 미적용 답변 58개 중 25개가 이미 충실도 1.0이어서 개선될 여지가 작았다. 둘째, CAD는 답변 전체를 새로 생성하였고(60쌍 모두 답변이 달랐다), 그 결과 질의별 차이의 표준편차가 평균 차이보다 훨씬 컸다. 이 효과크기(dz=0.11)에서 58쌍의 검정력은 약 14%이며, 80% 확률로 검출하려면 약 616개의 질의가 필요하다(대응 t-검정 기준). 셋째, 같은 입력에서도 평가 모델의 채점이 달라지는 경우가 있어 작은 차이는 평가 변동에 묻힐 수 있다. 또한 CAD는 모델의 사전 지식과 입력 문서가 충돌할 때 효과가 크도록 설계되었으나[3], 본 실험의 질의는 특정 문서의 세부 내용을 묻는 것이어서 첫째 이유에서 보듯 기본 RAG도 이미 검색 결과를 충실히 따르는 경우가 많았다. 반면 실행 시간은 약 2.9배로 늘었으므로, 본 실험 조건에서 CAD는 품질 이득보다 시간 비용이 분명한 기법이었다.

조합 측면에서 SCD는 HyDE·CAD의 네 조합 모두에서 한국어 비율을 높였으므로, 다른 기법과 함께 적용해도 언어 제어 효과가 유지되었다. HyDE의 한국어 비율 증가는 CAD 미적용 조건에서 8.5%p, CAD 적용 조건에서 1.4%p였고, CAD와 SCD를 함께 쓰면 CAD의 추가 시간이 약 9초 줄었다. 평균값 기준으로는 H1C0S1이 한국어 비율이 가장 높고(0.807), CAD 미적용 조건이어서 실행 시간도 24.9초로 짧았다.

## 5.9 평가 범위와 후속 검증 [스타일=절(1.1)]

분석 대상은 문서 4종에서 구성한 질의 60개이며 각 질의·조건의 답변은 한 번씩 생성하고 평가하였다. 따라서 결과는 이 질의 집합에서 관찰된 조건 간 차이이며, 다른 분야의 문서와 생성 시드에 따른 변동은 반복 실험으로 측정할 대상이다. HyDE 조건은 가상 문서를 샘플링하므로 같은 질의라도 실행마다 검색 결과가 달라질 수 있다. RAGAS 품질은 SCD 상태에 따라 평가에 사용한 검색 결과의 언어가 달라 SCD 상태별로 나누어 해석하였다. 한국어 문자 비율은 답변의 언어 구성을 측정하는 지표이므로, 번역의 정확성과 문장의 자연스러움은 사람 평가로 확인할 항목이다.

# 6. 결론 [스타일=장(1.)]

본 연구는 한국어 질의로 영어 학술·기술 문서를 검색하는 Paper-RAG에서 HyDE·CAD·SCD의 8개 조합을 같은 질의 60개에 적용하고, 대응 t-검정과 반복측정 ANOVA로 각 기법의 단독 효과와 조합 효과를 분석하였다.

## 6.1 연구 질문별 결과 [스타일=절(1.1)]

RQ1: CAD와 SCD를 모두 끈 기본 조건에서 HyDE는 답변 관련성을 평균 0.080점 높였다(t(59)=2.236, p=0.029). CAD 수준을 평균한 주효과는 p=0.097이었다.

RQ2: 같은 검색 결과에서 CAD는 근거 충실도를 평균 0.029점 높였고, p값은 유의수준 0.05보다 컸다(t(57)=0.862, p=0.393).

RQ3: SCD는 한국어 문자 비율을 평균 21.8%p 높였다(t(59)=13.951, p<0.001).

RQ4: 한국어 문자 비율에서는 SCD 주효과(p<0.001)가 뚜렷했고 H×C 상호작용(p=0.040)은 탐색적 수준으로 유의하였다. 실행 시간에서는 HyDE·CAD 주효과와 C×S 상호작용(p<0.001)이 유의하였고, SCD 주효과(p=0.016)는 CAD 적용 조건의 시간 감소에서 비롯되었다. CAD는 실행 시간을 약 2.9배로 늘렸고, SCD와 함께 적용하면 그 증가폭이 약 9초 줄었다.

## 6.2 연구의 의의 [스타일=절(1.1)]

본 연구는 서로 다른 환경에서 제안된 HyDE·CAD·SCD를 한국어 질의–영어 문서라는 하나의 RAG 환경에서 같은 백본과 질의로 비교하였다. 그 결과 출력 언어 제어(SCD)는 다른 기법의 모든 조합에서 큰 효과를 보였고, 검색 입력 변경(HyDE)은 기본 조건에서 답변 관련성을 높였으며, 근거 반영 디코딩(CAD)은 이 환경에서 품질 이득보다 시간 비용이 컸다는 점을 정량적으로 보였다. 또한 단순 비교와 요인 분석을 함께 사용하여, 특정 조건에서의 효과와 다른 기법 수준을 평균한 효과가 다를 수 있음을 확인하였다.

## 6.3 적용 조건과 후속 연구 [스타일=절(1.1)]

한국어 답변이 필요한 영어 문서 RAG에는 SCD를 기본으로 적용하고, 답변 관련성이 중요하면 HyDE를 함께 적용하는 구성을 우선 고려할 수 있다. CAD는 실행 시간이 크게 늘어나므로 모델의 사전 지식과 문서 내용이 충돌하는 질의처럼 효과가 기대되는 경우에 선택적으로 적용하는 것이 적절하다.

후속 연구로는 다음을 제안한다. 첫째, 번역만 적용한 조건을 추가하여 HyDE의 효과를 번역과 가상 문서 생성으로 분리한다. 둘째, CAD의 α를 바꾸고 지식 충돌형 질의를 포함하여 CAD가 효과를 보이는 조건을 확인한다. 셋째, 질의 수와 문서 분야를 늘리고 생성과 평가를 반복하여 결과의 변동을 측정하며, 모든 조건의 평가 언어를 통일한다. 넷째, 사람 평가로 한국어 답변의 정확성과 자연스러움을 확인한다.
