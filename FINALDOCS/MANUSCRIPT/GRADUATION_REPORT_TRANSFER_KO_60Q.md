# 1. 서론 [스타일=장(1.)]

## 1.1 연구배경 및 목적 [스타일=절(1.1)]

검색 증강 생성(Retrieval-Augmented Generation, RAG)은 질문과 관련된 문서 구간을 외부 자료에서 검색하고, 검색한 구간을 생성 모델의 입력에 넣어 답변을 만드는 방법이다[1]. RAG는 모델의 학습 시점 이후에 나온 논문과 기술 문서도 원문을 근거로 답할 수 있어 학술 문서 질의응답에 널리 쓰인다.

RAG의 성능을 높이는 기법은 검색 단계와 생성 단계에 모두 있다. 검색 단계의 가상 문서 임베딩(Hypothetical Document Embeddings, HyDE)은 질문에 대한 답변 형태의 가상 문서를 먼저 생성하고, 이 문서의 임베딩으로 실제 문서를 검색한다[2]. 생성 단계의 문맥 인식 디코딩(Context-Aware Decoding, CAD)은 검색 결과를 입력에 포함했을 때와 제외했을 때의 다음 토큰 점수를 비교하여, 검색 결과가 뒷받침하는 토큰이 선택될 가능성을 높인다[3]. 소프트 제약 디코딩(Soft Constrained Decoding, SCD)도 생성 단계에서 목표 언어 토큰과 다른 언어 토큰의 로짓에 서로 다른 계수를 곱해 출력 언어를 제어한다[4].

한국어 질의로 영어 논문을 다루는 RAG는 세 가지 과제를 함께 풀어야 한다. 검색에서는 한국어 질의와 영어 원문의 어휘 차이를 넘어 근거를 찾아야 하고, 답변 생성에서는 영어 근거의 내용을 한국어 답변에 충실히 반영해야 한다. 또한 모델이 영어 근거를 따라 영어로 답하는 언어 이탈(language drift)을 막아야 한다. 앞의 세 기법은 이 과제에 하나씩 대응한다. HyDE는 검색 입력을, CAD는 근거 반영을, SCD는 출력 언어를 조정한다. 선행 연구에서는 세 기법을 서로 다른 모델과 과제에서 각각 제안하고 평가하였지만, 같은 파이프라인과 질의에서 세 기법의 효과와 실행 시간을 함께 비교하지는 않았다. 한국어 질의–영어 문서 RAG에 세 기법을 함께 적용하려면 이러한 비교가 필요하다.

본 연구는 영어 학술·기술 문서를 검색하여 한국어로 답하는 Paper-RAG를 구성하고, 한국어 질의 60개에 HyDE·CAD·SCD의 적용 여부를 조합한 8개 조건(RAG-Cube)을 적용하였다(그림 1-1).

## 1.2 연구범위 [스타일=절(1.1)]

검색 대상은 RAG Survey[D1], CAD[D2], RAPTOR[D3], Mi:dm K 2.5 Pro Technical Report[D4]의 영어 문서 4종이다. 문서마다 한국어 질의를 15개씩, 총 60개 작성하였고, 각 질의의 검색 범위는 해당 문서로 한정하였다. 질의마다 8개 조건을 적용하여 생성 답변 480개를 얻었다.

답변 생성 모델은 Mi:dm 2.0 Base Instruct[M1]이다. 답변 품질은 RAGAS의 네 지표로, 출력 언어는 한국어 문자 비율로, 비용은 조건 실행 시간으로 측정하였다. 검색·재정렬·생성 설정은 4장에 정리하였다.

## 2.2 하이브리드 검색과 재정렬 [스타일=절(1.1)]

밀집 검색은 질의와 문서 구간을 임베딩한 벡터의 유사도로, BM25 희소 검색은 두 텍스트의 어휘 일치로 관련 구간을 찾는다[5][6]. 한국어 질의와 영어 원문은 어휘가 대부분 다르지만, 논문명·모델명·데이터셋명·수치처럼 두 언어에 같은 형태로 쓰이는 표기는 BM25의 검색 단서가 된다.

두 검색 결과는 가중 역순위 융합(weighted Reciprocal Rank Fusion, RRF)으로 결합한다[7]. 문서 d의 밀집 검색 순위와 BM25 순위를 각각 rank_dense(d), rank_BM25(d)라 할 때, 가중치 0.6과 0.4, 상수 k=60을 적용한 결합 점수는 다음과 같다.

[한글 수식 입력기 복붙용 — 최종 HWP에는 렌더링된 수식만 남김]

```text
RRF(d) = {0.6} over {k + rank_dense(d)} + {0.4} over {k + rank_BM25(d)}
```

융합한 검색 후보는 질의와 후보 구간을 한 쌍으로 입력받는 재정렬 모델의 관련성 점수로 다시 정렬한다. 재정렬 모델로는 문맥화된 언어 모델 표현을 문서 순위 계산에 활용한 CEDR[8] 등이 있다. 재정렬 순서는 생성 모델에 입력하는 검색 결과의 배치를 정한다. 생성 모델은 입력 내 위치에 따라 근거를 다르게 활용할 수 있으므로[9], 이 배치가 답변에도 영향을 줄 수 있다.

## 2.4 Context-Aware Decoding [스타일=절(1.1)]

CAD는 검색 결과를 포함한 입력과 제외한 입력에서 각각 다음 토큰의 점수를 계산하는 디코딩 방법이다[3]. 검색 결과를 넣었을 때 점수가 크게 오르는 토큰일수록 검색 결과의 영향을 많이 받는다. CAD는 두 점수의 차이를 키워, 모델의 사전 지식보다 검색 결과의 내용을 반영하는 토큰이 선택되도록 한다(그림 2-3).

[그림삽입: FINALDOCS/FIGURES/LITERATURE/fig2_3_cad_independent.png | 권장폭=본문폭 100% | 정렬=가운데]

[그림 2-3] CAD의 문맥 포함·제외 로짓 결합[3] [스타일=그림제목]

두 입력 뒤에 같은 생성 토큰열이 이어질 때, 검색 결과를 포함한 입력의 로짓을 z_ctx, 제외한 입력의 로짓을 z_noctx라 하면 CAD의 로짓은 다음과 같다. α는 검색 결과의 영향을 키우는 정도를 정하며, α=0이면 일반 디코딩과 같다.

[한글 수식 입력기 복붙용 — 최종 HWP에는 렌더링된 수식만 남김]

```text
z_CAD = (1 + alpha) z_ctx - alpha z_noctx
```

Shi 외[3]는 요약 과제와 지식 충돌 과제(모델의 사전 지식이 입력 문서의 내용과 충돌하는 과제)에서 CAD가 입력 문서를 더 충실히 반영한다고 보고하였다. CAD는 토큰마다 검색 결과를 제외한 입력의 로짓을 한 번 더 계산하므로 생성 시간이 늘어난다.

## 2.5 Soft Constrained Decoding과 언어 이탈 [스타일=절(1.1)]

다국어 RAG에서는 질문과 다른 언어의 문서를 검색하면 답변이 검색 문서의 언어로 바뀌는 언어 이탈이 발생할 수 있다. Li 외[4]는 이 현상을 분석하고, 디코딩 단계에서 목표 언어 토큰의 점수를 조정하는 SCD를 제안하였다. SCD는 어휘 집합을 목표 언어 토큰, 비목표 언어 토큰과 숫자·기호 같은 중립 토큰으로 나누어 로짓을 조정한다(그림 2-4).

[그림삽입: FINALDOCS/FIGURES/LITERATURE/fig2_4_scd_independent.png | 권장폭=본문폭 100% | 정렬=가운데]

[그림 2-4] SCD의 토큰 그룹별 로짓 조정[4] [스타일=그림제목]

생성한 토큰 수가 Tstart 이상이 되면 목표 언어 토큰의 로짓 z_i에는 α를, 비목표 언어 토큰의 로짓에는 β를 곱하고, 중립 토큰은 그대로 둔다. 본 연구는 한국어를 목표 언어로 하여 원 논문의 곱셈식을 그대로 적용하였다. 이 식은 원시 로짓에 계수를 곱하므로, 로짓이 양수인 토큰과 음수인 토큰에서 점수가 변하는 방향이 반대가 된다.

[한글 수식 입력기 복붙용 — 한국어 목표 토큰]

```text
tilde z_i = alpha z_i
```

[한글 수식 입력기 복붙용 — 비목표 언어 토큰]

```text
tilde z_i = beta z_i
```

[한글 수식 입력기 복붙용 — 중립 토큰]

```text
tilde z_i = z_i
```

## 2.6 RAG 평가 [스타일=절(1.1)]

RAGAS(Retrieval Augmented Generation Assessment)는 RAG의 검색과 생성을 나누어 자동으로 평가하는 프레임워크다[10]. RAGAS가 제공하는 근거 충실도(faithfulness), 답변 관련성(answer relevancy), 문맥 정밀도(context precision), 문맥 재현율(context recall) 가운데 근거 충실도와 답변 관련성은 생성 답변을, 문맥 정밀도와 문맥 재현율은 검색 결과를 평가한다. 근거 충실도는 평가 모델로 쓰는 대규모 언어 모델(Large Language Model, LLM)이 답변을 주장 단위로 나누고 각 주장이 검색 결과에 근거하는지 판정하여 계산한다. 지표별 계산 방식은 5.2절에 정리하였다.

## 2.7 관련 연구와 본 연구의 위치 [스타일=절(1.1)]

검색 구조에 관한 연구로는 Dense Passage Retrieval(DPR)[11]과 Fusion-in-Decoder(FiD)[12]가 있다. DPR은 질의와 문서를 각각 임베딩하는 밀집 검색으로 어휘 기반 검색보다 높은 질의응답 성능을 보였고, FiD는 여러 검색 구간을 디코더에서 함께 활용하여 답변을 개선하였다.

생성 방식에서는 Contrastive Decoding[13]이 두 출력 분포를 대조해 다음 토큰을 고르는 방법으로 생성 품질을 높였다. CAD[3]는 같은 모델에서 검색 결과를 포함한 입력과 제외한 입력의 로짓을 비교한다는 점에서, 서로 다른 두 모델의 출력을 대조하는 Contrastive Decoding과 구성이 다르다.

검색 전략에서는 RAPTOR[14]가 문서를 계층적으로 요약한 구조로 긴 문서의 검색을 개선하였다. RAPTOR 논문은 본 실험의 검색 대상 문서[D3]이기도 하다. Self-RAG[15]와 Adaptive-RAG[16]는 검색 필요성이나 질문 복잡도에 따라 검색 여부와 방식을 조정하였다. 검색과 생성의 구성 요소별 기법은 Zhao 외[17]와 Fan 외[18]의 조사 연구에 정리되어 있고, 검색·임베딩 모델의 비교에는 BEIR[19]와 MTEB[20] 같은 공개 벤치마크가 쓰인다.

# 3. 시스템 설계 [스타일=장(1.)]

## 3.1 연구 및 실험 요구사항 [스타일=절(1.1)]

모든 조건에서 검색·재정렬·생성 모델, 청크 분할, 후보 수와 생성 설정을 고정하고, 같은 한국어 질의 60개를 사용하였다. 질의마다 검색 청크 ID, 최종 검색 결과, 생성 답변, 실행 시간과 적용 파라미터를 저장하여 조건 간 결과를 질의 ID로 연결하였다.

## 3.2 아키텍처 설계 [스타일=절(1.1)]

Paper-RAG는 검색, 재정렬, 생성의 세 단계로 구성된다. 단계별 실행 순서는 4.2절의 그림 4-1에 제시하였다. 검색 단계에서는 BGE-M3[5] 기반 밀집 검색과 BM25 희소 검색을 함께 사용한다. HyDE를 적용하면 밀집 검색의 입력만 원질의에서 영어 가상 문서로 바뀐다. BM25와 재정렬에는 항상 한국어 원질의를 사용하여, HyDE 적용 여부에 따른 차이가 밀집 검색 입력에서만 생기도록 하였다.

두 검색 결과를 가중 RRF로 결합하고 CrossEncoder로 재정렬한 뒤, 상위 5개 구간을 생성 모델에 입력한다. CAD와 SCD는 생성 단계의 로짓에 차례로 적용한다. CAD는 검색 결과의 유무에 따른 원래 로짓의 차이를 이용하므로 먼저 적용하고, SCD는 그 결과에 언어별 계수를 곱해 출력 언어를 조정한다. 두 기법은 생성 단계에만 작용하므로, HyDE 미적용 조건에서 CAD와 SCD의 적용 전후 비교에는 같은 검색 결과가 쓰인다. HyDE 조건에서는 가상 문서를 샘플링하므로 실행마다 검색 결과가 달라질 수 있다.

## 5.4 통계 분석 방법 [스타일=절(1.1)]

같은 질의 60개를 8개 조건에서 모두 측정한 결과에 대응 t-검정과 반복측정 ANOVA를 적용하였다. 두 조건의 비교에서는 질의별 점수 차이를 검정하였고, 세 기법의 주효과와 상호작용은 질의를 반복측정 단위로 하여 분석하였다. 유의수준은 양측 0.05로 정하였다. 연구 질문별 핵심 지표는 실험 종료 후 선정하였다.

대응 t-검정의 귀무가설은 질의별 ON−OFF 차이의 평균이 0이라는 것이다. 질의 i의 적용 조건 점수를 s_i^ON, 미적용 조건 점수를 s_i^OFF라 하면 차이, 평균 차이와 t 통계량은 다음과 같다. s_Δ는 질의별 차이의 표본표준편차이며 자유도는 n−1이다.

```text
Delta_i = s_i^{ON} - s_i^{OFF}
```

```text
bar Delta = {1} over {n} sum_{i=1}^{n} Delta_i
```

```text
t = {bar Delta} over {s_Delta / sqrt n}
```

효과크기는 평균 차이를 차이의 표준편차로 나눈 Cohen dz로 나타내었다. RQ3에서는 한 질의에 SCD 대응쌍이 둘(CAD OFF·ON) 있으므로, 질의별로 두 차이를 먼저 평균하여 질의 하나가 표본 하나가 되도록 하였다(n=60).

반복측정 ANOVA의 각 효과는 두 수준이므로 자유도는 (1, n−1)이다. 효과크기는 부분 η²=F/(F+오차 자유도)로 계산하였다. 한국어 문자 비율과 실행 시간에는 8개 조건 전체로 H×C×S 3요인 ANOVA를 적용하였다. 품질 지표는 SCD 상태에 따라 평가 입력의 언어가 다르므로(5.3절), SCD OFF와 ON 안에서 각각 H×C 2요인 ANOVA를 적용하였다. 유의한 상호작용에 대해서는 조건별 단순 효과를 대응 t-검정으로 확인하였다.

RAGAS 평가값 1,920개 중 1,915개가 유효했고, 결측 5개는 모두 근거 충실도에서 발생하였다(ext_rag_003·006의 H0C1S0, ext_rag_003·005·006의 H0C0S1). 각 검정에는 필요한 조건의 값이 모두 있는 질의만 사용하였으며, 이에 따라 RQ2의 표본은 58개다.

## 5.8 종합 논의 [스타일=절(1.1)]

SCD는 HyDE·CAD의 네 조합 모두에서 영어 근거로 생성한 답변의 한국어 문자 비율을 높였으며, 평균 증가폭은 약 22%p였다. CAD 미적용 조건에서 SCD 적용에 따른 실행 시간 중앙값 차이는 1.5~2.5초였다. 한국어 질의–영어 문서 RAG에서 한국어 답변이 필요하다면 SCD는 비용이 작은 선택지다.

HyDE는 CAD·SCD 미적용 기본 조건에서 답변 관련성을 0.080점 높였다. 이 비교에서 검색 결과를 평가하는 문맥 정밀도와 문맥 재현율의 차이는 각각 −0.034점과 0.000점으로 작았다. 그림 B-2에서는 밀집 검색 입력이 바뀌면서 검색 결과와 답변 서술이 함께 달라졌다. 관련성 향상이 검색 결과의 변화에서 왔는지 답변 서술의 변화에서 왔는지 구분하려면 검색 결과를 고정한 비교가 필요하다. 한편 SCD만 적용한 조건(H0C0S1)에 HyDE를 추가한 탐색적 비교에서는 답변 관련성의 평균 차이가 +0.072점이었다(t(59)=1.602, p=0.114, 한국어 번역 평가). 다른 기법의 수준을 평균하면 HyDE는 실행 시간을 약 7초 늘렸다.

같은 검색 결과를 사용한 CAD 적용 전후의 근거 충실도 평균 차이는 +0.029점(p=0.393)이었으며, 8개 조건 전체에서 CAD 적용 시 평균 실행 시간은 미적용 조건보다 약 2.9배 길었다. 본 실험 조건에서 CAD는 품질 이득보다 시간 비용이 분명한 기법이었다.

CAD 미적용 답변 58개 중 25개는 근거 충실도가 이미 1.0이어서 올라갈 여지가 작았다. CAD는 60쌍 모두에서 답변 텍스트를 바꾸었으나, 근거 충실도는 22개 질의에서 오르고 24개에서 내려 평균 차이가 +0.029점에 그쳤다. 차이의 표준편차(0.255)는 평균 차이의 약 9배로, 효과의 방향과 크기가 질의마다 크게 달랐다. 그림 B-1처럼 답변이 지시문 형태의 짧은 문장으로 바뀐 경우도 있었다. 5.7절에서 확인한 평가 모델의 채점 변동을 고려하면, 작은 평균 차이에는 평가 변동이 섞여 있을 수 있다.

관측 효과크기 dz=0.113을 가정하면, 양측 유의수준 0.05에서 58쌍의 추정 검정력은 약 14%이고, 같은 효과크기에서 검정력 80%를 얻는 표본 수는 약 616개다.

Shi 외[3]는 모델의 사전 지식과 입력 문서가 충돌하는 과제에서 CAD의 효과를 보고하였다. 본 실험의 질의는 특정 문서의 세부 내용을 묻는 것이어서 그러한 충돌이 드물었을 가능성이 있으며, 높은 기본 충실도도 이와 부합한다. 지식 충돌형 질의를 추가한 후속 실험에서 CAD 적용 전후의 충실도 차이를 다시 비교할 수 있다.

한국어 문자 비율이 가장 높은 조합은 H1C0S1(0.807)이었으며, 이 조건의 평균 실행 시간은 24.9초로 CAD 적용 네 조건(55~74초)보다 짧았다.

## 5.9 평가 범위와 후속 검증 [스타일=절(1.1)]

영어 문서 4종의 질의 60개에서 각 질의·조건의 답변을 한 번씩 생성하고 평가하였다. 다른 분야의 문서, 생성 시드와 HyDE의 가상 문서 샘플링에 따른 결과 변동은 반복 실험으로 측정할 수 있다. 한국어 문자 비율은 답변의 언어 구성을 측정하는 지표이므로, 번역의 정확성과 문장의 자연스러움은 사람 평가로 확인할 항목이다.

# 6. 결론 [스타일=장(1.)]

본 연구는 한국어 질의로 영어 학술·기술 문서를 검색하는 Paper-RAG에서 HyDE·CAD·SCD의 적용 여부를 조합한 8개 조건을 같은 질의 60개에 적용하고, 대응 t-검정과 반복측정 ANOVA로 각 기법의 단독 효과와 조합 효과를 분석하였다.

## 6.1 연구 질문별 결과 [스타일=절(1.1)]

RQ1: CAD·SCD 미적용 기본 조건에서 HyDE는 답변 관련성을 높였다(+0.080, p=0.029).

RQ2: 같은 검색 결과에서 CAD 적용 전후의 근거 충실도 평균 차이는 +0.029점이었고, p값은 유의수준 0.05보다 컸다(t(57)=0.862, p=0.393).

RQ3: SCD는 한국어 문자 비율을 21.8%p 높였다(p<0.001).

RQ4: SCD는 네 조합 모두에서 한국어 비율을 높였고, CAD는 실행 시간을 약 2.9배로 늘렸다. 실행 시간에서는 C×S 상호작용이 유의하여(p<0.001), SCD를 함께 적용하면 CAD의 추가 시간이 약 8.8초 줄었다. 한국어 비율에서는 H×C 상호작용(p=0.040)도 유의하여, HyDE에 따른 한국어 비율 차이가 CAD 미적용 조건에서 더 컸다.

## 6.2 연구의 의의 [스타일=절(1.1)]

본 연구는 서로 다른 환경에서 제안된 HyDE·CAD·SCD를 한국어 질의–영어 문서 RAG에서 같은 백본과 질의로 비교하였다. 답변 품질은 SCD 상태별로 평가 언어를 나누어 분석하였고, 한국어 문자 비율과 실행 시간은 8개 조건 전체에서 비교하였다. 단순 비교로는 기법별 효과를, 요인 분석으로는 주효과와 상호작용을 분석하였다. SCD는 작은 시간 비용으로 한국어 문자 비율을 높였고, HyDE는 기본 조건에서 답변 관련성을 높였다. CAD는 근거 충실도 차이가 작았으나 실행 시간이 크게 늘었다.

## 6.3 적용 조건과 후속 연구 [스타일=절(1.1)]

한국어 답변을 생성하는 Paper-RAG에는 SCD를 기본으로 적용할 수 있다. SCD 적용 조건에서 HyDE를 추가했을 때 답변 관련성의 평균 차이는 +0.072점이었다(p=0.114). HyDE의 적용 여부는 조건별 답변 관련성, 한국어 문자 비율과 실행 시간을 비교하여 결정한다. CAD는 실행 시간이 크게 늘어나므로, 모델의 사전 지식과 문서 내용이 충돌하는 질의처럼 효과가 기대되는 경우에만 적용을 검토한다.

후속 연구로는 다음을 제안한다. 첫째, 번역만 적용한 조건을 추가하여 HyDE의 효과를 번역과 가상 문서 생성으로 분리한다. 둘째, CAD의 α를 바꾸고 지식 충돌형 질의를 포함하여 CAD가 효과를 보이는 조건을 확인한다. 셋째, 질의 수와 문서 분야를 늘리고 생성과 평가를 반복하여 결과의 변동을 측정하며, 모든 조건의 평가 언어를 통일한다. 넷째, 사람 평가로 한국어 답변의 정확성과 자연스러움을 확인한다.
