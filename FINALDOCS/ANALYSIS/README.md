# 60문항 질문별 분석

원래 생성·검색·평가 기록을 그대로 읽어 같은 질문의 기준 조건과 적용 조건을 연결한다. 네 질문 유형은 사실·정의 8개, 방법·절차 29개, 결과·비교 20개, 목적·기여 3개다. 질문의 원문·정답 근거·원문 페이지는 기존 60문항 표와 대조하였다.

품질 비교는 SCD 상태가 같은 여덟 쌍이다. 영어 근거 평가 네 쌍과 한국어 번역 근거 평가 네 쌍을 각각 분석한다. SCD 추가 네 쌍에는 출력 문자 비율과 시간을 대응한다. 품질 결측 5개는 같은 질문을 양쪽 평균에서 함께 제외한다. 원점수·평균·대응 차이·개선/악화/비슷함과 실제 질문·근거·답변을 사용한다.

## 자료

- `QUERY_LEVEL_RESULTS.csv`: 60×8개 실행과 질문 특성.
- `QUERY_LEVEL_DELTAS.csv`: 허용된 비교의 측정값 차이 3,360개.
- `QUESTION_TYPE_SUMMARY.csv`: 전체·유형·문서·답 형태·요구 항목별 728행.
- `QUESTION_CLASSIFICATION_60Q.csv`: 질문 유형·답 형태·요구 정보와 분류 검토.
- `ZERO_RELEVANCY_AUDIT.json`: 0점 전환·양쪽 양수인 질문들의 평균 차이.
- `CONTEXT_IDENTITY_AUDIT.json`: 실제 입력 구간과 순서가 있는 청크 ID를 각각 비교한 결과. 가상 문서·번역문·샘플링 설정도 확인한다.
- `CASE_REVIEW_PLAN.json`: 전체 분석 결과의 해시와 그 뒤 선정한 현상·질문·확인 항목.
- `REVIEWED_CASES.json`: 선정된 9개 질문의 원래 입력 구간·답변·측정값과 근거 검사 33개.
- `CASE_EXCERPTS.json`: 질문 요구에 해당하는 실제 답변의 정확한 발췌.
- `SOURCE_PAGE_AUDIT.json`: 60개 질문의 원문 페이지 확인 자료.
- `RAW_PRESERVATION.json`: 원자료 8개 파일의 변경 전·후 바이트 해시와 LF 정규화 해시.

## 관측

방법·절차에서 미적용→HyDE의 관련성 평균은 0.575→0.747, 개선/악화/비슷함은 14/3/12다. SCD→HyDE+SCD에서는 0.531→0.688, 12/7/10이다. 영어 평가의 0점→양수 전환은 6개이고 양쪽 양수인 22개 질문의 평균 차이는 +0.069다. 실제 출력에는 최적 클러스터 수의 근거 회복, NQ-Swap 절차 설명과 사전학습 원문 이어 쓰기가 함께 포함된다.

CAD의 방법·절차 충실도 평균 차이는 +0.082이고 같은 입력 구간에서 생성된 답변의 내용을 대조하였다. XSUM 답변은 다른 표 행의 수치를, RAPTOR 청크 질문은 트리 구축 비용을 설명한 상태에서 충실도가 높아졌다. HyDE가 포함된 조합끼리는 가상 문서와 입력 구간도 달라진 실행을 포함한다. 네 유형에서 SCD 추가 후 문자 비율 평균이 모두 높아졌다. 방법·절차 CAD 단독의 평균 추가 시간은 44.3초다.

## 재현

```powershell
python FINALDOCS/ANALYSIS/analyze_questions.py
python FINALDOCS/ANALYSIS/review_cases.py
python FINALDOCS/VALIDATION/verify_question_analysis.py --analysis-only
```

원래 생성·평가 API를 호출하지 않는다. 사례 계획의 기준 요약 해시가 바뀌면 사례 선정을 다시 검토한다. RAGAS 0.2.15의 회피 판정 규칙은 고정된 원본 구현을 대조하였다. 원래 저장 자료에는 질문별 평가자의 내부 판정 플래그가 포함되어 있지 않다. 실제 검색 근거의 언어 구분과 답변 내용을 함께 제시한다.
