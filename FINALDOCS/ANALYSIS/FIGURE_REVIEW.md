# 평행좌표 검토 기준

영어 근거 평가 네 조건과 한국어 번역 근거 평가 네 조건을 각각 한 열의 네 패널로 제시한다. 각 패널은 해당 조건의 질문 60개를 모두 표시한다. 선 하나는 질문 하나이며 색은 네 질문 유형이다. 다섯 축은 근거 충실도, 답변 관련성, 문맥 정밀도, 문맥 재현율, 한국어 문자 비율의 관측 원점수(0~1)다. 결측 축에서는 선을 끊는다.

유형 평균이나 대표 질문의 선을 별도로 중첩하지 않는다. 유형 평균·대응 차이·개선/악화/비슷함과 초 단위 실행 시간은 표로 제시한다. 그림 5-1과 5-2는 비교 절차와 실제 입력·답변의 연결을 설명하는 도식이다.

포스터는 미적용·HyDE의 전체 질문 60개씩을 두 개의 편집 가능한 평행좌표로 제시한다. PPTX의 120개 계열과 600개 축 값을 원자료와 대조하고, 표 5개는 본문과 같은 요약 자료에서 생성한다.
