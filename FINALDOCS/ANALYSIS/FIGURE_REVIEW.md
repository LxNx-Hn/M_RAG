# 그림 검토 기준

논문의 평행좌표는 질문 유형마다 그림 하나(그림 5-3 수치 질문 18개, 그림 5-4 방법 질문 25개, 그림 5-5 개념과 결과 질문 17개)이며, 각 그림은 미적용, HyDE, CAD, SCD 조건의 패널을 위에서 아래로 쌓는다. 선 하나는 질문 하나이고 다섯 축은 근거 충실도, 답변 관련성, 문맥 정밀도, 문맥 재현율, 한국어 문자 비율의 원점수(0에서 1)다. 0점과 결측값 위치에서는 선을 끊는다.

색 선은 미적용과 비교하여 HyDE의 답변 관련성, CAD의 근거 충실도, SCD의 한국어 문자 비율이 가장 크게 오르거나 내린 질문이며, 오른 질문은 빨강 ▲, 내린 질문은 파랑 ▼로 표시한다. 선정 결과는 `FIGURE_HIGHLIGHTS.json`에 남긴다.

그림 4-2와 포스터 03은 수치 질문 하나(Mi:dm K 2.5 Pro의 파라미터 수)에서 미적용과 HyDE, CAD, SCD 단독 조건을 패널마다 비교한다. 인용문과 점수는 저장된 실행 기록에서 읽고(`EXAMPLE_MECHANISM.json`), 임베딩 점의 위치와 후보 단어의 글자 크기는 원리를 보인 개념도다.

포스터 06은 방법 질문 25개의 미적용, HyDE, CAD, SCD 패널을 2×2로 배치한다. 그림 5-1과 5-2는 비교 절차와 실제 입력, 답변, 평가값의 연결을 설명하는 도식이다.
