# Cube-RAG 질문 유형별 논문과 포스터

한국어 질문 60개에 HyDE, CAD, SCD의 적용 여부를 조합한 여덟 조건을 적용하고, 조건별 원점수, 수치, 방법, 개념과 결과의 세 질문 유형(18, 25, 17개)별 평균, 점수가 크게 바뀐 질문의 실제 검색 결과와 답변을 분석한다. 근거 충실도, 문맥 정밀도, 문맥 재현율은 같은 평가 언어의 조건끼리 비교하고, 처리 시간은 각 생성 실행의 첫 기록을 뺀 58개 질문으로 계산한다. 원래 480개 생성 기록과 평가값은 보존한다.

결과 그림은 질문 유형마다 하나인 평행좌표이며, 미적용, HyDE, CAD, SCD 조건의 패널에서 질문 하나를 선 하나로 그린다. 축은 근거 충실도, 답변 관련성, 문맥 정밀도, 문맥 재현율, 한국어 문자 비율의 다섯 개이고 처리 시간은 표로 제시한다. 0점과 결측값은 그림에서만 선을 끊고, 원자료와 표의 계산은 그대로 둔다. 그림 4-2는 수치 질문 하나에서 미적용과 HyDE, CAD, SCD 단독 조건을 비교한다.

부록 A는 60개 질문과 정답 근거를, 부록 B는 5.7절에서 대조한 실제 사례 9개를 담는다. 최종 배치는 한컴 편집 화면에서 확인하고, PDF는 한컴에서 내보낸 쪽 번호와 본문 대조 자료다. 미정인 인준일, 심사위원, 날인과 개인정보는 공개 편집본에 비워 둔다. 실물 인쇄, A1 거리별 판독, 설치형 PowerPoint 실행은 별도 확인 대상이다.
