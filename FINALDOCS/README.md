# M-RAG 질문 유형별 논문·포스터

60개 한국어 질문에 적용한 HyDE·CAD·SCD 여덟 조건의 점수와 실제 검색·답변을 분석한다. 네 질문 유형(8·29·20·3개)을 유지하고, 같은 평가 근거 언어의 조건끼리 질문별 대응 차이를 비교한다. 원래 480개 생성 기록과 평가값은 보존한다.

결과 그림은 HyDE·CAD·SCD 적용 후의 질문별 점수를 각각 네 질문 유형으로 나눈 평행좌표다. 그림마다 실제 질문 60개를 사용하며 평균선과 적용 전후 선을 겹쳐 그리지 않는다. 한 선은 질문 하나이고, 여섯 지표 중 처리 시간은 초 단위의 별도 축으로 표시한다. 사용자가 지정한 0점 비표시는 그래프에만 적용하며 원자료와 표의 계산은 보존한다.

관련성 비교표는 두 조건 모두 0점이 아닌 질문을 사용한다. 비교 제목은 ‘HyDE에 CAD를 추가했을 때의 답변 관련성’처럼 문장으로 쓰고 평가 언어와 제외 수를 다음 줄에 분리한다. 부록 A는 60개 질문을 보존하며 부록 B는 전체 분석 후 대조한 실제 사례다. [녹취 기반 그래프 의도 검토](VALIDATION/GRAPH_INTENT_REVIEW_20261020.md)에 표시 기준을 기록했다.

최종 배치는 한컴 편집 화면에서 확인한다. PDF는 한컴에서 내보낸 쪽번호·텍스트 연결 자료다. 미정인 인준일·심사위원·날인과 개인정보 필드는 공개 편집본에 비워 둔다. 실물 인쇄·A1 거리별 판독과 설치형 PowerPoint 실행은 별도 확인 대상이다.
