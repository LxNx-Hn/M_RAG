# 5. 실험 [스타일=장(1.)]

이 장은 질문 구성과 평가 방법을 설명하고 결과를 분석한다.

## 5.1 질문 구성과 질문 유형 [스타일=절(1.1)]

실험에는 영어 문서 네 종에 관한 한국어 질문 60개를 사용하였다. RAG Survey는 RAG의 구성과 발전 과정을, CAD 논문은 검색 결과를 답변에 반영하는 디코딩 방법을, RAPTOR 논문은 문서 요약 트리를 이용한 계층적 검색을 다룬다. Mi:dm K 2.5 Pro Technical Report는 한국어와 영어를 함께 학습한 언어 모델의 학습 과정과 평가 결과를 다룬다. 문서마다 15개 질문을 구성하였고, 각 질문의 검색 범위는 해당 문서 하나다.

질문은 문서의 주요 내용을 고르게 다루도록 작성하였다. 문서마다 질문의 형식과 범위를 정하는 초기 질문 3개를 먼저 작성하고, GPT-4o로 문서의 주요 내용을 15개 단위로 요약하였다. 각 단위에 질문을 하나씩 배정하였으며 초기 질문 3개도 이 15개에 포함된다. 연구자는 원문 PDF에서 모든 질문의 답변 가능성과 정답 근거를 확인하고 해당 쪽을 기록하였다(부록 A). 질문 작성과 근거 확인을 나눈 절차는 논문 기반 질의응답 데이터셋인 QASPER[21]와 문서 기반 질문 생성 연구[22]를 참고하였다.

실험 결과를 분석하는 단계에서 정답의 형태와 내용에 따라 질문을 세 유형으로 다시 나누었다. 정답이 점수, 비율, 개수, 설정값 같은 수치인 질문 18개는 수치 질문이다. 나머지 서술형 질문 42개 가운데 처리 과정, 실험 구성, 사용한 모델과 자료를 묻는 질문 25개는 방법 질문, 개념의 정의와 연구 목적, 결과의 경향이나 이유를 묻는 질문 17개는 개념과 결과 질문이다. 예를 들어 장문 독해 데이터셋 QuALITY(Question Answering with Long Input Texts, Yes!)에서 한 계층과 세 계층을 검색했을 때의 정확도를 묻는 질문은 수치 질문, RAPTOR가 군집 수를 정하는 기준을 묻는 질문은 방법 질문, RAG가 지식 집약 과제에서 갖는 이점을 묻는 질문은 개념과 결과 질문이다.

질문에는 원문 내용에 따른 네 분류(사실과 정의 8개, 방법과 절차 29개, 결과와 비교 20개, 목적과 기여 3개)도 함께 기록되어 있다. 이 분류에서 목적과 기여는 3개뿐이고, 결과와 비교 20개에는 수치를 옮겨야 하는 질문 12개와 경향을 설명하는 질문 8개가 함께 들어 있다. 답변에 필요한 작업은 수치를 정확히 옮기는 일, 과정을 설명하는 일, 개념이나 결과를 해석하는 일로 나뉘므로, 정답의 형태를 먼저 기준으로 삼고 서술형 질문만 내용으로 나누었다. 그 결과 세 유형의 질문 수는 18, 25, 17개가 되었다.

## 5.2 평가 지표와 평가 입력 [스타일=절(1.1)]

답변과 검색 결과의 품질은 RAGAS 0.2.15의 네 지표로 평가하였다. 평가 모델은 GPT-4o, 임베딩 모델은 BGE-M3이며, 참조 답변으로는 부록 A의 영어 정답 근거를 사용하였다.

근거 충실도는 생성 답변의 주장 가운데 입력 구간이 뒷받침하는 주장의 비율이다. 답변 관련성은 평가 모델이 생성 답변에서 역으로 만든 질문과 원래 질문의 임베딩 코사인 유사도다. 평가 모델이 답변을 모호하거나 회피하는 응답으로 판정하면 답변 관련성은 0이 된다. 480개 답변 가운데 54개가 0으로 기록되었고, 조건별 개수는 5.4절에 제시하였다.

문맥 정밀도는 참조 답변에 유용한 구간이 검색 결과의 위쪽에 놓인 정도이고, 문맥 재현율은 참조 답변의 주장을 검색 결과가 뒷받침하는 비율이다. 근거 충실도, 문맥 정밀도, 문맥 재현율은 0에서 1 사이의 값이다. 답변 관련성은 코사인 유사도이므로 이론적 범위가 −1에서 1이고, 이번 실험의 관측값은 모두 0에서 1 사이였다. 네 지표 모두 값이 클수록 품질이 높다.

출력 언어는 생성 답변의 한국어 문자 비율로 측정하였다. 한글 문자 수를 N_Hangul, ASCII 영문자 수를 N_ASCII라 하면 한국어 문자 비율은 다음과 같다.

```text
KoreanRatio = {N_Hangul} over {N_Hangul + N_ASCII}
```

모델명과 논문명의 영문자도 분모에 들어가므로, 자연스러운 한국어 답변도 1보다 낮은 값을 가진다. 숫자만 출력한 답변 1개는 비율이 0으로 기록되어 있다. 처리 시간은 질문 하나의 처리 시작부터 답변 생성과 기록용 메타데이터 구성이 끝날 때까지의 초 단위 시간이며, 짧을수록 비용이 작다.

품질 평가에 제공한 검색 결과의 언어는 SCD 적용 여부에 따라 다르다. SCD를 적용한 조건의 답변은 대부분 한국어이므로, 같은 실행에서 저장한 영어 검색 결과를 GPT-4o로 번역하여 근거 충실도, 문맥 정밀도, 문맥 재현율의 평가에 사용하였다. SCD를 적용하지 않은 조건은 생성에 사용한 영어 검색 결과로 평가하였다. 따라서 이 세 지표는 SCD 적용 여부가 같은 네 조건 안에서 비교한다. 답변 관련성은 질문과 답변만으로 계산하므로 한국어 문자 비율과 함께 여덟 조건 전체에서 비교한다. 답변을 생성할 때는 모든 조건에 영어 검색 결과를 입력하였고, 참조 답변도 모든 조건에서 영어 원문이다. 그림 5-1은 생성 기록과 평가값을 질문과 조건으로 연결하는 과정을 나타낸다.

평가값은 질문, 참조 답변, 입력 구간, 생성 답변을 함께 볼 때 의미가 분명해진다. RAPTOR에서 베이즈 정보 기준(Bayesian Information Criterion, BIC)이 결정하는 항목을 묻는 질문에서 HyDE 조건의 입력 구간에는 최적 군집 수를 정한다는 원문 문장이 들어 있었고, 답변도 같은 내용을 설명하였다. 이 답변의 근거 충실도는 0.857, 문맥 재현율은 1.000이었다. 근거 충실도는 답변의 주장을 입력 구간과 대조하고, 문맥 재현율은 참조 답변을 입력 구간과 대조한다(그림 5-2).

## 5.3 분석 방법 [스타일=절(1.1)]

분석은 조건별 원점수, 질문 유형별 평균, 질문별 변화의 순서로 진행하였다. 먼저 질문 60개에 대한 여덟 조건의 평균과 표준편차를 지표별로 계산하였다(5.4절). 다음으로 같은 평균을 세 질문 유형으로 나누어 계산하고, 각 기법이 유리한 유형을 비교하였다(5.5절).

질문별 변화는 같은 질문에서 적용 조건의 점수와 미적용 조건의 점수를 비교한 값이며, 검색 결과를 쓰는 세 지표는 SCD 적용 여부가 같은 조건끼리 비교한다. 차이가 0.05보다 크면 오른 질문, −0.05보다 작으면 내린 질문, 그 사이면 비슷한 질문으로 세었고, 처리 시간은 1초를 경계로 삼았다. 두 조건 중 한쪽의 답변 관련성이 0인 질문은 오르내림 대신 관련성 0점이 생기거나 사라진 질문으로 따로 세었다.

평균은 질문 사이의 차이를 가린다. 같은 조건에서도 점수가 크게 오른 질문과 크게 내린 질문이 함께 있을 수 있으므로, 질문별 원점수를 평행좌표(지표를 세로축으로 나란히 두고 한 질문의 값을 선으로 이은 그림)로 그려 유형마다 평균에서 멀리 떨어진 질문을 찾았다(5.6절). 이렇게 찾은 질문은 원문 정답 근거, 입력 구간, 생성 답변을 미적용 조건과 대조하였다(5.7절).

근거 충실도 480개 값 가운데 5개가 결측이다(CAD 조건 2개, SCD 조건 3개). 결측 질문은 해당 조건의 평균과 대응 비교에서 제외하였고, 나머지 지표는 480개 값을 모두 사용하였다.

## 5.4 조건별 평가 결과 [스타일=절(1.1)]

여덟 조건의 평균에서 SCD를 포함한 조건은 한국어 문자 비율이 모두 높았지만, 두 기법 이상을 결합한 조건의 답변 관련성은 모두 HyDE 단독보다 낮았다. 표 5-1은 질문 60개에 대한 조건별 평균과 표준편차를 지표별로 정리한 것이다.

SCD를 적용하지 않은 조건 1, 2, 3, 5에서는 HyDE가 답변 관련성을 0.683에서 0.763으로 가장 크게 높였다. 관련성 0점이 없는 질문끼리 비교하면 HyDE로 관련성이 오른 질문은 16개, 내린 질문은 5개였다. CAD는 근거 충실도를 0.791에서 0.839로 높였고, 답변 관련성은 0.675로 미적용의 0.683과 비슷하였다. HyDE+CAD는 근거 충실도가 0.860으로 가장 높았지만 답변 관련성은 0.705로 HyDE 단독보다 낮았다. 검색 지표에서는 미적용의 문맥 정밀도가 0.749로 HyDE의 0.714보다 높았고, 문맥 재현율은 두 조건이 0.933으로 같았다.

SCD를 적용한 조건 4, 6, 7, 8에서는 HyDE+SCD의 답변 관련성이 0.710으로 가장 높았다. 여기에 CAD를 더한 HyDE+CAD+SCD는 0.667, SCD에 CAD를 더한 CAD+SCD는 0.600으로 낮아졌다. 관련성 0점 답변은 HyDE 조건에서 3개로 가장 적었고 CAD+SCD 조건에서 11개로 가장 많았다.

한국어 문자 비율은 SCD를 적용한 네 조건이 0.699에서 0.807로, SCD를 적용하지 않은 네 조건의 0.488에서 0.556보다 모두 높았다. 가장 높은 조건은 HyDE+SCD(0.807)였다. SCD를 단독으로 적용하면 질문 60개 가운데 50개에서 비율이 0.05보다 크게 올랐다.

조합의 손실은 같은 질문끼리 비교해도 나타났다. HyDE에 CAD를 더하면 답변 관련성이 내린 질문이 18개, 오른 질문이 5개였고, HyDE+SCD에 CAD를 더해도 내린 질문이 14개, 오른 질문이 5개였다. HyDE와 HyDE+CAD는 입력 구간이 같은 질문이 18개뿐이어서(3.3절), 이 차이에는 검색 결과의 변화와 CAD의 디코딩 변화가 함께 들어 있다. 두 기법 이상을 결합한 네 조건의 답변 관련성은 0.600에서 0.710 사이였고, 조합이 일관되게 높인 지표는 SCD를 포함할 때의 한국어 문자 비율이었다. SCD를 적용한 네 조건 가운데 HyDE+CAD+SCD는 SCD 단독보다 근거 충실도가 0.787에서 0.831로, 문맥 재현율이 0.900에서 0.917로 높았고, 문맥 정밀도는 0.763과 0.754로 비슷하였다. 답변 관련성은 미적용의 0.683과 비슷한 0.667이었고, 한국어 문자 비율은 0.494에서 0.731로 올랐다.

처리 시간은 CAD를 포함한 네 조건이 56.033초에서 72.527초로, CAD를 포함하지 않은 네 조건의 16.656초에서 24.811초보다 약 세 배 길었다. CAD는 토큰을 하나 생성할 때마다 검색 결과를 뺀 입력의 로짓을 한 번 더 계산한다. HyDE는 번역과 가상 문서 생성으로 평균 6.877초를, SCD는 2.002초를 더했다.

CAD에 SCD를 더한 CAD+SCD는 CAD 단독보다 평균 8.148초 짧았다. 1초 넘게 짧아진 31개 질문은 모두 답변 길이가 줄었고, 58개 답변의 평균 길이는 1,064자에서 765자로 줄었다. CAD의 추가 계산은 생성하는 토큰 수만큼 반복되므로 답변이 짧아진 만큼 처리 시간도 줄었다.

## 5.5 질문 유형별 결과 [스타일=절(1.1)]

질문을 세 유형으로 나누면 각 기법이 유리한 질문이 서로 달랐다. 표 5-2는 표 5-1의 평균을 수치 질문, 방법 질문, 개념과 결과 질문으로 나누어 계산한 것이다.

HyDE는 방법 질문에서 가장 큰 차이를 만들었다. 방법 질문 25개의 답변 관련성은 미적용 0.575에서 HyDE 0.745로, 문맥 재현율은 0.880에서 0.960으로 올랐다. 미적용에서 관련성이 0점이던 방법 질문 5개는 HyDE 적용 후 모두 양수가 되었고, 그중 3개는 질문에 필요한 정보를 제시하였다. 새로 0점이 된 질문은 1개였다. 개념과 결과 질문에서도 답변 관련성은 0.778에서 0.815로, 근거 충실도는 0.848에서 0.903으로 올랐다. 수치 질문의 답변 관련성은 0.743에서 0.740으로 비슷하였고, 문맥 정밀도와 재현율은 각각 0.668에서 0.622, 0.944에서 0.889로 낮아졌다. 문서별로는 관련성 0점이 없는 질문끼리 비교한 HyDE의 답변 관련성 변화가 RAG Survey 질문 14개에서 +0.110, CAD 논문 질문 13개에서 −0.008로 달랐다.

CAD는 수치 질문과 방법 질문에서 근거 충실도를 높였다. 수치 질문의 충실도는 0.826에서 0.896으로, 방법 질문은 0.726에서 0.830으로 올랐다. 수치 질문에서 충실도가 가장 높은 조건은 SCD를 적용하지 않은 조건 가운데 HyDE+CAD, 적용한 조건 가운데 HyDE+CAD+SCD였고 둘 다 0.927이었다. 개념과 결과 질문에서는 반대로 충실도가 0.848에서 0.789로, 답변 관련성이 0.778에서 0.663으로 낮아졌다. 이 유형은 미적용에서 이미 문맥 재현율이 1.000, 근거 충실도가 0.848이었고, CAD 적용 후 관련성 0점 답변이 2개 생겼다. 같은 유형 안에서도 문서에 따라 변화의 크기가 달랐다. 수치 질문에서 CAD의 근거 충실도 변화는 RAPTOR 질문 6개가 평균 +0.163, CAD 논문 질문 4개가 +0.120, Mi:dm 질문 8개가 −0.024였다.

SCD는 세 유형 모두에서 한국어 문자 비율을 높였다. 상승폭은 개념과 결과 질문(0.456에서 0.709)과 수치 질문(0.585에서 0.814)이 방법 질문(0.455에서 0.610)보다 컸다. 방법 질문 가운데 RAG Survey의 검색 기법을 묻는 세 질문은 SCD 적용 후에도 답변이 영어 원문을 이어 써 비율이 0에 머물렀다. HyDE와 함께 적용한 HyDE+SCD는 세 유형 모두에서 비율이 가장 높았고(0.835, 0.785, 0.810), SCD를 적용한 조건 가운데 방법 질문의 근거 충실도도 0.829로 가장 높았다.

세 기법의 이득은 서로 다른 지표에서 나타났고, 그 대가도 달랐다. CAD의 충실도 상승에는 약 네 배의 처리 시간이 따랐고, 개념과 결과 질문에서는 관련성 하락이 함께 나타났다. SCD 단독의 답변 관련성은 0.637로 미적용(0.683)보다 낮았다. HyDE는 처리 시간을 6.877초 늘렸고, 수치 질문에서 문맥 정밀도와 재현율을 낮추었다.

## 5.6 질문별 원점수의 분포 [스타일=절(1.1)]

같은 유형의 평균이 오른 경우에도 질문마다 변화의 크기와 방향은 달랐다. 그림 5-3부터 그림 5-5는 세 유형의 질문별 원점수를 미적용, HyDE, CAD, SCD 조건으로 나누어 그린 평행좌표로, 평균이 가리는 질문 사이의 차이와 평균에서 멀리 떨어진 질문을 보여 준다. 색 선은 미적용과 비교하여 HyDE의 답변 관련성, CAD의 근거 충실도, SCD의 한국어 문자 비율이 가장 크게 오르거나 내린 질문이다. 0점과 결측값 위치에서는 선을 끊었다.

그림 5-3에서 수치 질문의 선은 네 조건 모두 근거 충실도와 문맥 재현율의 위쪽에 모였고, 문맥 정밀도에서는 0점을 뺀 값이 0.200에서 1.000까지 넓게 퍼졌다. HyDE 조건에서 답변 관련성이 가장 크게 오른 질문은 Mi:dm의 레드팀 평가 공격 성공률을 묻는 질문(0.770에서 0.886)이었다. CAD 조건에서 근거 충실도가 가장 크게 오른 질문은 RAPTOR의 청크 길이와 문장 경계 처리를 묻는 질문(0.250에서 1.000)이었지만, 이 답변은 질문과 다른 내용을 설명하였다(5.7절).

그림 5-4의 방법 질문은 미적용에서 근거 충실도와 답변 관련성이 넓게 흩어져 있었고, 관련성 0점으로 선이 끊긴 질문이 5개였다. HyDE 조건에서는 관련성 축의 선이 위쪽으로 모였고 0점 질문은 1개로 줄었다. 0점을 제외하면 RAPTOR에서 가우스 혼합 모델(Gaussian Mixture Model, GMM) 군집화 전에 차원 축소 기법인 UMAP(Uniform Manifold Approximation and Projection)을 쓰는 이유를 묻는 질문의 관련성이 0.541에서 0.943으로 가장 크게 올랐다. CAD 조건에서 충실도가 가장 크게 오른 질문은 Natural Questions(NQ)의 정답 개체를 바꾼 NQ-Swap 데이터셋의 생성 절차를 묻는 질문(0.185에서 0.955)으로, 이 답변은 입력 구간의 영어 문단을 그대로 옮긴 것이었다(5.7절).

그림 5-5의 개념과 결과 질문은 미적용에서 문맥 재현율이 모두 1.000이었고, 근거 충실도와 답변 관련성도 위쪽에 모여 있었다. HyDE 조건의 분포는 미적용과 비슷하였고, CAD 조건에서는 충실도와 관련성이 아래로 내려간 선이 늘었다. 충실도가 가장 크게 내린 질문은 RAG가 지식 집약 과제에서 갖는 이점을 묻는 질문(0.938에서 0.500)으로, CAD 답변에는 ‘위 내용 참조’라는 지시문만 남았다.

SCD 조건에서는 세 유형 모두 한국어 문자 비율 축의 선이 위로 올라갔다. 비율이 가장 크게 오른 질문은 수치 질문에서 Mi:dm의 문맥 길이(0.354에서 0.877), 방법 질문에서 사후 훈련의 모델 병합(0.471에서 0.969), 개념과 결과 질문에서 RAG와 파인튜닝의 비교(0.332에서 0.962)를 묻는 질문이었다. 세 그림에서 유형 평균의 큰 변화는 일부 질문의 큰 변화에서 나왔다. 방법 질문의 HyDE 관련성 상승은 관련성 0점 답변 5개가 양수로 바뀐 데서, 개념과 결과 질문의 CAD 하락은 관련성 0점 답변 2개가 생긴 데서 크게 영향을 받았다.

## 5.7 실제 답변에서 확인한 변화 [스타일=절(1.1)]

점수가 크게 바뀐 질문을 원문 정답, 입력 구간, 생성 답변과 대조하면 점수 변화의 원인은 유형마다 달랐다. 이 절의 비교는 모두 같은 질문의 미적용 답변을 기준으로 한다.

RAPTOR는 문서 구간을 임베딩한 뒤 군집으로 묶고 각 군집을 요약하여 트리를 만든다. 이 과정에서 BIC가 무엇을 정하는지 묻는 방법 질문에서 미적용의 입력 구간에는 최적 군집 수를 정한다는 문장이 없었고, 답변은 해당 정보를 확인할 수 없다고 하였다. HyDE를 적용하자 이 문장이 입력 구간에 들어왔고, 답변은 BIC가 최적 군집 수를 정하는 데 쓰인다고 설명하였다. 답변 관련성은 0.000에서 0.895로, 문맥 재현율은 0.000에서 1.000으로 올랐다.

CAD 논문의 NQ-Swap 데이터셋이 어떻게 만들어졌는지 묻는 방법 질문에서는 미적용과 HyDE 모두 생성 절차가 담긴 원문 구간을 입력받았다. 미적용 답변은 절마다 설명을 요청하는 문장을 나열하여 관련성이 0.000이었고, HyDE 답변은 개체 정답 질문의 선택, 근거 문서 탐색, 정답 개체의 무작위 치환이라는 세 단계를 설명하여 0.785를 받았다. 같은 입력에서 CAD 답변은 CAD 논문의 α 설정 문단을 영어로 옮겨 근거 충실도가 0.185에서 0.955로 올랐고, 답변 관련성은 0.395였다.

관련성 점수가 올라도 요구 정보가 빠진 답변이 있었다. Mi:dm 보고서에서 Fusion SFT(지도 미세조정, Supervised Fine-Tuning) 단계의 비추론(non-reasoning) 데이터 비중을 늘린 목적을 묻는 질문의 정답은 대화 정렬이라는 목적과 창작, 번역, 일반 질의응답 데이터의 보강이며, 이 내용은 미적용과 HyDE의 입력 구간에 모두 있었다. HyDE 답변은 사전학습 단계의 데이터 구성을 다룬 영어 원문을 이어 썼다. 이 답변에는 목적과 보강 과제가 빠졌지만 답변 관련성은 0.000에서 0.463으로 올랐다.

수치 질문에서는 정답 수치가 담긴 구간이 입력에 들어오는지가 결과를 갈랐다. RAPTOR 논문은 QuALITY 데이터셋의 한 이야기에서 트리의 맨 아래 계층만 검색한 경우와 세 계층을 모두 검색한 경우의 정확도를 비교한다. 이 두 정확도를 묻는 질문에서 미적용의 입력 구간과 답변에는 57.9와 73.68이 모두 있었다. HyDE를 적용하자 73.68이 담긴 구간이 입력에서 빠졌고, 답변은 비교 수치를 확인할 수 없다고 한 뒤 트리 검색의 일반적인 장점을 설명하였다. 답변 관련성은 0.871에서 0.000으로, 문맥 재현율은 1.000에서 0.000으로 내려갔다.

CAD가 높인 근거 충실도에는 다른 수치나 다른 내용을 옮긴 답변도 포함되었다. CAD 논문의 표에서 LLaMA-30B의 요약 데이터셋 XSUM(Extreme Summarization) 결과를 묻는 질문의 정답은 일반 디코딩과 CAD의 ROUGE-L(최장 공통 부분열 기반 요약 지표) 18.7과 22.0, factKB(사실 일치 지표) 47.7과 66.4, BERT-P(BERTScore 정밀도) 87.1과 90.3이다. 미적용과 CAD 답변은 모두 같은 표의 다른 행 값인 ROUGE-L 25.8과 31.8, factKB 87.8을 XSUM 결과로 제시하였다. CAD 답변에서 정답과 같은 값은 일반 디코딩의 factKB 47.7과 BERT-P 87.1뿐이었지만, 근거 충실도는 0.526에서 0.867로 올랐다. RAPTOR가 문서를 100토큰 단위로 나누는 규칙을 묻는 질문에서도 CAD 답변은 트리 구축 비용이 문서 길이에 선형으로 늘어난다는 다른 내용을 설명하였고, 근거 충실도는 0.250에서 1.000으로, 답변 관련성은 0.000에서 0.755로 올랐다. 근거 충실도는 답변의 주장이 입력 구간에 있는지를 평가하므로, 입력 구간의 다른 행이나 다른 문단을 옮긴 답변도 높은 점수를 받는다.

개념과 결과 질문에서는 CAD가 이미 정확했던 답변을 짧게 바꾼 경우가 있었다. RAG Survey에서 지식 집약 과제에 RAG가 주는 이점을 묻는 질문에서 미적용 답변은 실시간 지식 갱신과 외부 지식 활용을 원문 인용과 함께 정리하였다. 같은 입력 구간에서 CAD 답변은 ‘위 내용 참조’와 요청 문장 조각만 남겼고, 근거 충실도는 0.938에서 0.500으로, 답변 관련성은 0.900에서 0.000으로 내려갔다. 처리 시간도 22.556초에서 3.975초로 줄었다.

HyDE와 CAD를 함께 적용하면 HyDE 단독에서 얻은 설명이 사라진 경우도 있었다. RAG Survey에서 Naive RAG의 처리 과정을 묻는 질문에서 미적용, HyDE, HyDE+CAD의 세 조건은 모두 색인, 검색, 생성의 세 단계를 담은 구간을 입력받았다. 미적용 답변은 파인튜닝과 프롬프트 공학을 비교한 영어 원문을 이어 쓴 뒤 다른 질문을 스스로 만들었고(관련성 0.747), HyDE 답변은 세 단계를 한국어로 설명하였다(관련성 0.929). HyDE+CAD 답변은 Modular RAG의 새 모듈을 묻는 질문을 만든 뒤 그 내용을 설명하여 관련성이 0.000이 되었다.

SCD를 적용한 뒤에도 한국어 문자 비율이 낮게 남은 답변은 영어 원문을 이어 쓴 경우였다. RAG Survey에서 큰 청크와 작은 청크의 장단점을 묻는 질문에서 미적용 답변은 참고문헌 목록을 이어 쓴 뒤 RAG의 세 구성요소를 한국어로 설명하였고, SCD 답변은 영어 참고문헌만 이어 써 비율이 0.425에서 0.000으로 내려갔다. 두 답변 모두 질문한 장단점 대신 다른 내용을 담았다. 부록 B에는 이 절에서 다룬 질문의 정답 근거와 답변 발췌를 정리하였다.

## 5.8 질문 유형에 따른 기법 선택 [스타일=절(1.1)]

질문 유형별 결과를 정리하면 유형마다 적합한 기법이 달랐다. 방법 질문에는 HyDE가 가장 효과적이었다. 답변 관련성이 0.575에서 0.745로, 문맥 재현율이 0.960까지 올랐고, 관련성 0점이던 질문 5개 가운데 3개는 질문에 필요한 정보를 담은 설명으로 바뀌었다.

수치 질문에서 HyDE 조건의 답변 관련성은 0.743에서 0.740으로 비슷하였고 문맥 정밀도와 재현율은 낮아졌다. 근거 충실도는 SCD를 적용하지 않은 CAD와 HyDE+CAD, SCD를 적용한 HyDE+CAD+SCD에서 0.896에서 0.927 사이였지만, 처리 시간은 14.648초에서 55.410초로 늘었고 다른 행의 수치를 옮긴 답변도 높은 충실도를 받았다. 수치 질문의 답변 품질은 정답 수치가 담긴 구간이 입력에 들어오는지와 답변이 그 값을 정확히 옮기는지에 달려 있었다.

개념과 결과 질문은 미적용에서 이미 점수가 높았고, HyDE가 답변 관련성과 근거 충실도를 조금 더 높였다. CAD는 이 유형에서 두 지표를 모두 낮추었으므로, 개념과 결과 질문에는 미적용이나 HyDE가 적합하다. SCD는 세 유형 모두에서 한국어 문자 비율을 높였으므로 한국어 답변이 필요할 때 유형과 관계없이 더할 수 있다.

두 기법 이상을 결합한 네 조건의 답변 관련성은 모두 HyDE 단독보다 낮았고, HyDE에 CAD를 더하면 관련성이 내린 질문(18개)이 오른 질문(5개)보다 많았다. 따라서 적용할 기법은 우선하는 지표에 따라 정해야 한다. 답변 관련성은 HyDE 단독이 0.763으로 가장 높았고 처리 시간은 6.877초만 늘었으므로, 관련성이나 응답 시간이 중요하면 HyDE 하나가 유리하다. 수치 질문에서 근거 충실도가 중요하면 HyDE+CAD가 네 품질 지표를 모두 미적용 이상으로 유지하며 충실도를 0.927까지 높였지만, 한국어 문자 비율은 0.520으로 낮았다. 반대로 한국어 답변에서 검색 근거, 충실도, 관련성을 고루 지켜야 하면 세 기법을 모두 적용하는 구성이 맞다. SCD를 적용한 조건 가운데 HyDE+CAD+SCD는 전체 평균의 근거 충실도와 문맥 재현율이 SCD 단독보다 높았고, 방법 질문에서는 근거 충실도, 문맥 정밀도, 문맥 재현율이 모두 SCD 단독보다 높았다. 이 균형의 대가는 SCD 단독의 약 3.5배인 처리 시간이다.

CAD는 원 논문에서 모델의 사전 지식과 입력 문서가 충돌하는 과제에서 효과가 컸다. 이번 60개 질문은 모두 대상 문서에 적힌 내용으로 답하는 질문이며, 미적용 조건의 근거 충실도도 0.791로 높았다.


# 6. 결론 [스타일=장(1.)]

본 연구는 Paper-RAG에 HyDE, CAD, SCD를 조합한 여덟 조건을 같은 질문 60개에 적용하고, 조건별 원점수, 질문 유형별 결과, 점수가 크게 바뀐 질문의 답변을 분석하였다.

## 6.1 연구 질문별 결과 [스타일=절(1.1)]

RQ1. 답변 관련성은 HyDE(0.763), 한국어 문자 비율은 HyDE+SCD(0.807)가 가장 높았고, 근거 충실도는 HyDE+CAD(0.860)가 SCD 미적용 조건에서, HyDE+CAD+SCD(0.831)가 적용 조건에서 가장 높았다. 두 기법 이상을 결합한 네 조건의 답변 관련성은 모두 HyDE 단독보다 낮았고, 조합이 일관되게 높인 지표는 SCD를 포함할 때의 한국어 문자 비율이었다. CAD를 포함하면 처리 시간이 약 세 배였다(표 5-1).

RQ2. HyDE는 방법 질문의 답변 관련성을 0.575에서 0.745로, 문맥 재현율을 0.880에서 0.960으로 높였고, 수치 질문의 관련성은 비슷하였다. CAD는 수치 질문과 방법 질문의 근거 충실도를 높였지만 개념과 결과 질문에서는 충실도와 관련성을 모두 낮추었다. SCD는 세 유형 모두에서 한국어 문자 비율을 높였다. 방법 질문에서는 HyDE+CAD+SCD가 SCD 적용 조건 가운데 유일하게 검색 결과를 쓰는 세 지표를 모두 SCD 단독보다 높였다(표 5-2).

RQ3. 방법 질문에서 크게 오른 답변은 HyDE로 필요한 구간을 찾거나 같은 구간을 질문에 맞게 설명한 경우였고, 관련성이 양수로 바뀐 다섯 답변 중 둘에는 요구 정보가 없었다. 수치 질문의 큰 하락은 정답 수치가 담긴 구간이 입력에서 빠진 경우였고, CAD의 높은 근거 충실도에는 다른 행이나 다른 문단을 옮긴 답변도 포함되었다. 개념과 결과 질문에서는 CAD가 정확한 설명을 짧은 지시문으로 바꾼 경우가 있었다(5.7절).

## 6.2 연구의 의의와 적용 조건 [스타일=절(1.1)]

이 연구는 세 기법을 같은 파이프라인과 질문에 적용하여, 같은 기법도 질문 유형에 따라 이득과 손실이 달라짐을 보였다.

답변 관련성이나 응답 시간이 중요하면 HyDE 하나를 적용하고, 개념과 결과 질문에도 HyDE가 적합하다. 수치 질문은 정답 수치가 담긴 구간이 검색되는지를 먼저 확인하고, 근거 충실도가 중요하면 HyDE+CAD를 사용한다. 한국어 답변이 필요하면 SCD를 더하며, 이때 방법 질문처럼 검색 근거와 충실도를 고루 지켜야 하는 질문에는 세 기법을 모두 적용한다.

## 6.3 후속 연구 [스타일=절(1.1)]

이번 결과는 영어 문서 네 종, 한국어 질문 60개, 생성 모델 한 종에서 질문과 조건마다 답변을 한 번 생성하고 평가한 기록이다. 첫째, 허위 전제나 지식 충돌을 담은 질문 그룹을 추가하여 CAD의 효과를 문서 내용을 묻는 질문과 비교한다. 둘째, 수치 질문에서 정답 수치가 담긴 구간이 검색되었는지와 답변이 그 값을 정확히 옮겼는지를 함께 평가한다. 셋째, 같은 질문의 생성과 평가를 반복하여 질문별 점수의 변동을 측정한다. 넷째, 번역만 적용한 조건을 추가하여 HyDE의 효과를 번역과 가상 문서 생성으로 나눈다. 다섯째, 모든 조건을 같은 언어의 검색 결과로 다시 평가하여 SCD가 근거 충실도와 검색 지표에 주는 영향을 확인한다.
