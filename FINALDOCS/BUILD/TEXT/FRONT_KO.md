# 졸업자격실험보고서 [스타일=논문제목]

한국어 질의로 영어 학술 및 기술 문서를 검색하는 RAG에서의 HyDE, CAD, SCD 조합 실험 [스타일=논문제목]

[학생명 입력], [학번 입력], 지도교수 [지도교수 입력], 제출일 [제출일 입력]

# 제출 페이지 [스타일=목차제목]

본 보고서를 [소속 대학 입력] [소속 학과 입력] 졸업자격실험보고서로 제출한다.

제출자: [학생명 입력]  /  학번: [학번 입력]  /  지도교수: [지도교수 입력]  /  제출일: [제출일 입력]

# 인준 페이지 [스타일=목차제목]

위 보고서를 졸업자격실험보고서로 인준함.

지도교수: [지도교수 입력] (인)  /  심사위원: [심사위원 입력] (인)  /  인준일: [인준일 입력]
