# 표지·제출·인준 페이지 입력 체크리스트

2026-10-09 제출 감사 기준. 이번 요청에는 아래 실제 값이 제공되지 않았다. 다른 문서나 계정에 표시된 이름·학번을 개인 정보의 근거로 전용하지 않았다. 학교 양식의 예시 학과·대학·캠퍼스도 사용자 소속으로 확정하지 않았다.

| 항목 | 현재 상태 | HWPX 입력 위치 | 사용자가 확인할 값 |
|---|---|---|---|
| 학생명 | 미입력 | 1쪽 `[학생명 입력]`, 2쪽 제출자 | 학교에 등록된 성명 |
| 학번 | 미입력 | 1~2쪽 `[학번 입력]` | 실제 학번 |
| 소속 학과 | 미입력·확인 필요 | 1쪽 `[소속 학과 입력]`, 2쪽 제출 문장과 하단 | 공식 학과명 |
| 소속 대학·캠퍼스 | 미입력·확인 필요 | 1쪽 `[소속 대학·캠퍼스 입력]`, 2쪽 대학·학과 입력란 | 공식 대학·캠퍼스명 |
| 지도교수 | 미입력 | 1~2쪽 `[지도교수 입력]` | 실제 지도교수 성명 |
| 제출일 | 미입력 | 1~2쪽 `[제출일 입력]` | 실제 제출일 |
| 인준일 | 미입력 | 2쪽 `[인준일 입력]` | 학교가 정한 인준일 |
| 심사위원 | 미입력 | 2쪽 `[심사위원 입력]` | 실제 위원 성명·인원, 학교 요구 서명·날인 |
| 제출연도 | 미입력 | 1쪽 `[제출연도 입력]` | 실제 제출연도; 현재 날짜만으로 확정하지 않음 |

입력 후 동일 항목이 두 페이지에 반복된 위치를 모두 확인한다. 학교 원본의 두 표지 배치표, 크기·여백·스타일은 유지하였다. 실제 날짜나 위원 수를 넣은 뒤 줄바꿈·공간을 확인하고 저장·재열기·PDF 내보내기를 수행한다. 본문이 이동하면 목차·그림목차·표목차도 새 PDF와 대조한다. 이 입력과 필요한 서명·인준을 마치기 전에는 행정적으로 제출이 완료된 문서라고 표시하지 않는다.
