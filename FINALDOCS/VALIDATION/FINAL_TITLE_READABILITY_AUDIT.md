# 제목 통일 및 포스터 가독성 최종 점검

확정 제목: **한국어 질의–영어 학술·기술 문서 RAG에서의 HyDE·CAD·SCD 조합 실험**

논문 국문 제목과 영문 제목을 표지·제출 페이지·HWPX 생성기·검증기까지 통일하였다. 본문 문장은 그대로 유지했다. 실제 웹한글에서 공개용·제출용 HWPX를 열고 PDF를 각각 다시 내보냈다. 두 PDF 모두 55쪽이며 변경된 쪽은 표지와 제출 페이지 1·2쪽이다. 나머지 53쪽은 기존 승인 PDF와 픽셀이 같았다. 목차 점선과 77개 페이지 항목도 유지했다.

포스터의 01 배경, 03 질의 구성, RQ4 문구는 사용자가 제시한 B의 뜻과 표현을 반영했다. 질의 구성의 긴 설명은 세 줄로 나눴다. 제목 44→52pt, 절 제목 20→24pt, 주요 본문 12~16.5→18pt, 참고문헌 11→16pt로 확대했다. 그림 내부의 설명은 16pt다. 작은 인쇄 규격 표기는 발표 본문과 구분한다.

04 평가 방법은 RAGAS 네 지표, SCD 평가 문맥 번역 차이, 비교 조건과 유효 표본을 남기고 중복 설명을 줄였다. 05 결과표와 두 신뢰구간 그림을 확대했다. 06 출력 사례는 CAD 감소 사례와 SCD 언어 변화 사례를 크게 제시하며, 원래 사례 전체는 POSTER_CASES_FULL.md에 보존했다. 08은 주요 문헌 6편을 짧게 표시하고 전체 22편은 POSTER_REFERENCES_FULL.md에 보존했다. 두 동봉 파일은 배포 ZIP에도 포함한다.

핵심 수치 +0.0805, +0.0288, +0.2182, +0.2289와 신뢰구간을 유지했다. CAD 근거 충실도의 95% 신뢰구간 [-0.0367, +0.0934]은 0을 포함한다. SCD의 HyDE OFF 동일 문맥 120쌍과 H/C 상태 일치 전체 240쌍을 구분했다. 평가 질의 60개·8조건·생성 기록 480개도 유지했다.

공개 포스터의 학번 표시 질문에는 답이 없어 공개본의 학번을 생략하는 기준을 알린 뒤 적용했다. 제출용 포스터에는 확인된 이름과 학번을 유지한다. 제출용 논문과 포스터는 다운로드 폴더에만 둔다. 과거 Git 커밋의 개인정보는 이 작업에서 이력을 바꾸지 않았다.

검증: HWPX 320개 순서 문단·1,092개 XLSX 셀·표 17·그림 22·수식 10·참고문헌 22, 본문 검토 593개 단위. HWPX 회귀 테스트 14개와 문체·출처·인쇄 검증 29개 통과. 수정 Python Ruff·Black 통과. 포스터 PPTX 1쪽·네이티브 표 7개·차트 2개와 두 내장 Excel의 수치·수식은 기존 파일과 일치했다. 구조·배치 검사 및 Artifact Tool 가져오기·렌더링을 통과했다.

검증 명령:
- python -X utf8 FINALDOCS/VALIDATION/verify_finaldocs_60q.py
- python -X utf8 FINALDOCS/BUILD/verify_thesis_hwpx.py (공개·제출본 각각)
- python -X utf8 -m unittest discover -s FINALDOCS/BUILD -p 'test*.py'
- python -X utf8 -m unittest discover -s FINALDOCS/VALIDATION -p 'test*.py'
- python -m ruff check (수정한 Python 5개)
- python -m black --check (동일 5개)
- python -m compileall (HWPX 생성·검증 및 포스터 출력)
- 포스터 출력 재생성, PPTX 패키지·배치·차트 내장 통합문서 검증

인준일과 주심·부심은 미정 입력 칸을 유지한다. 실물 인쇄의 색상·재단과 1~2m 거리 가독성은 실제 인쇄 확인이 필요하다. PowerPoint 데스크톱을 열었다고 주장하지 않으며, 네이티브 구조와 렌더링 결과를 검증했다. 최종 Git SHA와 CI 결과는 커밋 후 별도 기록한다.
