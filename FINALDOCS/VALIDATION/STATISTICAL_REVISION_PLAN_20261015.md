# 지도교수 피드백 통계 재분석 계획

기준 커밋: d4931ec76f591016b2601561d17fbd37ac2a833a. 2026-10-15 수정 단계에서 정한 분석 계획이다. 기존 결과를 열람한 뒤 수립했으므로 사전 등록된 확증 분석으로 표기하지 않는다.

- 분석 단위: 질의 60개. 질의마다 8조건을 측정했다. 120/240개 SCD 대응쌍은 질의별 평균 차이 60개로 집계해 검정한다.
- 유의수준: 양측 0.05. 원자료에서 산출한 비유의 결과도 함께 보고한다. 결과나 결측값을 변경하지 않는다.
- 기술통계: 원정밀도 평균과 표본 SD(ddof=1). 표시 단계에서 소수점 세 자리로 반올림한다.
- RAGAS: S0 영어 문맥 및 S1 한국어 번역 문맥을 나누어 H×C 반복측정 ANOVA를 수행한다. 프로토콜을 교차하는 SCD 품질 효과는 검정하지 않는다.
- 문자 비율과 조건 실행 시간: H×C×S 반복측정 ANOVA. 각 효과의 자유도는 (1,n−1)이다. 각 질의 내 직교 대비의 t²와 statsmodels AnovaRM의 F를 대조한다.
- 결측: 지표별·분석 조건별 완전사례를 사용한다. 충실도는 S0 n=58, S1 n=57이다. 다른 지표는 n=60이다.
- 다중비교: RAGAS 요인 검정 전체 24개를 하나의 Holm 가설군으로 정한다. 문자 비율과 시간은 각각 7개 효과를 보정한다. HyDE/CAD 단순 비교는 각각 품질 지표 4개를 보정한다. SCD 문자 비율의 주·전체 비교 2개를 함께 보정한다. 보정 전후 p를 모두 보고한다.
- 효과크기: 반복측정 ANOVA의 부분 η², 대응 검정의 Cohen dz.
- 민감도: 질의 단위 부호 순열 100,000회(seed=20261015), 대응 비교의 Wilcoxon, 차이 분포 및 문서 하나씩 제외한 평균 차이. 네 문서를 고정한 질의 수준 분석으로 범위를 기술한다.
- 한글·ASCII 영문자가 없는 답변 1건: 기존 분석기의 문자 비율 0 기록을 재현하고 그 사실을 밝힌다. 해당 질의 전체를 제외한 n=59 민감도 분석도 보고한다. 새 0 대체 규칙을 추가하지 않는다.
- 분산이 0인 대비의 t/F/p/효과크기는 계산 불가로 명시한다. 임의로 0이나 p=1을 채우지 않는다.
- 재생성 및 추가 API 평가는 수행하지 않는다. 동일 입력에 대한 저장 평가값 차이는 입력 대조로 진단하고 반복 평가 분산을 측정한 결과로 확대하지 않는다.
