## 전체 평가와 교정 방법

## 수치·표·그림·참고문헌 정합성

`ACADEMIC_DATA_PRESERVATION.json`의 대조 결과: XLSX 17개 시트의 1,092개 셀, 시트 순서·크기·병합과 원본 파일 바이트를 보존하였다. 기존 XLSX와 `HWP_COPYPASTE_TABLES_60Q.txt`는 표 5-3/5-4의 증가·감소·동률 헤더가 이미 올바르므로 다시 작성하지 않았다. 영문 헤더가 남아 있던 Markdown 두 곳을 수정하고 HWPX 셀과 교차 검증하였다. n과 모든 수치는 동일하다.

원고의 28개 수식/표 탭 블록은 두 헤더 변경 외에 동일하다. 문서 4개×질의 15개=60개, 조건 8개, 생성 기록 480개, 별도 튜닝 5개, 검색 8·재정렬 8·문맥 5를 유지하였다. 주요 결과 +0.0805, +0.0288(58쌍), +0.2182(120쌍), +0.2289(240쌍)와 구간·부호·소수점은 기존 저장 평가·분석 자료에 대한 검증을 통과하였다. 실험 원자료 7개의 manifest 검사도 유지하였다. 모델/API/RAGAS 호출, 검색·생성·평가 재실행은 하지 않았다.

정식 제목 전체를 비교하여 그림목차 22개와 본문 22개, 표목차 17개와 본문 17개의 일치를 검사한다. 그림 5-4는 ‘HyDE와 CAD의 주 대응 비교’이며 신뢰구간 설명은 별도 문단으로 보존했다. 그림 2-1~2-6은 제목 다음에 출처 문장을 배치했다. 원문 도표를 영역 잘라내기로 렌더링한 발췌이며 재구성 그림이 아니다. 2-6은 Es 외[9]의 **표 2**이다. 원본 PNG와 입출력 원문은 보존하였다.

라이선스의 확인 근거와 소스 버전별 상태는 [문헌 그림 README](../FIGURES/LITERATURE/README.md)에 기록했다. CAD의 ACL 자료와 SCD·RAGAS arXiv 자료의 CC BY 4.0에는 저자/문헌/원 도표 번호, 잘라내기와 라이선스 URL을 본문에 표시하였다. 기존 RAG·긴 문맥·HyDE arXiv 발췌본 3개는 별도 재사용 허용 범위를 확정하지 못해 **UNRESOLVED**로 남겼다. arXiv 배포 허가를 일반적인 그림 재사용 허가로 간주하지 않았다. 확인하지 않은 법적 예외나 학회판과의 그림 동일성을 가정하지 않았다.

## HWPX·PDF 반영 및 검토

학교 변환본을 바탕으로 재생성하였다. A4·1단·용지 여백, 함초롬바탕 10pt·본문 160%, 원본 19개 스타일과 글꼴/글자/문단 정의는 XML 정규화 대조로 보존했다. 표 17개와 표지 배치용 표 2개, 그림 22개, 네이티브 수식 10개, 참고문헌 22편을 구분하여 검사했다. 원고의 의미 문단 318개는 순서와 정확한 출현 횟수로 대조하였다.

현재 교정본을 한컴독스에 업로드하고 재열어 편집 메뉴·문서 편집 영역과 교정된 표/그림 5-4를 확인했다. 업로드 파일은 저장된 상태이며 파일 메뉴의 ‘저장하기’는 변경 내용이 없는 상태로 비활성임을 확인했다. **파일→PDF로 다운로드**로 최종 PDF를 실제 생성하였다. 이번 교정은 생성 원고에서 수행했으며, 이전 시험본의 문단·표 셀 수정/저장/재열기 결과는 기존 호환성 시험 기록이다. 이번 확인으로 모든 수식 편집 대화상자를 새로 시험했다고 주장하지 않는다.

새 출력은 **55쪽**이다. 이전 57쪽을 그대로 사용하지 않고 모두 렌더링하여 검토했다. 절 제목이 이전 쪽 끝에 홀로 남던 4.3·5.3·6.3에 원고의 명시적 쪽나눔을 반영하고 24·27·41쪽에서 본문과 함께 시작함을 확인했다. 단락 스타일을 바꾸지 않았다. 단독 쪽나눔/잘못된 위치는 빌드가 실패하고 누락은 HWPX 검증·훼손 시험이 실패한다.

쪽지도는 새 PDF의 고유 본문 앵커와 육안 확인으로 다시 작성했다. PDF 텍스트 추출로 위치가 확정되지 않은 16개 제목은 `visual_overrides`에 실제 쪽을 기록했다. 쪽번호 반영 후 다시 웹한글에서 출력했으며, 변경된 쪽은 목차·그림목차·표목차 **5~8쪽뿐**이고 나머지 51쪽은 검토 기준 출력과 픽셀 단위로 동일하였다. 5~8쪽의 번호·제목·정렬도 직접 확인했다. 부록 A는 44~50쪽, 부록 B는 51~55쪽이다.

최종 PDF SHA-256: `a4178631f7531d4cfaa00e63166eb36044fc26cfab1300f4ac1ff91e6b92a61d`. 쪽지도와 파일 해시 목록에 실제 출력 해시를 기록하였다. 이전 HWPX는 자동으로 `DELIVERY/versions/<UTC시각>/`에 보존하고, 이전 57쪽 PDF와 쪽지도도 `versions/`에 별도로 보존하였다. 버전 보관 디렉터리는 Git 제외 대상이다.
