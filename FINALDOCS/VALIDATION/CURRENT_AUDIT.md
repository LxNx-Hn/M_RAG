# 현재 제출본 검증

기준은 2026-10-27 문장 정리본(v27)이다. 480개 생성 기록과 1,920개 RAGAS 평가값(결측 5개), 480개 처리 시간은 원자료 그대로이며, 분석은 조건별 평균(표준편차), 수치, 방법, 개념과 결과의 세 질문 유형별 평균, 질문별 변화로 구성한다. 원분류 네 유형(8, 29, 20, 3개)은 분류 표에 보존한다.

분석 기준은 다음과 같다. 근거 충실도, 문맥 정밀도, 문맥 재현율은 SCD 미적용 조건(영어 검색 결과)과 적용 조건(한국어 번역 검색 결과) 안에서만 비교하고, 답변 관련성과 한국어 문자 비율은 여덟 조건 전체에서 비교한다. 처리 시간은 각 생성 실행의 첫 기록(track1_0009, ext_rag_001)을 모든 조건에서 뺀 58개 질문으로 계산한다. 관련성 0점은 평가 모델의 판정값으로만 기술하며, 미적용에서 0점이던 방법 질문 5개의 HyDE 답변 가운데 요구 정보를 담은 답변은 3개다.

논문은 한컴독스 `M_RAG_QUESTION_GROUPS_20261027_v27.hwpx`와 같은 파일이며 한컴 내보내기 기준 49쪽이다. 장 시작은 1, 3, 7, 9, 12, 25쪽, 참고문헌 26쪽, 그림 자료 이용 정보 28쪽, 부록 A 30쪽, 부록 B 40쪽이다. 논리 표 6개(본문 표 개체 15개), 그림 12개, 편집 수식 8개, 참고문헌 22편이다. v23 초안 내보내기에서 14쪽 하단 빈 공간과 6장 넘침을 확인하고 표 5-1 위치와 6장 문장을 고쳤다. v24에서 단일 기법이 최고인 지표를 답변 관련성으로 한정하고, 답변 길이와 문서별 변화의 집계 기준을 밝혔다. v25에서 표 주석의 주 라벨을 없애고, 질의와 질문 및 입력 구간을 정의하고, 약어를 첫 등장에서 풀어 쓰고, 그림 4-2를 2행 2열로 바꾸었다. v25 첫 초안에서 5.8절이 넘친 것을 확인하고 중복 문장 세 개를 덜어 49쪽을 유지하였다. 본문에 쓰지 않는 평행좌표 그림 14개는 `HISTORY/20261025_unused_figures/`로 옮겼다. v26에서 교수 지시(10-18 녹취, AC-41)대로 논문의 결과 수치를 모두 소수점 세 자리로 바꾸었다. 표 5-1과 표 5-2, 본문과 부록 B, 그림 4-2와 그림 5-2의 값을 원자료에서 다시 계산하였고, 세 자리에서 달라진 두 비교는 같다는 표현을 비슷하다로 고쳤다. 포스터는 10-20 녹취의 지시대로 두 자리를 유지한다. v27에서 비교 기준이 빠지거나 평가하는 말투인 문장, 5.2절의 조건별 관련성 0점 개수, 5.8절 수치 질문의 처리 시간 범위, 질의와 처리 시간과 검색 지표 용어를 22곳에서 정리하고, 넘친 6장을 25쪽에 맞추었다. 기록은 `EDITOR_REVIEW_20261021.json`과 `EDITOR_EVIDENCE_20261021/`에 있다.

제출용 포스터(B 구성)는 A1 세로 594×841 mm이며 01 연구 배경과 목적, 02 파이프라인, 03 예시 질문 그림(패널마다 미적용과 단독 적용 비교), 04 질문과 평가(다섯 지표의 측정 내용과 값의 방향을 담은 정의표 포함), 05 편집 가능한 유형별 평균 가로 표, 06 방법 질문 25개의 평행좌표(전체 폭, 네 조건 패널 한 줄), 07 결론(전체 폭 두 열)으로 구성한다. 2026-10-27 교수 피드백에 따라 지표 정의표를 되살리고 실제 답변 사례 영역을 뺐다. 가로 표의 굵은 값은 논문 표와 같은 기준이다. 비교용 A 구성은 파이프라인 도식 없이 같은 내용을 담는다. 가운뎃점, 화살표, 콜론 설명, 표준편차, 통계 검정 용어가 없는지, 정의표의 지표가 결과표와 같은 이름과 순서이고 값의 방향을 모두 적었는지 `poster_checks.py`가 검사한다.

검증 명령은 `python -X utf8 -m FINALDOCS.VALIDATION.validate_all`이다. 독립 계산은 조건별 평균과 표준편차, 유형별 평균, 질문 유형과 문서의 조합별 평균 변화, 4,320개 질문별 차이, 사례 근거 37개를 원자료에서 다시 계산하고, 검색 결과를 쓰는 세 지표가 평가 언어를 넘어 비교되지 않는지와 굵은 표시 범위를 확인한다.
