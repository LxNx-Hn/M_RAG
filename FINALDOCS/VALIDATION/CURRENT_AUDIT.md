# 현재 제출본 검증

기준은 2026-10-21 질문 유형별 분석 개정본이다. 480개 생성 기록과 1,920개 RAGAS 평가값(결측 5개), 480개 처리 시간은 원자료 그대로이며, 분석은 조건별 평균(표준편차), 수치, 방법, 개념과 결과의 세 질문 유형별 평균, 미적용 대비 질문별 변화로 구성한다. 원분류 네 유형(8, 29, 20, 3개)은 분류 표에 보존한다.

논문은 한컴독스 `M_RAG_QUESTION_GROUPS_20261021_v11.hwpx`와 같은 파일이며 한컴 내보내기 기준 47쪽, 본문 표시 1~41쪽이다. 장 시작은 1, 3, 7, 9, 11, 23쪽, 참고문헌 24쪽, 그림 자료 이용 정보 26쪽, 부록 A 28쪽, 부록 B 38쪽이다. 논리 표 6개(본문 표 개체 15개), 그림 11개, 편집 수식 8개, 참고문헌 22편이다. v1~v10 내보내기를 쪽별로 확인하며 빈 공간과 배치를 수정했고, 편집 화면에서 표 5-2, 그림 5-4, 5.6절(17쪽)을 확인했다. 기록은 `EDITOR_REVIEW_20261021.json`과 `EDITOR_EVIDENCE_20261021/`에 있다.

포스터는 A1 세로 594×841 mm이며 편집 가능한 표 5개(조건 범례, 지표 설명, 조건별 평균, 유형별 평균, 단일 기법 시간)와 방법 질문 25개의 평행좌표를 담는다. 가운뎃점, 화살표, 콜론 설명, 표준편차, 통계 검정 용어가 없는지 `poster_checks.py`가 검사한다.

검증 명령은 `python -X utf8 -m FINALDOCS.VALIDATION.validate_all`이며 8개 묶음이 모두 통과했다(검사 30+25개). 독립 계산은 조건별 평균과 표준편차, 유형별 평균, 5,040개 질문별 차이, 사례 근거 37개를 원자료에서 다시 계산한다.

개인 제출 정보와 인준일, 심사위원, 날인은 공개 편집본에 비워 둔다. 실물 인쇄와 A1 거리별 판독은 추가 확인 대상이다.
