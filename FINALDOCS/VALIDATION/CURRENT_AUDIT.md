# 현재 제출본 검증

기준은 2026-10-20 질문 유형별 분석 개정본이다. 사실·정의 8개, 방법·절차 29개, 결과·비교 20개, 목적·기여 3개의 원분류와 480개 생성 기록을 유지한다. 결과는 같은 평가 언어의 질문별 대응 비교, 평균·변화량·개선/악화/비슷함 및 실제 질문·입력 구간·답변으로 설명한다.

관련성은 두 조건 중 하나라도 0점이면 해당 비교의 평균과 개수에서 제외한다. 원점수와 0점 전환 사례는 그대로 보존한다. 충실도 결측 5개도 대응하는 양쪽 평균에서 함께 제외한다. 독립 검증기는 저장된 원자료로 제외 여부, 유효 질문 수와 계산을 다시 대조한다.

현재 논문은 한컴독스 v14이며 내보내기 기준 48쪽, 본문 표시 1~42쪽이다. 장 시작은 1·3·7·8·10·24쪽, 참고문헌 25쪽, 그림 자료 이용 정보 28쪽, 부록 A 29쪽, 부록 B 39쪽이다. 표지와 목차에는 쪽 번호를 표시하지 않는다. 논리 표 9개를 18개 본문 표 개체로 배치하고, 그림 11개·편집 수식 8개·정식 참고문헌 22편을 확인한다.

배치 확인의 기준은 한컴독스 편집 화면이다. v9 전체 화면, v13 본문 13~28쪽, v14 목차와 변경된 표·본문·모델 출처 및 최종 그림을 검토했다. 버전별 범위와 증거를 `EDITOR_REVIEW_20261020.json`에 기록한다. PDF는 같은 한컴 문서에서 내보낸 쪽번호·텍스트 연결 및 변경 위치 확인용 보조 자료다. 실제 산출물 해시는 `ARTIFACT_MANIFEST.json`과 `DELIVERY/PAGE_MAP_60Q.json`을 따른다.

포스터는 A1 세로 594×841 mm다. 04는 HyDE 관련성·CAD 충실도·SCD 한국어 문자 비율의 유형별 변화, 05는 조합 비교를 제시한다. 08은 HyDE의 전체 60개 질문을 원분류 네 패널로 나눠 보여준다. 논문은 HyDE·CAD·SCD를 별도 그림으로 제시한다. 선 하나는 질문 하나이며 여섯 지표를 연결한다. 시간은 실제 초 단위의 공통 역방향 축(위 0초, 아래 180초)이다. 사용자가 선택한 표시 정책에 따라 모든 지표의 0점은 해당 축에서 선을 끊는다. 원자료와 표 계산은 유지한다. 설명은 문장으로 작성하고 편집 가능한 표는 6개다.

검증 명령은 `python -X utf8 -m FINALDOCS.VALIDATION.validate_all`이다. 독립 계산, 원자료 보존 해시, 학교 양식·표 셀·부록 행·도식·수식, 쪽 지도, 포스터와 화면 검토 기록을 함께 확인한다. 이번 커밋의 원격 CI 결과는 별도로 확인한다.

개인 제출 정보와 인준일·심사위원·날인은 공개 편집본에 비워 둔다. 실물 인쇄와 A1 거리별 판독은 추가 확인 대상이다. 포스터 내보내기에 사용한 설치형 PowerPoint 실행 기록은 `POSTER/FINAL/README.md`를 따른다.

최신 실행 결과는 `tmp/query-revision/thesis-v14-filled/validation/VALIDATION_RESULT.json`에 저장한다. 이전 v10 검증은 51개 회귀 검사였으며, 최신본은 0점 표시·시간 축·전체 질문 보존·SVG 이미지 무손실 재인코딩의 회귀 검사 4개를 추가했다. 최종 쪽 지도로 학교 원본에서 HWPX를 재생성하여 구조·셀 검사를 별도로 수행한다.
