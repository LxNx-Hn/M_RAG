## 구성과 글자

594×841mm A1 세로 1쪽, 기존 보라색 제목 띠와 01–08 구획을 유지한다. 제목 52pt, 구획 제목 24pt, 본문과 표 18pt, 주요 참고문헌 16pt를 기준으로 한다. 공간이 부족하면 설명을 줄이고 표의 숫자와 비교 조건을 유지한다. 도형·텍스트·표는 편집 가능하게 만들고, 본문을 통째로 이미지로 넣지 않는다.

01 RAG의 정식 명칭과 작동 원리, 세 기법의 정식 명칭과 역할을 설명한다. 한국어 질문에 맞는 영어 근거를 찾아 한국어로 답변하는 과정의 평가 필요성을 제시하고, 같은 파이프라인에서 조합을 비교하는 목적을 연결한다. 독립적인 초록 영역은 두지 않는다.
02 큐브 대신 한국어 질의→HyDE 적용 여부→BGE-M3·BM25→가중 RRF→CrossEncoder 재정렬→Mi:dm 생성의 기능별 흐름을 그린다. CAD와 SCD의 적용 위치를 표시한다.
03 H=HyDE, C=CAD, S=SCD, 0=미적용·1=적용을 정의하고 8개 조건을 표로 제시한다. 영어 문서 4종×문서별 질의 15개×8조건=480개 생성 기록이다.
04 지표 정의, 점수 방향과 단위, 실제 평가 사례, 평가 환경, 통계 방법 순서로 구성한다. 품질 관측값의 0~1 범위와 관련성 차이 +0.080, 한국어 비율 0.700=70.0%, 차이 +0.218=+21.8%p를 구분한다. 답변 관련성의 이론적 코사인 범위는 −1~1이다. ext_raptor_011/H0C0S0의 질문에 대해 검색 근거의 “RAPTOR selects nodes from different layers”와 답변의 “질문의 요구사항에 따라 서로 다른 층위(layer)에서 노드를 선택할 수 있습니다.”를 발췌로 연결한다. 충실도 1.000은 평가자가 추출한 주장에 대한 검색 문맥의 지지, 관련성 0.937은 답변 기반 질문과 원질문의 평균 의미 유사도로 설명한다. 질의 구성 설명은 최종 60개 질의·원문 페이지·정답 근거의 검증 자료와 대조한다. 자료 가용 범위는 별도 기록을 따른다.
표 정렬은 데이터 유형별로 지정한다. 조건 코드와 H/C/S 부호는 가운데, 설명은 왼쪽, 평균(SD)·t·F·df·p·효과크기는 오른쪽에 맞춘다. PPTX와 SVG에 동일하게 적용하고 실제 PDF를 확대해 확인한다.

05 8조건 평균(SD), 한국어 비율·시간의 3요인 ANOVA, 주요 대응 비교 순서로 편집 가능한 표를 제시한다. 전체 평균표는 S0 네 행 뒤 S1 네 행을 배치하고 경계에 구분선을 넣는다. 실행 시간 단위는 초다. 전체 검정·결측·민감도 분석은 동봉 상세표를 안내한다.
06 HyDE의 양의 평균 차이와 보정 검정, CAD 질의별 변동과 추가 시간, SCD 문자 사용 비중 증가, 시간의 C×S 상호작용을 해석한다. 변동의 인과적 원인은 실제 측정 자료로 설명한다.
07 품질의 평균 차이와 보정 검정, 목표 한국어 비중, 허용 실행 시간을 기준으로 적용 조건을 제시한다. 05의 수치 재나열은 줄인다.
08 본문 번호와 같은 주요 참고문헌을 제시하고 전체 22편을 동봉한다.

## 수치와 통계

원자료와 검정 결과를 수정하지 않는다. 유의수준은 양측 0.05다. p<0.05를 맞추기 위해 표본을 제외하거나 분석법을 선택하지 않는다.

HyDE 답변 관련성: 차이 +0.080495, t(59)=2.236, 보정 전 p=0.029, Holm 보정 p=0.117. 소수 셋째 자리 표시는 +0.080이다.
CAD 근거 충실도: 차이 +0.028838, t(57)=0.862, 보정 전 p=0.393, 보정 p=1.000.
SCD 주 비교: H0 동일 문맥 120쌍을 질의별로 평균한 n=60, 차이 +0.218224, 보정 p<0.001. 전체 240쌍도 질의별 n=60이며 차이 +0.228941, 보정 p<0.001. 비율 차이 +0.218은 21.8%p다.

RAGAS의 S0는 영어 평가 문맥, S1은 한국어 번역 평가 문맥이다. 품질은 각 프로토콜 내 H×C로 분석하고 24개 검정 전체에 Holm 보정한다. 보정 p는 모두 0.05 이상이다. 한국어 비율·실행 시간은 각각 7개 검정을 보정한다. 품질 결측 5개는 완전 대응 질의만 사용하며 대체값을 넣지 않는다. HyDE ON의 temperature=0.1, top_p=0.9 샘플링과 검색 문맥 변화를 해석에 포함한다.

문체는 구체적인 대상·조건·행동을 직접 서술한다. 불필요한 부정·방어형 대조, ‘의의가 있다’의 반복, 과장된 우수성 표현을 줄인다. 실제 비유의 결과·결측·평가 문맥 차이는 정확하게 설명한다.
