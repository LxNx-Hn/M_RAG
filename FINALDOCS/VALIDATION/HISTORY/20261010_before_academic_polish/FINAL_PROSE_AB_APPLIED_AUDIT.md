### 01. 원래 제안 B

검색 증강 생성(Retrieval-Augmented Generation, RAG)은 외부 문서에서 질문과 관련된 내용을 검색하고, 이를 생성 모델에 제공하여 답변을 생성하는 방법이다. 한국어 질문으로 영어 학술 및 기술 문서를 검색하는 과정에서는 질문과 원문의 표현 차이가 검색 결과에 영향을 줄 수 있다. 또한 생성된 답변이 검색 근거에 의해 뒷받침되는 정도와 답변에 사용된 한국어의 비율을 구분하여 평가할 필요가 있다. 본 연구에서는 Hypothetical Document Embeddings(HyDE), Context-Aware Decoding(CAD), Soft Constrained Decoding(SCD)을 각각 검색 입력 변경, 문맥을 활용한 디코딩, 한국어 출력 제어에 적용하였다. 세 기법의 적용 여부를 조합하여 총 8개 조건으로 구성된 RAG-Cube 실험을 수행하였다.

최종 C는 위 표에 기록하였다. 이유: RAG 정의, 연구 환경, 평가 대상과 세 기법의 역할을 순서대로 설명한다. 실제 출력 언어 지표가 문자 비율임을 명시하였다.

### 02. 원래 제안 B

HyDE는 CAD와 SCD를 모두 OFF로 고정한 60개 대응쌍에서 비교하였다. CAD는 검색 문맥이 동일한 대응쌍에서 평가하였다. SCD는 HyDE를 OFF로 고정하고 검색 문맥이 동일한 120개 대응쌍을 주 비교로 사용하였으며, HyDE와 CAD의 적용 상태를 각각 맞춘 전체 240개 대응쌍도 분석하였다.

최종 C는 위 표에 기록하였다. 이유: B의 120쌍 주 비교 순서를 적용하고 CAD의 H0S0 고정 조건을 보존하였다.

### 05. 원래 제안 B

HyDE는 입력 질의를 바탕으로 가상 문서를 생성하고, 이를 벡터로 변환하여 관련 문서를 검색한다[2]. CAD는 문맥을 포함했을 때와 제외했을 때 계산한 다음 토큰의 점수를 비교하고, 그 차이를 이용해 생성 점수를 조정한다[3]. SCD는 토큰을 목표 언어, 다른 언어와 중립 토큰으로 구분하여 각 그룹의 점수를 조정한다[4].

최종 C는 위 표에 기록하였다. 이유: SCD의 중립 토큰에는 점수 변경을 적용하지 않으므로 B의 각 그룹 조정 표현을 바로잡았다.

### 06. 원래 제안 B

HyDE는 적용 전후 검색 문맥과 생성 답변의 변화를 함께 비교하였다. CAD는 검색 문맥을 동일하게 유지한 상태에서 답변 품질과 생성 시간을 비교하였다. SCD는 HyDE OFF 조건에서 검색 문맥이 동일한 대응쌍을 사용해 한국어 문자 비율의 변화를 분석하였다.

최종 C는 위 표에 기록하였다. 이유: 측정 시간은 검색부터 생성까지의 조건 실행 시간이므로 생성 시간이라는 B 표현을 수정하였다.

### 43. 원래 제안 B

HyDE의 후속 실험에서는 질의 번역, 가상 문서 생성과 밀집 검색 입력 변경을 별도의 실험 요인으로 구분하는 방향을 제안한다. 동일 질의를 반복해서 실행하면 가상 문서 생성에 따른 검색 결과의 변동을 분석할 수 있다. CAD는 α와 검색 문맥의 길이를 달리하여 근거 충실도, 답변 관련성과 생성 시간을 비교하는 방향을 제안한다. SCD에는 답변의 자연스러움, 번역 충실도, 내용 정확성과 전문용어 보존에 대한 사람 블라인드 평가를 추가하는 방향을 제안한다. 재정렬 단계에서는 현재 사용한 CrossEncoder와 다국어 재정렬 모델을 동일한 검색 후보에 적용하여 결과를 비교하는 후속 실험을 제안한다.

최종 C는 위 표에 기록하였다. 이유: 후속 연구를 현재 수행한 결과와 구분하고 동일 후보 재정렬 비교를 명시하였다. 생성 시간을 조건 실행 시간으로 고쳤다.

## 남아 있는 입력 및 배치 사항

인준일과 주심·부심 성명은 사용자가 아직 정하지 않았다고 답하여 입력 칸을 유지하였다. 실제 PDF 물리 24쪽은 그림 4-2 이후 다음 장의 시작을 위해 공간이 남고, 38쪽은 5.9절 뒤 6장 쪽나눔으로 여백이 남는다. 물리 55쪽에는 부록 B 표의 마지막 두 행이 있다. 학교 글자·행간과 원래 표 행을 유지한 조판이며, 이번 교정으로 생긴 빈 페이지나 글자 잘림은 확인하지 않았다. 공간을 줄이기 위해 글꼴을 줄이거나 수치를 삭제하지 않았다.

생성 코드와 실험 원자료는 수정하지 않았다. 개인정보를 넣은 HWPX/PDF와 로컬 필드 JSON은 공개 Git 인덱스에 포함하지 않는다. 공개 파일은 표지 입력 칸을 가진 별도 HWPX 및 실제 웹한글 PDF이다.

## 최종 출력의 독립 대조

실제 최종 개인 제출 PDF와 공개 PDF는 각각 55쪽이다. 개인본의 초안과 최종본은 목차 5~8쪽만 달라졌고 나머지 51쪽이 픽셀 단위로 같다. 개인본과 공개본은 표지 1~2쪽만 다르고, 본문·목차를 포함한 53쪽이 픽셀 단위로 같다. 최종 목차 4쪽과 공개 표지 2쪽을 확대 확인하였다. 목차 번호 77개는 네이티브 XML과 실제 제목·캡션 페이지 지도로 대조하였다. 웹한글 PDF의 목차 글자는 벡터 윤곽선으로 출력되어 텍스트 추출로 판정하지 않고 렌더링을 직접 확인하였다. 자세한 체크 및 해시는 `FINAL_PROSE_AB_CHECKS.json`에 기록하였다.

공개 HWPX의 표시 텍스트에는 원자료 질문의 가운데점 1자와 표지 입력 칸 명칭 `[소속 대학·캠퍼스 입력]`의 2자가 있다. 후자는 학교 표지 입력 안내의 명칭이며 작성한 논문 제목·본문에는 포함되지 않는다. 로컬 개인 제출본의 실제 소속은 확인된 대학명으로 들어가므로 해당 안내 문구는 없다. 목차 점선은 문자 삭제 대상에서 제외하고 원래 탭 리더를 보존하였다.

최종 웹한글 교정 화면은 `WEB_HANCOM_AB43_FINAL.png`에 보존하였다. 확인된 개인정보가 포함된 파일은 Git 인덱스에서 제외하고, 기존 로컬 제출 복사본 경로는 `.gitignore`에 명시하였다.

쪽번호 기록은 짧은 앞부분 검색이 아니라 최종 문단 전체의 시작·끝 위치를 기준으로 다시 대조하였다. 다른 절에서 같은 RAG 정의의 앞부분을 사용하는 경우와 다음 쪽으로 이어지는 문단을 구분하여 위 표의 물리 쪽수를 기록하였다. 실제 문장과 산출물은 변경하지 않았다.
