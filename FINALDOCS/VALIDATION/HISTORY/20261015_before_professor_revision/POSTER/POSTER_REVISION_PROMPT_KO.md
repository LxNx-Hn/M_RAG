# 최종 포스터 수정 및 유지 프롬프트

기준 파일은 동봉된 최종 SVG와 PPTX다. 제목은 “한국어 질의–영어 학술·기술 문서 RAG에서의 HyDE·CAD·SCD 조합 실험”로 고정하고, 보라색 제목 띠와 01~08 흐름, A1 세로 593.99×840.98mm를 유지한다.

다음 문구를 반영한 상태를 유지한다.
1. 연구 배경: “한국어 질의로 영어 문서를 검색했을 때의 검색 결과 분석”. 언어 표현 차이를 독립 실험 요인으로 분리해 검증한 것처럼 쓰지 않는다.
2. 질의 구성: “요약 내용을 15개 단위로 나누어 질의 작성 → 총 60개 질의의 원문 근거 확인”. 문서별 15개, 4종, 총 60개와 실제 생성 절차를 함께 유지한다.
3. RQ4: “평가 목적에 따라 답변 품질, 한국어 문자 비율과 실행 시간을 어떻게 비교할 것인가”. 근거 없는 최적 조합을 단정하지 않는다.

제목 52pt, 절 제목 24pt, 본문 18pt, 그림 설명과 주요 참고문헌 16pt를 기준으로 한다. 글이 넘치면 중복 설명을 줄이고 줄을 나눈다. 04에는 SCD OFF 영어 문맥 / ON 한국어 번역 문맥의 RAGAS 평가 차이를 명시하고, 답변 생성에는 영어 문맥을 사용했다는 조건을 남긴다. 05 결과표와 신뢰구간 그림은 크게 유지한다. 06의 CAD 감소 사례와 SCD 언어 변화 사례를 정확한 인용과 조건으로 표시한다. 다른 사례는 동봉 전체 기록에 보존한다. 08 주요 문헌 6편의 원래 번호를 유지하고 전체 22편을 동봉한다.

결과를 바꾸지 않는다: HyDE 관련성 +0.0805 [0.0110, 0.1514], CAD 충실도 +0.0288 [-0.0367, 0.0934], SCD 주 비교 120쌍 +0.2182 [0.1880, 0.2487], 전체 240쌍 +0.2289 [0.2051, 0.2532]. CAD 신뢰구간의 0 포함과 유효 충실도 58쌍을 표시한다. 한국어 문자 비율은 한글/(한글+ASCII 영문자)다. 한국어 질의 60개×8조건=480개 답변이다.

짧고 직접적인 한국어로 쓴다. 방어형 대비 문장, 추상적인 기여 표현, 근거 없는 성능 우위를 추가하지 않는다. 필요한 통계 해석과 평가 조건은 유지한다. 출력 인용문을 임의로 윤문하지 않는다.

제출용 상단의 확인된 학생·학과·지도교수·제출일 정보를 유지한다. 공개 GitHub 배포본에서는 학번을 생략한다. 표 7개와 차트 2개를 PPTX에서 계속 편집할 수 있어야 하며 내장 Excel 수치를 변경하지 않는다. SVG·PPTX·PDF·PNG의 제목·문구·결과를 맞추고 A1 1쪽, 300dpi 7016×9933, 글자 겹침과 잘림을 실제 렌더링으로 검사한다.
