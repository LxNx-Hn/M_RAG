# 평행좌표 의도와 표시 기준 재검토

사용자가 전달한 교수 피드백 전사 원문의 01:00~01:08 구간을 다시 대조하였다. 원음 재청취 기록과 구분한다.

| 시간 | 원문에서 확인한 발언과 맥락 | 반영 |
|---|---|---|
| 01:00:44~01:02:04 | 서로 다른 60개 질문이며 질문에 따라 좋거나 나쁜 결과가 나올 수 있다는 지적 | 네 유형의 전체 질문을 각각 분리하여 개별 점수 표시 |
| 01:03:22 | ‘60개의 일단 그려보고 식별이 잘 안 되면 그중에 중간에 있는 거 빼’ | 전체 원자료로 먼저 작성. 조건을 혼합하거나 전후 선을 덧그리지 않고 유형별 패널로 분리 |
| 01:03:42~01:03:58 | 지표의 높낮이가 두드러지는 질문과 여섯 지표·60개 질문의 구조를 설명 | 한 선은 질문 하나, 한 그림은 한 조건. 원래 여섯 지표 사용 |
| 01:05:33~01:05:50 | 질문마다 지표의 높낮이가 다르므로 질문 패턴에 맞는 기법 선택을 해석 | 전체 유형별 분포에서 사례를 실제 입력·답변 분석으로 연결 |
| 01:08:05 | 기존 질문 유형별 자료를 ‘그걸 위주로’ 분석 | 사실·정의 8개, 방법·절차 29개, 결과·비교 20개, 목적·기여 3개 유지 |

사용자는 ‘전체 질문의 분포 — 질문 유형별로 나누어 개별 점수를 표시’를 선택하였다. 60개 회색선에 단일 지표의 증가·감소 상위만 겹쳐 강조하던 구성을 교체하였다. 한 질문의 전후 두 선만 그린 XSUM 시안은 최종 본문 그림에 채택하지 않았다.

논문은 HyDE·CAD·SCD 각각을 네 유형으로 분리한 세 그림이다. 그림별로 60개 질문을 사용하며 한 질문은 한 번만 그린다. BIC 결정 항목과 XSUM 수치 비교 질문은 기존 전체 분석 후 원문·입력·답변을 대조한 사례로 표시한다. 조합의 전후 평균·변화·개선/악화 수는 표로 설명한다. 포스터는 04~07의 세 기법과 조합 결과표를 유지하고, 핵심인 HyDE의 전체 질문 분포를 네 유형으로 표시한다.

사용자는 모든 지표의 0점을 그래프에서 표시하지 않도록 지정하였다. 원자료·평균·표를 변경하지 않고 표시 좌표에서만 해당 점을 비우며 선을 연결하지 않는다. 원래 결측값도 그대로 비운다. 남아 있는 개별 점은 작은 표식으로 표시한다.

다섯 점수 지표는 0~1 축이며, 처리 시간은 초 단위의 별도 역방향 축이다. 시간축은 위 0초·중간 90초·아래 180초이고 세 그림에서 범위가 같다. 원자료의 시간은 바꾸지 않는다. 저장된 480개 기록의 최댓값 164.153초를 모두 포함하며, 표시 범위를 넘으면 자동 축소나 잘라내기 대신 오류로 처리한다. 이는 표시 좌표의 축 설정이며 새로운 분석 통계량을 계산하지 않는다.

표의 비교 제목은 ‘HyDE에 CAD를 추가했을 때의 답변 관련성’처럼 문장으로 쓰고, 평가 언어와 제외 질문 수는 다음 줄의 문장으로 분리하였다. 열 제목도 적용 전 평균·적용 후 평균으로 명확히 했다.

검증은 표시 좌표를 원자료에 다시 대조하여 유형별 8·29·20·3개 질문과 여섯 축의 값을 확인하고, 0점·결측에서 선이 끊기는지 검사한다. 최종 배치 판정은 한컴 편집 화면에서 수행한다.
