포스터는 교수 지시에 맞춰 설명을 문장으로 쓰고, 04에 HyDE 관련성·CAD 충실도·SCD 한국어 문자 비율의 유형별 변화와 개선/악화 수를 제시한다. 05의 HyDE→HyDE+CAD는 개선 5개·악화 18개다. 08은 세 기법의 60개 질문을 회색으로 그리고 증가·감소 상위 각 3개를 파랑·빨강으로 강조한다.

한컴 v9의 표지·목차와 본문 표시 1~41쪽을 연속 화면으로 검토했다. 최종 v10은 표 5-1·5-3 주석을 고친 파일이며 변경된 두 페이지를 편집 화면에서 재확인했다. 한컴 내보내기 자료의 픽셀 비교에서도 물리 19·23쪽만 달랐고 나머지 45쪽은 v9와 같았다. 이 PDF 비교는 편집 화면 검토의 보조 대조다.

최종 문서는 한컴독스 `M_RAG_QUESTION_ANALYSIS_20261020_v10.hwpx`이며 DELIVERY에 동일 HWPX·한컴 내보내기 PDF·빌드 기록·쪽 지도를 둔다. 전체 47쪽, 장 시작 1·3·7·8·10·23쪽, 참고문헌 24쪽, 부록 A 28쪽, 부록 B 38쪽이다. 원자료 8개 파일의 바이트 해시는 인계 전과 같고, 보호된 연구 출처의 해시도 유지했다. 갱신한 해시는 변경된 제출 산출물에 한정했다.

검증 명령은 `python -X utf8 -m FINALDOCS.VALIDATION.validate_all`이다. 변경 Python 파일은 Ruff·Black·compileall로 추가 확인한다. 상세 실행 결과는 `CURRENT_AUDIT.md`와 최종 검수 기록을 따른다. 인준 정보와 실물 인쇄 판독은 남아 있다.

최종 로컬 실행 결과는 validate_all 8/8 묶음 성공, 회귀 검사 51개 성공이다. 학교 원본과 최종 쪽 지도로 재생성한 HWPX도 구조·1,037개 XLSX 셀·18개 본문 표 조각·10개 그림·8개 수식 검사에 통과했다. 변경 Python 11개 파일의 Ruff·Black과 compileall이 통과했다.

커밋 시 로컬 pre-commit의 전역 Ruff 설정이 변경하지 않은 backend에서 178개 경고를 내며 중단했다. CI 고정 버전 Ruff 0.13.0의 기본 설정으로 backend 및 변경 Python 파일이 통과했고 Black 26.3.1의 backend 49개 파일도 통과했다. 이번 커밋만 로컬 훅 경로를 비워 실행하며 저장소 훅과 전역 설정은 수정하지 않는다. 원격 CI는 실제 커밋에서 확인한다.
