# v40f 논문과 V9 포스터 문장 단위 검토 기록

검토 대상은 저장소 납품본 `FINALDOCS/DELIVERY/GRADUATION_REPORT_60Q_FINAL.hwpx`(v40f, 한컴 내보내기 49쪽), 개인본 V9 포스터, 부록 A 질문 60개다. 모든 단위를 대화 안에서 직접 읽고 문법(맞춤법, 띄어쓰기, 주어와 서술어 호응), 학술 표현(용어 정의, 인용, 수치와 원자료 일치, 문단 흐름), 사용자 문체 규칙(방어형 문장, 가운뎃점, 화살표, 콜론 표기, 실행 이력 서술 금지)으로 판정하였다.

## 요약

- 논문 본문 단위 227개(장과 절 제목, 본문 문단, 그림과 표 제목, 부록 B 포함): 모두 적합. 이번 개정에서 고친 단위 30개.
- 포스터 문장과 라벨 53개: 모두 적합. 이번 개정에서 고친 것은 결론 첫 줄 1개(HyDE 권고 조건).
- 부록 A 질문 60개: 모두 문법 적합. 실험에 입력한 원문이라 표기 그대로 보존.
- 자동 점검: 띄어쓰기, 문장 부호, 반복 낱말, 가운뎃점과 화살표, 콜론 라벨, 실행 이력, 방어형 표현, 확인되지 않은 하드웨어 표기 모두 0건. 전체 검증 8개 묶음 통과.

## 4.1절 하드웨어 판단

- 7월 생성 실행은 `experiments/reports/phase8_main_generation_validation.md`에 NVIDIA A100 80GB PCIe 기록이 있다.
- 9월 생성 실행은 저장소 어디에도 GPU 기록이 없다. `extended_validation_executor.py`는 `alice_mode`를 상수 True로 기록하고 장치 이름을 남기지 않으며, 생성 코드는 CUDA를 강제하지 않는다.
- Hugging Face Transformers 4.45.2는 2026-04-15부터 `backend/requirements.txt`에 고정되어 있어 두 실행 모두에 해당한다.
- 결정: 확인되는 사실만 적는다. 4.1절은 "Paper-RAG는 Python과 PyTorch, Hugging Face Transformers 4.45.2로 구현하였다."로 확정한다. 실행을 둘로 나눈 이력은 실행 이력 서술 금지 규칙에 따라 본문에 쓰지 않는다.

## 독립 재검토 결과

같은 검토 에이전트가 반영 후 원고(v40f)를 다시 문장 단위로 읽고, v40d와 줄 단위로 비교하였다(바뀐 줄 30개, 모두 처리 표의 반영 사항).

- 논문: 적합. 첫 검토의 상 항목 3건과 중 항목이 모두 바르게 반영되었고 새 문법 오류나 수치, 주장의 불일치는 없다. 남은 조건 없음.
- 포스터: 적합. P1, P2는 저자 결정으로 조건에서 제외. P3(약어 풀이 위치)은 판정을 막지 않는 배치 사항으로 남김.
- 재검토의 낮음 항목 R1(ROUGE-L 풀이 대소문자), R2('모델이' 반복), R3('수치 질문의' 반복)은 v40f에 반영하였다. R4(생성 기록과 실행 기록, 질의와 질문)는 이해를 방해하지 않는 수준으로 판정되어 유지한다.
