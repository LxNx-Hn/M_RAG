## C. 구조 감사

- 1장: RAG 정의 → 개선 기법(HyDE·CAD·SCD의 실제 연산) → 한국어 질의–영어 문서의 세 단계 과제 → 함께 비교할 필요 → 실험 구성과 의의 순서로 이어진다.
- 2장: 각 기법의 원리와 수식, 2.7절은 선행연구가 보여 준 것과 이 실험이 더하는 비교(요인설계·상호작용·시간 비용)로 끝난다.
- 3~4장: 설계 요구사항 → 검색 역할 분담과 처리 순서의 이유 → 2³ 요인설계 → 환경·파라미터 근거 → 질의 처리 절차(세 문단) → 실행 순서와 기록 항목.
- 5장: 질의 구성 → 지표 정의와 범위 → 평가 절차(SCD 상태별 평가 언어) → 분석 방법 → 8조건 결과 → RQ별 t-검정 → 요인 ANOVA·단순 효과 → 논의 → 평가 범위.
- 6장: RQ별 결과 요약, 의의, 적용 조건과 후속 연구. 5장 수치의 전면 재나열은 하지 않는다.
- 부록 B.1: 사례마다 질의, 비교 조건, 검색 결과 동일 여부, 답변 내용, 점수 변화를 2~4문장으로 설명한다.
