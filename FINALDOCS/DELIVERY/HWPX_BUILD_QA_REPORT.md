## 생성 방식 선정

[python-hwpx 공식 저장소](https://github.com/airmang/python-hwpx)와 [pyhwpxlib 공식 저장소](https://github.com/ratiertm/pyhwpxlib)를 조사하고 학교 양식 변환을 실제 시험했다. `python-hwpx==6.8.0`의 HWP 열기·변환, 문단 스타일, 표, 이미지, 수식 API를 사용하고 필요한 OWPML 속성을 직접 조정했다. `pyhwpxlib==0.18.3` 변환은 시험 시 셀 주소와 선 종류의 스키마 경고가 발생하여 최종 경로로 선정하지 않았다.

원본 1단·구역 속성을 유지하며, 편집 가능한 표의 병합·머리글 반복·셀 단위 쪽 나눔을 설정했다. 이미지 원본 바이트와 종횡비를 보존했다. 수식은 `doc.shapes.add_equation`의 네이티브 개체 10개로 삽입하고 원문 스크립트를 대조했다. 이미지 수식으로 대체한 항목은 없다. 바닥글 쪽번호는 자동 번호 개체다. 원본이 사용한 목차 스타일·탭을 이용하여 실제 페이지 번호를 넣었다. 자동 목차 필드는 적용하지 않았으므로 편집 후 수동 갱신 대상이다.

학교 양식에 포함된 그림 예시 자산은 원본 변환본과 패키지에 보존되지만 논문에 표시되는 그림 개체 수에는 포함하지 않는다. HWP 변환기가 누락한 `version.xml`의 패키지 manifest 항목을 명시적으로 등록하여 패키지 검사 경고를 해결했다. 작은 시험본은 표지, 본문 2문단, 장·절 2종, 표·그림·수식 각 1개와 쪽번호를 포함한다.

## 실제 웹한글 및 PDF 검증

사용자가 직접 로그인하고 확장 프로그램의 파일 URL 권한을 허용한 후 실제 업로드를 수행했다. 시험본의 문단과 표 셀을 수정했으며, 문단 수정은 저장→새로 열기→HWPX 다운로드→문자열·XML 재검사로 확인했다. 다운로드 시험본은 `HWPX_SMOKE_WEB_ROUNDTRIP.hwpx`, 수정 화면은 `WEB_SMOKE_EDIT.jpg`로 보존한다. 최종 파일도 업로드·열기·재열기·편집 메뉴 활성·PDF 출력까지 확인했다. 최종 논문에는 시험용 수정 문자열을 넣지 않았다.

실제 웹한글 PDF는 **57쪽**이다. 전체 쪽을 렌더링하여 잘림·겹침·표 넘침·그림 비율·수식·빈 페이지·장 시작·캡션을 검토했다. 최초 PDF에서 쪽 위치를 확인한 뒤 목차 5~8쪽에 번호를 적용해 다시 출력했다. 최종 출력의 1~4쪽 및 9~57쪽은 초기 출력과 픽셀 단위로 동일하며, 변경된 목차 4쪽을 별도로 육안 확인했다. 부록 A 표는 46~52쪽에서 머리글을 반복하며 셀 내용이 다음 쪽으로 이어진다. 장 시작은 1장9, 2장11, 3장19, 4장22, 5장26, 6장42쪽이고 참고문헌44, 부록A46, 부록B53쪽이다.

일부 양식 글꼴의 PDF 텍스트 매핑은 추출 도구가 제목을 읽지 못한다. 해당 제목의 페이지는 이미지로 검토하여 `PAGE_MAP_60Q.json`의 `visual_overrides`에 근거를 기록했다. PDF 텍스트 추출만으로 전체 내용 일치를 주장하지 않는다. 원고 내용은 HWPX 텍스트와 셀·수식 대조로 확인했다. 최종 PDF SHA-256: `ef75e44b8fbbf6d747ff5cca38cf3257db752794b46cd97911ba345fdf50e04f`.

웹한글에서 동일 파일을 중복 탭으로 열었을 때 협업 모드의 수식 기능 제한 안내가 관찰되었다. 중복 탭을 닫고 재열기 후 안내는 사라졌다. 수식 표시와 네이티브 구조는 검증했으며 모든 수식 편집 대화상자 동작을 개별 시험한 것은 아니다. 큰 사례 그림은 비율과 해상도를 유지했으므로 세부 텍스트는 확대하여 볼 수 있다. 설치형 HWP 변환과 열림을 검증하지 않아 `.hwp` 최종 파일은 제공하지 않는다.

## 남은 입력과 전달

확인되지 않은 학생·학번·지도교수·제출일을 1~2쪽에서 입력해야 한다. 내용·서식을 편집해 쪽이 달라지면 목차의 페이지 번호를 갱신해야 한다. `WEB_HANCOM_CHECKLIST.md`에 정확한 위치와 조작법, `BUILD/README.md`에 재생성 방법이 있다. 산출물은 모두 `FINALDOCS/DELIVERY/`에 있고 GitHub에서 파일별 **Download raw file**로 받을 수 있다. 이전 생성본은 로컬 `versions/`에 보존하며 원본 양식과 실험 자료를 삭제하지 않았다.
