국문초록
검색 증강 생성(Retrieval-Augmented Generation, RAG)은 외부 문서를 검색해 생성 모델의 문맥으로 제공함으로써 특정 문서에 근거한 질의응답을 가능하게 한다. 한국어로 질문하고 영어 학술·기술 문서에서 근거를 검색한 뒤 한국어로 답하는 환경에서는 질의와 문서의 언어·표현 차이, 검색 근거의 생성 단계 활용, 영어 문맥에 따른 출력 언어 이탈을 함께 고려해야 한다. 본 연구는 Hypothetical Document Embeddings(HyDE), Context-Aware Decoding(CAD), Soft Constrained Decoding(SCD)을 각각 검색 표현 확장, 문맥 기반 생성 제어, 한국어 출력 언어 제어의 실험 요인으로 두고 2×2×2 조합을 RAG-Cube로 구성하였다.
실험은 BGE-M3 밀집 검색, BM25 희소 검색, weighted Reciprocal Rank Fusion, CrossEncoder 재정렬, K-intelligence/Midm-2.0-Base-Instruct로 구성된 고정 Paper-RAG 백본을 사용하였다. RAG Survey, CAD, RAPTOR, Mi:dm K 2.5 Pro Technical Report의 네 문서에 문서별 15개씩 총 60개의 한국어 질의–대상 문서 쌍을 구성하고, 8개 실험 조건을 적용하여 480개의 생성 기록을 저장하였다. HyDE는 CAD·SCD OFF의 60개 대응쌍, CAD는 동일 검색 문맥 대응쌍, SCD는 동일 질의에서 HyDE·CAD의 ON/OFF 상태를 맞춘 240개 대응쌍과 HyDE OFF 동일 검색 문맥 120개 대응쌍으로 비교하였다.
HyDE 적용 시 답변 관련성 평균 변화는 +0.0805이고 95% 신뢰구간은 [+0.0110, +0.1514]였다. 근거 충실도는 +0.0436, 문맥 정밀도는 -0.0343, 문맥 재현율은 0.0000으로 지표별 방향이 달랐다. CAD의 동일 문맥 비교에서 근거 충실도는 양쪽 평가값이 존재하는 58쌍에서 +0.0288, 95% 신뢰구간은 [-0.0367, +0.0934]였고, 답변 관련성은 60쌍에서 -0.0073이었다. SCD의 주 비교인 HyDE OFF 동일 문맥 120개 대응쌍에서 한국어 문자 비율은 평균 +0.2182, 95% 신뢰구간은 [+0.1880, +0.2487] 증가했으며, 전체 240개 대응쌍에서도 +0.2289의 변화가 나타났다.
이 평가 집합에서 HyDE의 답변 관련성은 증가하였다. CAD의 근거 충실도 평균 차이는 양수였으나 신뢰구간이 0을 포함하였다. SCD는 동일 문맥 비교에서 한국어 문자 비율을 높였다. 세 결과는 각각 답변의 질문 관련성, 동일 근거의 활용, 출력 언어라는 측정 대상에 따라 구분하여 해석하였다.
주요어: Retrieval-Augmented Generation, HyDE, Context-Aware Decoding, Soft Constrained Decoding, 한국어 질의, 영어 학술·기술 문서, 언어 이탈
Abstract
Retrieval-augmented generation (RAG) enables document-grounded question answering by retrieving external evidence and supplying it to a generator. When Korean questions target English academic or technical documents and the expected answer language is Korean, retrieval and generation involve three coupled issues: cross-lingual mismatch between queries and evidence, use of retrieved context during generation, and output-language drift toward English. This study treats Hypothetical Document Embeddings (HyDE), Context-Aware Decoding (CAD), and Soft Constrained Decoding (SCD) as binary factors for retrieval-query expansion, context-aware generation, and Korean-output control, forming an eight-condition 2×2×2 experimental design termed RAG-Cube.
The fixed Paper-RAG backbone combines BGE-M3 dense retrieval, BM25 sparse retrieval, weighted Reciprocal Rank Fusion, CrossEncoder reranking, and K-intelligence/Midm-2.0-Base-Instruct. Sixty Korean query-document pairs were constructed from four English academic or technical documents, and eight configurations were applied to every pair, yielding 480 stored generation records. HyDE was compared on 60 pairs with CAD and SCD disabled, CAD was compared on identical-context pairs, and SCD was evaluated on 240 state-matched on/off pairs together with a 120-pair HyDE-OFF identical-context subset.
HyDE increased answer relevancy by +0.0805 on average, with a 95% bootstrap interval of [+0.0110, +0.1514]. Its changes in faithfulness, context precision, and context recall were +0.0436, -0.0343, and 0.0000, respectively. Under identical contexts, CAD changed faithfulness by +0.0288 on 58 complete pairs, with a 95% bootstrap interval of [-0.0367, +0.0934], while answer relevancy changed by -0.0073 on 60 pairs. In the primary SCD comparison, the Korean-character ratio increased by +0.2182 on 120 HyDE-OFF identical-context pairs, with a 95% bootstrap interval of [+0.1880, +0.2487]. Across all 240 state-matched pairs, the mean change was +0.2289. Within this evaluation set, HyDE increased answer relevancy and SCD increased the Korean-character ratio; the CAD faithfulness interval included zero.
Keywords: Retrieval-Augmented Generation, HyDE, Context-Aware Decoding, Soft Constrained Decoding, Korean query, English academic or technical document, language drift

1. 서론
1.1 연구배경 및 목적
한국어 질의로 영어 학술·기술 문서를 활용할 때는 질의와 문서의 언어 차이, 검색 근거의 활용, 한국어 출력의 일관성을 함께 고려해야 한다. 특정 논문의 방법, 실험 조건, 수치와 결론을 확인하려면 생성 답변을 실제 문서의 근거와 연결해야 한다. 검색 증강 생성(Retrieval-Augmented Generation, RAG)은 외부 문서를 검색해 생성 모델의 입력으로 제공하는 질의응답 구조이다[1].
이 연구에서는 한국어 질의로 영어 학술·기술 문서에서 근거를 찾고 한국어 답변을 생성하는 환경을 다루었다. 분석 대상은 질의와 문서의 표현 차이에 따른 검색 결과, 검색 문맥이 답변에 반영되는 정도, 영어 문맥을 입력했을 때의 출력 언어이다.
HyDE는 질의에서 가상 문서를 생성해 검색 표현을 확장한다[2]. CAD는 문맥 포함·제외 확률 분포를 대조하여 생성 토큰의 점수를 조절한다[3]. SCD는 목표 언어와 비목표 언어 토큰의 점수를 다르게 조정한다[4]. 이들 기법을 적용한 뒤 검색 결과, 답변 품질, 출력 언어를 각 기법의 개입 위치에 맞춰 비교하였다.
연구 목적은 선행연구의 HyDE·CAD·SCD[2][3][4]를 고정된 Paper-RAG 백본에 적용하고, 한국어 질의–영어 문서 환경에서 나타나는 변화를 비교하는 것이다. 검색 입력을 바꾸는 HyDE와 생성 단계에 적용하는 CAD·SCD는 비교 조건을 구분하였다. 대응쌍의 구성과 문맥 동일성 확인 기준은 3.3절에서 설명한다.

1.2 연구범위
연구 대상은 RAG Survey, CAD, RAPTOR, Mi:dm K 2.5 Pro Technical Report의 네 영어 학술·기술 문서와 문서별 15개씩 구성한 60개 한국어 질의–대상 문서 쌍이다. 각 질의에 8개 RAG-Cube 조건을 모두 적용하여 480개의 생성 기록을 저장하였다. 검색과 생성에는 BGE-M3, BM25, weighted RRF, CrossEncoder, 상위 5개 문맥과 Mi:dm 2.0 Base Instruct를 공통으로 사용하였다. 구체적인 실행 설정은 4.1절에 정리하였다.
HyDE는 CAD·SCD OFF의 60개 대응쌍에서 검색부터 답변 생성까지의 변화를 비교하였다. CAD는 동일 검색 문맥에서 답변 품질과 생성 시간을 비교하였다. SCD는 HyDE OFF 동일 문맥 120개 대응쌍을 주 비교로 삼고, HyDE·CAD 상태를 맞춘 전체 240개 대응쌍을 함께 분석하였다. 답변 품질은 RAGAS 지표로, 출력 언어는 한국어 문자 비율로 측정하였다.
1.3 연구 질문, 분석 관점 및 논문 구성
연구 질문은 다음과 같다. 첫째, CAD·SCD를 OFF로 고정했을 때 HyDE 적용 전후의 답변 관련성과 다른 RAGAS 지표는 어떻게 달라지는가. 둘째, 동일 검색 문맥에서 CAD 적용 전후의 답변 품질과 생성 시간은 어떻게 달라지는가. 셋째, HyDE·CAD 상태를 맞춘 SCD 대응쌍, 특히 HyDE OFF 동일 문맥 대응쌍에서 한국어 문자 비율은 얼마나 달라지는가. 넷째, 조합별 평균과 요인별 대응 결과에 근거하여 적용 목적별로 어떤 조건을 선택할 수 있는가.
분석은 대응 평균 차이와 부트스트랩 신뢰구간, 검색·재정렬 청크 ID와 문맥 동일성, 실제 질문·검색 근거·생성 답변·평가값을 함께 사용한다. 정량 결과와 개별 입출력 사례를 동일한 질의와 실험 조건 단위에서 제시한다.
2장에서는 RAG와 세 실험 요인, 평가 및 관련 연구를 정리한다. 3장은 실험 요구사항과 비교 설계를, 4장은 구현과 생성 기록 저장 구조를 설명한다. 5장은 60개 질의 평가 결과와 사례를 제시하고, 6장은 주요 결과와 적용 기준 및 후속 연구를 종합한다.
2. 이론적 배경
2.1 Retrieval-Augmented Generation
RAG는 질의와 관련된 외부 문서를 검색하고, 선택된 문맥을 생성 모델의 입력에 포함하여 답변을 만드는 구조이다[1]. 문서 집합을 D, 질의를 q, 검색 문맥을 C, 답변을 y라고 하면 과정은 Retrieve(q, D)로 C를 얻고, 생성 모델이 q와 C를 조건으로 y를 생성하는 흐름으로 설명할 수 있다. 학술문서 질의응답에서는 검색 단계와 생성 단계를 구분해 보는 것이 중요하다. 필요한 문단의 검색 상태와 검색 문단이 최종 답변에 반영되는 정도는 서로 다른 분석 대상이기 때문이다.
Lewis 외[1]는 사전학습 검색기(retriever)가 외부 문서 인덱스에서 관련 문서를 찾고, 생성기(generator)가 질의와 검색 문서를 함께 사용해 출력을 생성하는 RAG 구조를 제시하였다. 그림 2-1은 이 개념을 바탕으로 본 연구에서 구성한 독립 도식으로, 외부 문서 검색과 질의·문맥을 이용한 답변 생성의 흐름을 보여준다. 본 연구의 하이브리드 검색과 디코딩 실험은 이 검색–생성 분리를 공통 기반으로 사용한다.

2.2 하이브리드 검색과 재정렬
고정 백본은 BGE-M3 기반 밀집 검색과 BM25 기반 희소 검색을 결합한다. 밀집 검색은 질의와 문서 구간의 의미적 유사성을 이용해 어휘가 정확히 일치하지 않아도 관련 후보를 찾고, BM25는 모델명·약어·수치처럼 표면 일치가 중요한 표현을 보완한다[5][6]. 두 결과는 순위 기반 weighted Reciprocal Rank Fusion으로 결합하며[7], CrossEncoder가 질의와 각 문서 구간의 관련성을 다시 계산해 순서를 조정한다[8].
밀집 검색과 BM25의 가중치는 각각 0.6과 0.4, 검색 후보 수와 재정렬 후보 수는 각각 8개, 최종 문맥 수는 5개로 고정하였다. 이 설정을 모든 RAG-Cube 조건에 공통으로 적용하였다.
한국어 질문의 설명형 표현과 영어 원문의 제목·방법론 용어는 언어와 표면 표현에서 차이가 난다. 논문명, 데이터셋명, 모델 크기와 하이퍼파라미터의 정확한 표기는 검색 단서가 된다. 밀집 검색과 희소 검색을 결합한 이유는 의미적 유사성과 표면 일치를 함께 활용하기 위해서다.
재정렬은 검색 후보의 우선순위를 조정하고, 생성 모델은 선택된 문맥을 입력으로 답변을 만든다. 검색 결과가 바뀌는 경우와 같은 문맥에서 생성 방식만 바뀌는 경우를 구분해야 두 단계의 영향을 해석할 수 있다.
관련 문서 구간을 검색하더라도 생성 모델이 이를 활용하는 정도는 입력 내 위치에 따라 달라질 수 있다. Liu 외[12]는 다중 문서 질의응답에서 정답 문서가 입력의 처음이나 끝에 있을 때보다 중간에 있을 때 성능이 낮아지는 U자형 패턴을 보고하였다. 그림 2-2는 원 논문의 해당 결과이다. 본 실험에서는 문맥 수와 순서 정책을 고정하고, 검색 결과와 생성 결과를 별도 지표로 기록하였다.

2.3 HyDE와 가상 문서 기반 검색
HyDE는 질의를 바탕으로 가상 문서를 생성하고, 해당 문서의 임베딩을 검색에 활용하는 방법이다[2]. 가상 문서를 거치면 짧은 질의를 문서 형태의 표현으로 확장할 수 있다.
Gao 외[2]의 HyDE는 언어 모델이 질의를 바탕으로 가상 문서를 생성하고, 인코더가 이를 임베딩으로 변환해 실제 문서 집합에서 유사한 문서를 검색한다. 그림 2-3은 질의와 문서를 직접 비교하는 대신 가상 문서를 거쳐 검색하는 구조를 보여준다.

HyDE ON에서는 한국어 질의를 영어로 변환한 뒤 가상 문서를 생성하여 밀집 검색 입력으로 사용하였다. BM25와 CrossEncoder에는 원질의를 유지하였다. 최종 답변은 검색된 실제 문서 구간을 근거로 생성하였다. 따라서 HyDE 비교에는 번역, 가상 문서 생성, 밀집 검색, 순위 결합, 재정렬과 문맥 선택의 변화가 함께 포함된다. 검색 청크 ID와 최종 문맥의 변화를 답변 관련성의 변화와 함께 분석하였다.
2.4 Context-Aware Decoding
CAD는 문맥 포함·제외 다음 토큰 확률 분포를 대조하여 문맥에 의해 상대적으로 강화된 토큰의 점수를 높이는 디코딩 방법이다[3]. 본 실험에서는 α=0.5를 고정하였다. 검색 이후의 생성 변화를 비교하기 위해 주 대응쌍의 검색·재정렬 청크 ID와 최종 문맥이 같은지 확인하였다.
Shi 외[3]는 문맥 포함 분포와 문맥 제외 분포를 대조해 문맥에 의해 강화되는 토큰의 상대적 비중을 높이는 구조를 제시하였다. 그림 2-4의 원 논문 사례는 모델의 기존 지식과 제공된 문맥이 충돌할 때 두 분포가 서로 다른 토큰을 선호하고, CAD가 그 차이를 이용해 문맥 쪽 신호를 강화하는 방식을 보여준다.

CAD는 생성 단계마다 문맥 포함 분포와 문맥 제외 분포를 계산하므로 단일 분포보다 실행 비용이 증가할 수 있다. 결과는 근거 충실도, 답변 관련성, 생성 시간을 함께 분석한다. 동일 입력에서 나타나는 질의별 변화와 평균을 함께 분석해 문맥 기반 로짓 조절의 결과 분포를 확인한다.
동일 문맥 대응쌍의 구체적인 구성은 3.3절에 제시한다. 검색 결과를 고정한 비교에서는 답변 품질의 차이를 검색 선택의 차이와 구분할 수 있다.
2.5 Soft Constrained Decoding과 언어 이탈
다국어 RAG에서는 질의와 문맥 내 예시가 목표 언어로 주어져도 검색 근거가 다른 언어일 때 생성 답변이 검색 문서의 언어 쪽으로 이동하는 출력 언어 이탈(language drift)이 발생할 수 있다. Li 외[4]는 다국어 RAG에서 이러한 현상을 분석하고, 추론 과정에서 목표 언어와 비목표 언어가 혼합된 뒤 최종 출력이 비목표 언어로 이동하는 사례를 제시하였다. 그림 2-5는 원 논문에 제시된 출력 언어 이탈 사례다.

SCD는 어휘 집합을 목표 언어, 비목표 언어와 중립 토큰으로 나누고 토큰 점수를 조정하는 디코딩 방법이다[4]. 본 실험에서는 한국어를 목표 언어로 두고 α=1.1, β=0.9, Tstart=5를 사용하였다. 생성 토큰 수가 5 미만일 때는 기존 점수를 유지하고, 5 이상부터 한국어 목표 토큰에는 α, 비목표 언어 토큰에는 β를 곱하며 중립 토큰의 점수는 유지하였다. CAD와 함께 적용할 때는 CAD 점수를 계산한 뒤 SCD 처리를 적용하였다.
출력 언어는 생성 답변의 한글 문자 수를 한글 문자와 ASCII 영문자 수의 합으로 나눈 한국어 문자 비율로 측정하였다. 후속 사람 평가의 측정 항목은 6.4절에 정리하였다.
SCD의 토큰 그룹별 점수 조정과 한국어 문자 비율은 다음 수식으로 정의한다.
논문 제목, 모델명과 데이터셋명 등의 영어 표기를 포함하여 실제 답변의 언어 구성을 계산하였다. SCD 대응쌍의 구성과 변화 판정 기준은 5.2절에 설명한다.
2.6 RAG 평가
HyDE와 CAD의 품질 비교에는 RAGAS의 근거 충실도(faithfulness), 답변 관련성(answer relevancy), 문맥 정밀도(context precision), 문맥 재현율(context recall)을 사용하였다[9]. 근거 충실도는 답변의 주장이 제공된 문맥에 의해 지지되는 정도를, 답변 관련성은 답변이 질문에 대응하는 정도를 측정한다. 문맥 정밀도는 관련 근거가 검색 결과의 상위에 배치되는 정도를, 문맥 재현율은 참조 답변에 필요한 근거가 검색 문맥에 포함된 정도를 측정한다.
RAGAS 원 연구는 질문–문맥–답변 예시로 평가 차원을 설명한다. 그림 2-6은 WikiEval의 동일 질문과 문맥에 대해 근거가 지지하는 답변과 지지하지 않는 답변을 대비한 원 논문의 표 2이다. 질문에 관련된 답변인지와 문맥이 그 답변을 지지하는지는 별도로 평가해야 함을 보여준다.

2.7 관련 연구와 본 연구의 위치
검색 증강 생성 연구는 검색기의 표현력, 여러 문서 구간의 활용, 디코딩 제어와 검색·생성의 자기검증으로 확장되어 왔다. Dense Passage Retrieval은 밀집 검색의 대표 구조를 정립했고[10], Fusion-in-Decoder는 여러 검색 문서 구간을 생성 단계에서 함께 이용하는 방식을 제안했다[11]. 긴 문맥에서는 관련 정보의 위치에 따라 모델의 활용 정도가 달라질 수 있다는 분석이 보고되었으며[12], contrastive decoding은 서로 다른 조건의 생성 분포를 대조하는 관점을 제시했다[13]. RAPTOR는 세부 문서 구간과 상위 요약을 계층적으로 구성하는 검색 구조를 제안했고[14], Self-RAG[15]와 Corrective RAG[16]는 검색 필요성이나 근거 품질을 생성 과정에서 점검하는 방향을 보였다.
RAG 시스템 전반을 정리한 조사 연구[17], 한국어·영어 이중언어 생성 모델에 관한 Mi:dm 2.0 연구[18], RAG의 구성과 평가를 체계화한 조사 연구[19]는 본 실험의 시스템·언어 조건을 설정하는 배경이 된다. 검색 모델의 도메인·과제 간 편차는 BEIR[20]과 MTEB[21] 같은 벤치마크의 관점에서 참고하며, 실험 문서 집합 중 하나인 Mi:dm K 2.5 Pro는 해당 기술 보고서[22]를 사용한다.
본 연구는 HyDE, CAD, SCD를 각각 검색 표현 확장, 문맥 기반 생성 제어, 출력 언어 제어로 고정 백본 안에 배치하고, 각 기법의 적용 위치에 맞는 대응 비교를 수행하였다. HyDE는 검색 입력 변화까지 포함한 종단 간 변화로, CAD는 동일 문맥에서의 생성 변화로, SCD는 동일 질의에서 HyDE·CAD 상태를 맞춘 출력 언어 변화로 분석한다.
표 2-1은 선행연구와 본 실험의 연결을 정리한다. DPR과 BEIR는 검색 표현과 도메인별 평가에, FiD와 긴 문맥 연구는 여러 문맥의 활용에 관련된다. 대조 디코딩은 CAD의 분포 대조와 연결되며, Self-RAG와 CRAG는 검색 필요성과 근거 품질을 점검한다.

4. 프로그램 구현
4.1 시스템 환경
생성에는 K-intelligence/Midm-2.0-Base-Instruct를 사용하고 최대 생성 토큰 수를 512로 설정하였다. 답변은 각 단계에서 확률이 가장 높은 토큰을 선택하는 방식으로 생성하였다.
문서 청크는 Python split()의 공백 분리 단위를 기준으로 최대 512개 단어, 64개 단어 중첩, 최소 50개 단어로 구성하였다. BGE-M3 밀집 검색과 BM25 희소 검색은 dense 0.6, BM25 0.4의 weighted RRF(k=60)로 결합하고 cross-encoder/ms-marco-MiniLM-L-6-v2로 재정렬하였다. 동일 CrossEncoder를 모든 조건에 적용하였다. 검색 후보 수와 재정렬 후보 수는 각각 8개, 최종 생성 문맥은 5개로 설정하였다.
문맥 길이 관리에는 ContextCompressor를 사용하였다. 설정값은 split()으로 계산한 공백 분리 기준 최대 3,072개 단어와 압축 비율 0.5이며, 추출식 압축으로 문맥 길이를 관리하였다. 표 4-1은 생성 기록에 저장된 모델, 검색·생성 설정과 요인별 파라미터를 정리한다.
검색 폭 설정은 최종 평가 집합과 분리된 5개 튜닝 질의를 사용하여 사전에 선정하였다. 검색 후보 수, 재정렬 후보 수와 최종 문맥 수를 달리한 세 가지 설정을 비교하였으며, 문맥 재현율 0.95 이상을 충족한 후보 가운데 평균 근거 충실도가 가장 높은 설정을 선택하였다. 그 결과 검색 후보 수 8, 재정렬 후보 수 8, 최종 문맥 수 5를 확정하고 이후 60개 평가 질의의 모든 RAG-Cube 실험 조건에 동일하게 적용하였다.

5. 실험
5.1 실험 대상과 구성
최종 평가 집합은 RAG Survey, CAD, RAPTOR, Mi:dm K 2.5 Pro Technical Report의 네 영어 학술·기술 문서를 대상으로 구성한 총 60개의 한국어 질의–대상 문서 쌍으로 이루어진다. 네 문서에 각각 15개의 질의를 배정하며, 모든 질의는 한국어 질의로 영어 문서에서 근거를 검색하는 동일한 교차언어 조건을 공유한다.
질의 구성은 네 문서에 동일한 절차를 적용하였다. 연구자는 각 문서의 주요 내용을 바탕으로 질문의 표현 방식과 범위를 정의하는 초기 질문 3개를 작성하였다. 이후 LLM을 사용하여 문서의 주요 내용을 질문 작성에 활용할 수 있는 형태로 요약하고, 요약 결과를 15개의 내용 단위로 구분하였다. 각 내용 단위에서 한국어 평가 질의 1개를 구성하여 문서별 15개, 총 60개의 질의를 완성하였다.
연구자는 각 질의를 원문 PDF와 대조하여 대상 문서, 원문 페이지, 정답 근거 구간과 답변 가능성을 확인하였다. 정답 근거는 원문에서 직접 확인할 수 있는 연속 구간으로 기록하고, 질문–근거 대응 관계를 검토하였다. 이 절차를 통해 60개 질의 각각에 원문 페이지와 정답 근거 구간을 연결하였다.
질문 유형은 요구되는 답의 성격을 기준으로 사실·정의, 방법·절차, 결과·비교, 목적·기여의 네 범주로 구분하였다. 사실·정의는 개념·수치·구성 요소, 방법·절차는 모델 구조·처리 과정·데이터셋 구성·평가 방법·실험 설정, 결과·비교는 정량·정성 결과와 방법 간 비교, 목적·기여는 연구 목적·문제 설정·주요 기여를 묻는 질의로 정의하였다. 최종 분포는 사실·정의 8개, 방법·절차 29개, 결과·비교 20개, 목적·기여 3개다.

5.2 평가 및 분석 방법
평가는 3.3절에서 정의한 대응 비교 설계에 따라 저장된 생성 기록과 평가 결과를 질의 단위로 연결하여 수행하였다. RAGAS 0.2.15를 사용하고, 평가 모델은 OpenAI gpt-4o, 답변 관련성 계산에 사용하는 임베딩 모델은 BAAI/bge-m3로 설정하였다. 평가 지표는 근거 충실도, 답변 관련성, 문맥 정밀도, 문맥 재현율의 네 항목으로 구성하였다.
SCD OFF 평가는 저장된 영어 검색 문맥을 평가 문맥으로 사용하였다. SCD ON 평가는 동일하게 저장된 검색 문맥을 gpt-4o로 한국어 변환한 뒤 평가 문맥으로 사용하고 생성 답변은 원문 상태로 유지하였다. 따라서 SCD OFF와 SCD ON의 RAGAS 값은 각각의 평가 프로토콜 내부에서 조건별 기술통계로 해석한다. SCD의 주 비교는 생성 답변에서 직접 계산한 한국어 문자 비율의 대응 차이로 평가하였다.
근거 충실도 비교는 양쪽 조건에 평가값이 존재하는 대응쌍을 분석 단위로 사용하였다. 이에 따라 CAD 주 비교의 근거 충실도 분석에는 58개 대응쌍을 사용하였다.
HyDE 주 비교는 CAD와 SCD를 OFF로 고정한 60개 질의를 대상으로 수행하였다. CAD 주 비교는 검색 청크 ID, 재정렬 청크 ID와 최종 검색 문맥이 동일한 대응쌍을 사용하여 검색 결과를 고정한 상태의 생성 차이를 측정하였다. SCD 주 비교는 HyDE OFF 조건에서 검색·재정렬 청크 ID와 최종 검색 문맥이 동일한 120개 대응쌍을 사용하였다. 추가로 동일 질의에서 HyDE와 CAD 상태를 각각 맞춘 240개 SCD 대응쌍을 이용하여 8개 실험 조건 전반의 출력 언어 변화를 집계하였다.
답변 생성 설정은 4.1절과 동일하게 유지하였다. HyDE 가상 문서 생성에는 temperature=0.1, top_p=0.9의 샘플링을 사용하였다. 요인별 차이는 같은 질의에서 ON 점수와 OFF 점수의 차이로 계산하였다. 질의를 재표집 단위로 200,000회의 대응 부트스트랩을 수행하고 seed는 20260713으로 고정하였다. 질의별 방향 분포는 RAGAS 차이 +0.01 초과를 증가, -0.01 미만을 감소, 그 사이를 동률로 집계하고, SCD의 한국어 문자 비율은 ±0.02를 기준으로 집계하였다. 이 신뢰구간은 네 대상 문서를 고정한 연구 설계에서 질의 수준의 변동성을 나타낸다.

5.8 종합 논의
검색 표현을 확장한 HyDE는 답변 관련성에서 양의 평균 차이를 보였지만, 문맥 정밀도는 -0.0343, 문맥 재현율은 0.0000이었다. 그림 5-3에서도 검색·재정렬 청크 ID와 최종 문맥이 바뀌었다. 따라서 답변 관련성의 변화는 번역과 가상 문서 생성을 포함한 검색 경로 전체의 결과로 해석해야 한다.
CAD 동일 문맥 비교에서 근거 충실도의 평균 대응 차이는 +0.0288, 답변 관련성은 -0.0073이었다. 두 지표의 95% 부트스트랩 신뢰구간은 모두 0을 포함하였다. CAD ON은 동일한 검색 문맥에서 문맥 제외 분포를 추가로 계산하며, 대응 조건군에서 생성 시간이 증가하였다. 이 결과는 CAD의 적용 판단에서 생성 품질 분포와 계산 비용을 함께 고려할 근거를 제공한다.
SCD는 생성 답변의 한국어 문자 비율을 높였다. HyDE OFF 동일 문맥 120개 대응쌍에서 평균 대응 차이는 +0.2182였고, HyDE·CAD 상태를 맞춘 전체 240개 대응쌍에서는 +0.2289였다. 따라서 본 연구에서 SCD의 직접적인 측정 결과는 출력 언어 성향의 변화로 정리된다.
조건별 평균과 요인별 대응 비교는 서로 다른 분석 수준을 제공한다. 표 5-2는 8개 조합의 기술통계를 제시하고, 표 5-3~5-6은 특정 요인의 ON/OFF 차이를 질의 단위 대응 구조에서 제시한다. 실험 조건의 선택 기준은 답변 관련성, 근거 충실도, 생성 시간, 한국어 문자 비율처럼 적용 환경에서 우선하는 목표 지표에 따라 달라진다.
그림 5-11은 HyDE와 CAD의 조건별 기술적 대응 차이를 정리한다. 답변 관련성에서 HyDE의 평균 대응 차이는 C0S0에서 +0.0805, C1S0에서 +0.0290이었고, SCD ON에서는 C0S1 +0.0725, C1S1 +0.0675였다. CAD의 답변 관련성 대응 차이는 H0S0 -0.0073, H1S0 -0.0588이었으며, SCD ON에서는 H0S1 -0.0377, H1S1 -0.0427이었다. 근거 충실도에서도 조건군별 대응 차이가 서로 다른 크기로 나타났다. HyDE ON 조건은 각 실험 조건에서 temperature=0.1, top_p=0.9 샘플링으로 가상 문서를 독립 생성하였다. 이에 따라 H1 조건의 CAD·SCD 비교에는 디코딩 조건에 따른 생성 변화와 HyDE 샘플링에 따른 검색 문맥 변화가 함께 반영된다. 그림 5-11은 각 조건에서 측정된 대응 차이를 제시하며, 실험 조건 선택은 목표 지표와 검색 문맥 변화를 함께 기준으로 한다.
부록 B의 문서별·질문 유형별 분석은 전체 평균에 가려진 하위집단의 차이를 보여준다. 문서별 질의 수는 15개로 같지만 질문 유형별 표본 수는 8, 29, 20, 3개로 다르다. 특히 표본이 적은 유형의 결과는 후속 실험 가설을 위한 탐색 자료로 해석하였다.
[그림 5-11] HyDE·CAD 조건별 근거 충실도·답변 관련성 대응 차이
5.9 실험 범위와 해석 기준
영어 학술·기술 문서 4종에 대해 문서별 15개씩, 총 60개의 한국어 질의를 구성하였다. 각 질의의 원문 페이지와 정답 근거 구간을 확인하고, K-intelligence/Midm-2.0-Base-Instruct와 CAD α=0.5 설정으로 평가하였다. 근거 부족 상황의 응답과 문서·모델 조건 확장을 위한 후속 평가를 6.4절에 제안하였다.
HyDE 평가는 번역, 가상 문서 생성과 밀집 검색 변경을 포함한 종단 간 비교로 구성하였다. 가상 문서는 temperature=0.1, top_p=0.9로 생성하였으며 저장된 검색·생성 기록을 분석하였다. SCD ON/OFF의 RAGAS 평가는 각각 한국어 변환 평가 문맥과 영어 검색 문맥을 사용하는 프로토콜별 결과로 해석하였다. SCD의 출력 언어 변화는 한국어 문자 비율의 대응 차이로 분석하였다.
6. 결론
한국어 질의–영어 문서 RAG에서 HyDE·CAD·SCD를 적용하고, 네 문서의 60개 질의에 대한 480개 생성 기록을 비교하였다. 다음 절에서는 연구 질문에 대한 답, 비교 설계의 의의, 적용 시 고려사항과 후속 연구를 정리한다.
6.1 연구 질문별 최종 답
첫 번째 연구 질문에서 HyDE의 답변 관련성 평균 대응 차이는 +0.0805, 95% 부트스트랩 신뢰구간은 [+0.0110, +0.1514]였다. 근거 충실도는 +0.0436, 문맥 정밀도는 -0.0343, 문맥 재현율은 0.0000이었다.
두 번째 연구 질문에서 CAD의 동일 문맥 근거 충실도 평균 대응 차이는 58개 유효쌍에서 +0.0288, 95% 신뢰구간은 [-0.0367, +0.0934]였다. 답변 관련성은 60쌍에서 -0.0073이었고 신뢰구간은 0을 포함하였다. CAD ON 조건의 평균 생성 시간은 대응 조건군에서 모두 증가하였다. 동일 문맥의 답변 품질에서는 증가와 감소가 함께 나타났으며 계산 비용도 늘었다.
세 번째 연구 질문에서 SCD의 한국어 문자 비율 평균 대응 차이는 HyDE OFF 동일 문맥 120개 대응쌍에서 +0.2182, 전체 240개 상태 일치 대응쌍에서 +0.2289였다. 이 결과는 SCD 적용 후 영어 검색 문맥을 사용하는 조건에서 생성 답변의 한국어 문자 비율이 높아졌음을 보여준다.
네 번째 연구 질문에서는 적용 목적별로 목표 지표와 요인별 대응 결과를 함께 검토하였다. HyDE의 답변 관련성 증가, CAD의 질의별 품질 차이와 생성 시간 증가, SCD의 한국어 문자 비율 증가를 분석하였다. 이 결과를 바탕으로 적용 목적별 실험 조건 선택 절차를 6.3절에 제안하였다.
6.2 비교 설계의 의의
이 비교 설계에서는 각 기법이 개입하는 위치에 따라 대응쌍을 구성하였다. 검색 입력을 바꾸는 HyDE는 검색 결과의 변화까지 포함하였고, CAD는 검색·재정렬 청크 ID와 최종 문맥이 같은 쌍에서 비교하였다. SCD는 HyDE OFF 동일 문맥 120쌍을 주 비교로 삼았으며, 전체 240개 상태 일치 대응쌍으로 조합 전반의 출력 언어 변화를 요약하였다. 이렇게 비교 조건을 구분하여 검색 문맥의 변화와 디코딩의 변화를 함께 해석할 수 있었다.
조합별 평균은 해당 설정의 전체 성능을, 요인별 대응 차이는 기법 적용 전후의 변화를 나타낸다. H1C1S0의 근거 충실도 평균 0.8599는 해당 조합의 결과이고, CAD의 +0.0288은 동일 문맥의 ON/OFF 대응 차이이다. 요인별 대응 결과를 함께 제시하여 두 해석을 구별하였다.
생성 기록에 질의, 검색·재정렬 청크 ID, 최종 문맥, 답변, 디코딩 메타데이터와 시간을 함께 저장한 점도 비교의 재현에 필요하다. 그림 5-3, 5-5, 5-7, 5-8, 5-10은 같은 기록에서 가져온 입력·출력과 평가값을 연결한다. 부록 B의 그림 B-1은 CAD의 근거 충실도가 감소한 사례이다. 이 자료들은 집계값과 개별 대응쌍의 입력 동일성 및 답변 차이를 제시한다.
6.3 적용 시 실험 조건 선택
적용 목적에 따라 목표 지표를 정하고 요인별 대응 결과를 함께 검토하는 절차를 제안한다. 답변 관련성이 목표이면 HyDE의 검색 결과 변화와 답변 관련성 대응 결과를 함께 검토한다. 같은 근거에서의 답변 품질이 목표이면 CAD의 질의별 품질 분포와 생성 시간을 함께 검토한다. 한국어 출력 유지가 목표이면 SCD의 동일 문맥 대응 결과를 검토한다. 고유명사·인용·전문용어의 보존은 별도 평가 항목으로 제안한다.
6.4 후속 연구 방향
후속 연구는 평가 상황의 확장과 기법별 처리 과정의 분리, 사람 평가를 중심으로 진행할 수 있다. 답변 불가능 질의, 오문서 지정 질의와 무근거 입력을 추가하여 근거 부족 상황에서의 응답을 분석한다. 문서 도메인과 생성 모델·토크나이저를 확대하여 결과의 재현 범위를 평가한다.
HyDE는 번역, 가상 문서 생성과 밀집 검색 변경을 분리하여 비교하고, 동일 질의를 반복 샘플링하여 결과의 변동을 측정한다. CAD는 α와 문맥 길이를 달리하여 답변 품질과 생성 시간의 관계를 측정하고, 질문 복잡도와 정보 통합 요구에 따른 질의별 변화 분포를 분석한다. SCD는 사람 블라인드 평가로 자연스러움, 번역 충실도, 내용 정확성과 전문용어 보존을 각각 측정한다. 다국어 재정렬 모델과 현재 CrossEncoder를 비교하여 검색 구성에 따른 차이를 확인한다.
