# 웹한글 최종 확인

2026-10-08에 한컴독스 로그인 계정에서 실제 업로드·열기·문단 편집·표 셀 편집·저장·재열기·다운로드·PDF 내보내기를 수행했다. 구조 검사와 브라우저 검증은 구분한다. 상세 근거는 `HWPX_BUILD_QA_REPORT.md`, `HWPX_STRUCTURAL_QA.json`, `LOGS/`에 있다.

| 대상 | 실제 확인 결과 |
|---|---|
| 최종 HWPX 업로드·웹한글 열기 | 완료, 편집 메뉴와 문서 편집 영역 활성 |
| 문단 및 표 셀 수정 | 시험본에서 입력 확인; 표 수정은 실행 취소, 문단 수정은 저장·재열기·다운로드로 확인 |
| 그림·수식 표시 | 시험본과 최종 PDF에서 확인; 22개 그림·10개 수식의 원본 대조 완료 |
| 편집 후 저장 및 재열기 | 시험본 `HWPX_SMOKE_WEB_ROUNDTRIP.hwpx`에 수정 문자열 보존, XML 유효 |
| 최종 PDF 내보내기 | 한컴독스 웹한글 출력 57쪽, 모든 쪽 검토 |
| 목차·그림목차·표목차 | 실제 출력 쪽번호 반영, 최종 5~8쪽 육안 확인 |
| 부록 A | 46~52쪽, 60개 질의 보존, 머리글 반복, 셀 단위로 쪽 연결 |

사용자의 최종 입력과 편집 절차:

1. `GRADUATION_REPORT_60Q_FINAL.hwpx`를 한컴독스의 **문서 업로드**로 올리고 파일명을 눌러 웹한글에서 연다. GitHub에서는 해당 파일의 **Download raw file**로 내려받는다.
2. 1~2쪽의 `[학생명 입력]`, `[학번 입력]`, `[지도교수 입력]`, `[제출일 입력]` 등 실제 입력 위치를 검색하여 본인 정보와 학교 제출일로 바꾼다. 확인되지 않은 정보는 제작 시 입력하지 않았다.
3. 본문과 표는 직접 편집한다. 그림은 원본 PNG 개체이므로 도형 안의 글자를 문단처럼 편집하는 대신 원본 그림을 수정하여 교체한다. 큰 입출력 사례는 확대하여 읽는다.
4. 수식은 네이티브 한글 수식 개체다. 동일 문서를 여러 탭에서 동시에 열면 웹한글이 협업 모드에서 수식 기능을 제한할 수 있다. 중복 탭을 닫고 문서를 다시 열어 확인한다. 모든 수식의 편집 대화상자 동작을 시험한 것은 아니다.
5. 쪽번호는 바닥글 자동 쪽번호다. 목차·그림목차·표목차의 오른쪽 번호는 검토한 실제 쪽을 입력한 텍스트이므로, 내용·서식 변경으로 쪽이 이동하면 PDF를 다시 내보내어 해당 번호를 직접 수정한다. 목차는 5~6쪽, 그림목차는 7쪽, 표목차는 8쪽에 있다. 빌드로 갱신하려면 `BUILD/README.md`의 새 페이지 지도 절차를 따른다.
6. **파일 → 저장하기** 후 다시 열고 **파일 → PDF로 다운로드**로 제출용 PDF를 만든다. 표 행이 쪽 사이에서 이어질 때 질문과 근거가 모두 남아 있는지, 머리글이 반복되는지 확인한다.
