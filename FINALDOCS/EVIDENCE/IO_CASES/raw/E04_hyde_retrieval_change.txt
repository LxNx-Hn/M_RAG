구체적으로 BIC는 다음과 같은 목적으로 활용됩니다:

3. **수식적 정의**: 논문에서 제시된 BIC 공식은 다음과 같습니다:

In RAPTOR's clustering process, the Bayesian Information Criterion (BIC) is employed to determine the optimal number of clusters by evaluating model fit while penalizing complexity. Specifically, BIC is calculated for each candidate cluster solution, providing a quantitative measure that balances goodness-of-fit against the number of parameters required. This criterion helps in selecting the model with the lowest BIC value, which indicates the most parsimonious explanation of the data. For instance, in a dataset analyzed using RAPTOR, the BIC values for models with 2, 3, and 4 clusters might be -1500, -1450, and -1420, respectively, leading to the selection of the 4-cluster solution as the best fit based on the lowest BIC score.
