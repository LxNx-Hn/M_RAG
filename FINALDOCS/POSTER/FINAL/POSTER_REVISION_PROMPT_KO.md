# 포스터 수정 지시

최신 논문의 질문 유형별 분석을 사용하여 A1 세로 594×841 mm 한 장을 수정한다. 네 문서·60문항·480개 생성 기록과 원래 평가값을 유지한다. 방법·절차의 HyDE 답변 관련성, SCD 추가 후 문자 비율, CAD 단독 처리 시간과 실제 질문의 요구 정보·출력 내용을 연결한다.

수치 결과는 표로, 질문별 점수는 평행좌표로 제시한다. 평행좌표는 한 열에 두 패널을 두고 각 패널에 60개 질문의 원점수를 모두 표시한다. 나머지 성능 그래프, 중앙값이나 새로운 검정, 조건 전체의 종합 순위는 추가하지 않는다. 네 질문 유형을 그대로 유지한다.

비교 제목에는 기준 조건·적용 조건·측정 지표·평가 근거 언어를 쓴다. 질문은 내용을 제목으로 표현한다. ID·실험 코드·청크 해시는 포스터에 넣지 않는다. 같은 평가 언어 안의 품질 비교를 유지하고 처리 시간은 단일 기법 비교만 제시한다. 숫자는 두 자리, 오른쪽 정렬, 흰 표 배경을 사용한다. 같은 비교의 적용 평균 최댓값만 굵게 하고 동률을 모두 표시한다.

결과 설명은 관측된 점수와 실제 답변의 내용을 직접 쓴다. 자동 점수가 오른 질문에서도 어떤 정보와 다른 내용이 출력되었는지 실제 발췌로 설명한다. 방어적 부정문이나 불명확한 A 대 B·Delta 표기는 쓰지 않는다.

PPTX에는 편집 가능한 표·차트·텍스트·도형을 유지하고 SVG와 PDF에도 같은 문구·수치를 반영한다. 원자료 대조, 최대값과 정렬, 120개 질문 선, A1 크기·텍스트 보존·잘림을 검토한 뒤 파일을 제공한다.
