# A1 포스터 최종 수정 반영 기준

01~08 구성을 유지한다. 초록은 선택사항이며, 현재 04 평가 사례와 05 결과표의 공간을 확보하는 구성으로 독립 초록을 두지 않았다.

01은 HyDE의 한국어 포함 다국어 평가와 본 연구의 교차언어 조합 비교를 설명한다. 02는 원질의·구간 쌍 CrossEncoder[M2]와 생성 모델[M1]의 실제 출처를 구분한다. 03은 동일 질의 60개×8조건의 반복측정 구조다. 04의 영어 검색 근거는 저장 문맥의 완결 문장이며 PDF 9쪽, 참조 답변 근거는 PDF 20쪽이다. 생성 답변·평가값은 저장 기록을 유지한다. 05는 S0/S1·평균(SD)·ANOVA·대응검정·Holm을 보존한다. 06·07은 연구 질문별 의미와 목표 언어·품질·시간의 적용 기준을 제시한다. 08은 정식 학술문헌과 공식 모델 출처를 구분한다.

전체 학술 22편과 모델·자료 출처는 ../../VALIDATION/REFERENCES.md를 따른다. SCD의 개념 출처는 AAAI 공식 출판본 https://ojs.aaai.org/index.php/AAAI/article/view/40417 이다. CEDR는 문맥화된 순위화의 학술 배경이며 실제 구현은 MiniLM CrossEncoder다.
