ZIP에는 구조도와 RAG-Cube의 SVG/PDF, 평가 및 결과 PDF, 원문 사본, 실제 입출력 증거, 원문 참고문헌22개, 확대 검수 이미지와 제작 기록이 포함됨
매니페스트의 상대 경로는 ZIP 내부 기준이며, 압축을 푼 뒤 검증에 사용
ZIP의 제작 스크립트는 당시 Windows 제작 환경과 기존 B1 자산을 사용하는 기록용 원본
이 폴더에서 그대로 재실행할 수 있는 독립 빌드 도구라고 주장하지 않음

PDF와 PPTX의 표본, 평균, 신뢰구간과 원문22개 참고문헌을 확인한 검수 결과는 VALIDATION에 보관
인쇄는 글꼴 포함 PDF, 편집은 PPTX 사용
PowerPoint 직접 실행과 실제 인쇄 검수는 미수행
맑은 고딕이 없는 편집 환경은 글꼴 대체 가능

이전 GitHub 릴리스 첨부 파일과 원래 제작 폴더는 유지하고, 검수 완료본을 FINALDOCS에 추가
논문 본문, 실험 데이터와 기존 제출 파일은 이 게시 작업에서 수정하지 않음
