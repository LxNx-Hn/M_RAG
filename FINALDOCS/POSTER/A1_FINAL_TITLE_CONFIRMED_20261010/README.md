# M-RAG A1 연구 포스터 · 최종 문체·정렬 교정

확정 제목: **한국어 질의로 영어 학술·기술 문서를 검색하는 RAG에서의 HyDE·CAD·SCD 조합 실험**

60개 질의와 480개 생성 기록을 기준으로 평균(SD), 반복측정 ANOVA, 대응 비교와 Holm 보정을 반영했다. 공개본은 문종건·지도교수 김진석을 표기하고 학번을 생략한다. 학번을 포함한 제출본은 로컬에 별도로 보관한다.

2026-10-16 교정에서는 01·04·06·07의 주어·지표 설명·통계 해석을 다듬었다. 숫자 셀 88개는 오른쪽, 조건 코드는 가운데, 설명은 왼쪽으로 정렬했다. 4개 표의 159개 셀을 PPTX XML과 SVG에서 각각 검사했다. 표시 문구 204단위와 모든 수치를 PDF까지 대조했다.
