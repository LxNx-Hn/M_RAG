# 포스터 수정용 프롬프트

현재 최종 편집용 PPTX 또는 SVG를 기준으로 교정한다. 확정 제목과 기존 A1 세로 레이아웃, 색상, 글꼴, 좌표, 표와 차트를 유지한다. 실제 변경문은 ACADEMIC_POLISH_CHANGES.json의 C이며, 누적 교정문은 A1_COPYEDIT_MAP.json의 new이다. 두 기록을 현재 화면의 문장과 대조한다.

기술 설명은 실제 처리 순서대로 작성한다. HyDE는 한국어 질의 번역과 가상 문서 생성 후 BGE-M3 밀집 검색에 적용하며 BM25와 CrossEncoder는 한국어 원질의를 사용한다. CAD ON에서는 같은 모델의 문맥 포함 로짓과 제외 로짓을 (1+α)z_ctx−αz_noctx로 결합하며 α=0.5이다. SCD ON에서는 한국어와 다른 언어 토큰의 로짓에 각각 1.1과 0.9를 곱하며 중립 토큰과 첫 5개 생성 토큰은 유지한다. 재정렬 상위 5개 청크를 선택한 후 조건부 문맥 길이 관리를 수행한다.

60개 평가 질의, 8개 조건과 480개 생성 기록을 유지한다. 평가 질의 구성의 초기 질문 3개는 표현 방식과 범위의 기준이며 튜닝 질의 5개는 최종 평가 집합과 분리했다. SCD의 문맥 번역은 RAGAS 평가 단계의 처리이며 생성 입력은 영어 문맥이다. 주 비교 120쌍과 전체 상태 일치 비교 240쌍을 구분한다.

HyDE +0.0805, CAD +0.0288, SCD 주 비교 +0.2182와 전체 비교 +0.2289, 모든 신뢰구간 및 그래프의 원데이터를 유지한다. CAD의 유효 근거 충실도 대응쌍은 58쌍이다. 20.792초와 63.867초는 H0S0에서 CAD OFF와 ON의 조건 실행 시간이며 검색부터 답변 생성까지의 범위이다. 원자료의 질문과 답변, 인용 및 참고문헌을 그대로 보존한다.

조사, 수식 범위와 주어·서술어의 호응을 앞뒤 문장과 함께 검토한다. 수행 내용과 측정 결과를 직접 서술하고 중복 설명을 정리한다. 통계적 불확실성과 음수 결과는 보존한다. 수정 후 SVG, PPTX와 실제 인쇄 PDF에서 최종 문장이 일치하는지 확인하고 전체 페이지에서 잘림, 겹침, 차트 범례와 표의 가독성을 검토한다.
