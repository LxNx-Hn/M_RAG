이전 대상: 졸업논문_한글이전용.txt

원본 HWP 양식의 스타일과 문단·글꼴 설정을 그대로 사용한다. TXT는 내용을 옮기기 위한 원고이며 HWP의 시각적 서식을 재현한 파일이 아니다.

본문 장 순서는 양식에 맞춰 1. 서론 / 2. 이론적 배경 / 3. 시스템 설계 / 4. 프로그램 구현 / 5. 실험 / 6. 결론으로 작성했다.
3.1 요구사항 / 3.2 아키텍처 설계 / 3.3 상세설계, 4.1 시스템 환경 / 4.2 시스템 구성 / 4.3 시스템 구현을 유지했다.
설계·구현 대상은 웹 앱이 아니라 기법 적용 실험 프로그램이다. 소스코드 본문 복사는 포함하지 않았다.

1. 원본 HWP의 사본을 열어 표지와 인준 영역은 유지한다. 이름·지도교수·날짜는 사용자 정보로 입력한다. 예시의 2025를 실제 제출 연도로 확인한다.
2. 제목은 논문제목, 본문은 본문, 장은 장(1.), 절은 절(1.1) 스타일로 적용한다.
3. 표의 텍스트를 실제 표로 옮기고 표 제목은 위쪽에 표제목, 셀은 표내용 스타일을 적용한다. Markdown 표 구분선은 본문 내용이 아니다.
4. 이 안내 파일 옆 figures 폴더에 그림이 있다. 그림 1-1은 application_overview_simple, 그림 3-1은 usecases, 그림 3-2는 architecture, 그림 3-3은 modules, 그림 3-4는 sequence를 사용한다. 각 그림의 SVG와 같은 이름의 PNG를 함께 제공한다. HWP에서 SVG 삽입이 어려우면 PNG를 사용한다. 그림 5-1은 execution_evidence.png이다. 그림 제목은 아래쪽에 그림제목 스타일을 적용한다.
5. 목차에는 차례리스트(장)·차례리스트(절), 표·그림 목록에는 표/그림리스트, 참고문헌에는 참고문헌제목·참고문헌리스트 스타일을 적용한다. 목차·표 목록·그림 목록의 페이지 번호는 최종 배치 후 갱신한다.
6. 표지·인준의 개인정보와 실제 제출 연도는 사용자 정보로 입력한다.
7. 참고문헌은 본문 첫 인용 순서로 정리했다. 일본어 논문 JHARS는 RAG의 잔여 환각 문제를 뒷받침하는 용도다.

원고는 최종 실험에서 사용한 구성과 결과만 서술한다. 실험 과정의 이전 설정이나 중간 산출물은 포함하지 않는다.

최종 확인이 필요한 사실
- 질문 19개의 최초 작성자와 최초 생성·사람 검토 절차는 저장소의 정리 이력만으로 완전히 확인되지 않았다. 현재 원고는 확인된 분리·정리 과정까지만 기술했다.
- 참고문헌과 지표는 기존 원고 및 보존 결과에 근거한다. 새 생성·채점 실험은 수행하지 않았다.
- 표지 정보 입력과 실제 HWP 이전 이후의 페이지·표·그림 배치는 최종 제출 전 확인해야 한다.
- 양식에서 요구한 1.1절의 1쪽 분량은 HWP의 본문 스타일을 적용한 뒤 확인한다. 원본 스타일을 바꾸어 분량을 맞추지 않는다.
- 발표 자료는 제공된 PDF 예시의 흰 바탕·장 순서·4:3 화면 비율을 참고하여 14장으로 구성했다. PDF 안의 ZigBee 발표 내용은 서식 예시이며 본 연구의 참고문헌이 아니다.
