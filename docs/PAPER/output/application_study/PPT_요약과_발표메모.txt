1. 한국어 질의 기반 영어 학술논문 RAG에서

HyDE, CAD, SCD의 적용 효과 분석
Application Effects of HyDE, CAD, and SCD
in RAG over English Academic Papers with Korean Queries

발표 메모: 기존 기법을 한국어 질문과 영어 학술논문의 조합에 적용한 비교 실험이다. 문서 4편에 대한 질문 19개를 사용하였다.

2. 목차

1. 서론 · 연구 목적과 범위
2. 이론적 배경 · 선행연구
3. 시스템 설계 / 4. 프로그램 구현
5. 실험 · 평가와 결과 / 6. 결론

발표 메모: 논문과 같은 장 순서로 발표한다.

3. 1. 서론

LLM은 근거에 없는 내용을 생성할 수 있다
RAG는 외부 근거를 제공하지만 생성 오류가 남는다
영어 논문을 한국어로 묻는 상황에서는 언어 차이도 고려해야 한다

발표 메모: RAG: Lewis et al., NeurIPS 2020. JHARS: https://www.anlp.jp/proceedings/annual_meeting/2025/pdf_dir/Q2-17.pdf. 언어 차이 자체의 검색 손실은 이번 실험에서 직접 측정하지 않았다.

4. 연구 목적과 범위

논문 근거에 충실한 한국어 답변을 얻고자 한다
선택된 영어 논문 안에서 질문에 맞는 문단을 검색한다
기존 기법의 적용 여부에 따른 변화를 비교한다

발표 메모: 대상 논문은 질문에 지정되어 있다. 모든 논문 중 관련 논문을 찾는 평가가 아니다. 웹 앱이나 사용자 독해 향상도 평가하지 않았다.

5. 2. 이론적 배경

HyDE · Gao 등 2023  |  가상 문서로 검색 표현 구성
CAD · Shi 등 2024  |  문맥 유무의 생성 점수 대조
SCD · Li 등  |  목표 언어에 따라 생성 점수 조정

발표 메모: HyDE https://aclanthology.org/2023.acl-long.99/ ; CAD https://aclanthology.org/2024.naacl-short.69/ ; SCD https://arxiv.org/abs/2511.09984 . 세 기법 모두 선행연구가 제안했다. 본 연구는 적용과 비교를 수행한다.

6. 3. 시스템 설계

한국어 질문     →     검색     →     LLM     →     답변
영어 논문             HyDE         CAD · SCD        목표 한국어
실제 검색 근거를 저장하여 조건 간 문맥을 확인한다

발표 메모: HyDE는 검색 전에 적용한다. CAD와 SCD는 생성이 끝난 후가 아니라 다음 토큰을 선택하기 전에 적용한다. 도식은 적용 위치를 나타내며 항상 세 기법을 모두 켠다는 뜻은 아니다.

7. 4. 프로그램 구현

BGE-M3 · BM25 · 가중 RRF · CrossEncoder
Mi:dm 2.0 Base · 최종 답변 greedy · 최대 512 tokens
HyDE 가상 문서: sampling · temperature 0.1 · top_p 0.9
후보 8개 · 재정렬 8개 · 문맥 5개 · 압축 후 생성

발표 메모: 실험 코드: experiments/runners/main_generation_executor.py. CAD fixed alpha=0.5. SCD reference_scd alpha=1.1 beta=0.9 Tstart=5. 재정렬 점수순 정렬 뒤 위치 재배치를 거친 배열에서 문단을 선택한다.

8. 5. 실험

HyDE × CAD × SCD의 적용 여부로 여덟 조건 구성
영어 논문 4편 · 한국어 질문 19개 · 답변 152개
서로 다른 질문은 19개이며 조건별로 답변을 생성한다
CAD와 SCD의 품질 비교는 동일 문맥 조건을 사용한다

발표 메모: CAD 품질 비교: HyDE-off, SCD-off 19쌍. SCD 대칭 품질 비교: HyDE-off 38쌍. HyDE-on에서는 가상 문서가 조건별로 다시 생성되어 모든 문맥이 동일하지 않다.

9. 평가 방법

내용  |  근거 충실도 · 질문 관련성 · 문맥 지표
언어  |  한글 수 ÷ (한글 수 + 영문 알파벳 수)
언어 이탈  |  한국어 문자 비율 0.5 미만
질문별 대응 차이와 95% 신뢰구간으로 결과를 해석한다

발표 메모: RAGAS 0.2.15. HyDE/CAD: gpt-4o 점수의 SCD-off 행, 19질문 paired bootstrap 200000회. SCD 품질: 영어/한국어 대칭 패널, 두 judge, 19질문 cluster bootstrap 10000회. 한국어 비율은 자연스러움이나 의미 보존 지표가 아니다.

10. HyDE와 CAD의 품질 결과

HyDE 질문 관련성  +0.0303
95% 신뢰구간  [+0.0016, +0.0615]
CAD 근거 충실도  +0.0023
95% 신뢰구간  [−0.0903, +0.0952]

발표 메모: 출처: docs/PAPER/THESIS_KO.md 표 2 및 verify_current_thesis_results.py. 각 19쌍. HyDE의 다른 품질 지표는 개선이 확인되지 않았다. CAD는 품질 개선을 확인하지 못했다.

11. SCD의 한국어 출력 결과

한국어 문자 비율의 평균 차이  +0.2203
언어 이탈 출력  26/76 → 12/76
76쌍 중 68쌍에서 비율이 0.02보다 크게 증가
동일 문맥 38쌍에서도 평균 차이 +0.2198

발표 메모: 출처: experiments/results/analysis/reference_scd_language_adherence.json. 3쌍 감소, 5쌍 동률. 기준 미만 26개 중 15개 회복, 반대 방향 1개. 모든 언어 이탈을 해결한 것은 아니다.

12. 내용 품질과 한계

SCD의 품질 변화는 두 평가 모델에서 일관되지 않았다
번역만 적용한 검색과의 비교와 사람 평가는 없다
SCD 품질 평가는 생성 후 번역과 평가 모델의 영향을 받는다
RAG 논문 질문 40건은 BM25 후보 없이 검색되었다

발표 메모: 출처: experiments/reports/reference_scd_symmetric_cross_judge_report.md 및 최종 생성 JSONL. Faithfulness 모든 구간 0 포함. Answer relevancy는 gpt-4o에서만 0 제외. 두 평가 모델은 같은 제공자이며 정규화 번역은 gpt-4o를 사용했다. 한국어 답변 번역은 SCD-off 23/38, on 11/38. BM25 후보 0건은 5질문×8조건=40건이며 나머지 112건의 BM25 후보는 8개였다.

13. 6. 결론

영어 학술논문에 대한 한국어 질의응답에 기존 기법을 적용했다
HyDE의 질문 관련성은 소폭 높아졌고 CAD 개선은 확인되지 않았다
SCD의 한국어 출력 비율이 높아졌지만 내용 품질은 불확실했다
더 다양한 질문과 번역 대조, 사람 평가가 후속 과제로 남는다

발표 메모: 본 연구의 기여는 해당 응용 조건에서 기존 기법의 효과와 한계를 비교한 데 있다. 19개 질문의 결과이므로 일반적인 우수성으로 확대하지 않는다.
