가제: 한국어 사용자의 영어 학술논문 질의응답을 위한 RAG 응용 시스템 구현과 기존 기법의 적용 효과 분석

서론 수정안

대규모 언어 모델(LLM)은 질문에 자연스러운 답변을 생성하지만, 사실과 다르거나 근거가 없는 내용을 제시하기도 한다. 특정 논문의 내용을 묻는 상황에서 이러한 답변이 나오면 사용자는 논문에 없는 설명을 실제 연구 내용으로 받아들일 수 있다. 검색 증강 생성(RAG)은 질문과 관련된 문서를 검색하여 답변 생성에 활용하는 접근이다[1]. 논문 질의응답에 이를 적용하면 해당 논문의 내용을 모델에 제공할 수 있다. 그러나 문서를 제공하더라도 모델이 그 내용을 충분히 반영하지 않을 수 있으므로, 필요한 근거의 검색과 생성 과정에서의 근거 활용을 함께 살펴볼 필요가 있다[3].

본 연구의 응용 분야는 한국어 사용자의 영어 학술논문 질의응답이다. 사용자는 논문의 방법이나 결과에 대해 한국어로 질문하고, 해당 논문의 근거를 바탕으로 설명을 얻고자 한다. 이 환경에서는 RAG의 근거 활용 문제에 더해 질문과 자료의 언어 차이를 고려해야 한다. 한국어 질문과 영어 문단의 표현이 충분히 연결되지 않으면 필요한 근거가 검색에서 누락될 수 있다. 관련 근거를 찾더라도 영어 문맥의 영향을 받아 답변이 다른 언어로 이어지는 언어 이탈이 발생할 수 있다[4]. 따라서 이 응용에서는 관련 근거를 찾는 것, 근거에 충실하게 답하는 것, 한국어로 설명하는 것이 함께 요구된다.

이러한 문제와 관련하여 선행연구에서는 가상 문서를 이용한 검색 기법인 HyDE[2], 문맥의 반영을 유도하는 생성 기법인 CAD[3], 목표 언어의 출력을 유도하는 SCD[4]가 제안되었다. 본 연구는 이들 기존 기법을 영어 학술논문에 대한 한국어 질의응답 시스템 M-RAG에 적용한다. 연구의 목적은 이 응용 환경에서 각 기법을 적용했을 때 어떤 변화가 나타나는지 확인하는 것이다. 이를 위해 검색·생성 기반을 고정하고 세 기법의 적용 여부에 따른 여덟 가지 조건을 비교하여, 답변의 근거 충실도와 질문 관련성, 한국어 출력의 변화를 분석한다.

선행연구와 본 연구의 적용 과제

검색에 필요한 표현의 확보

Gao 등은 관련성 정답 자료 없이 문서를 검색하는 문제를 다루기 위해 HyDE를 제안하였다[2]. HyDE는 질문으로부터 가상 문서를 생성하고, 그 문서의 임베딩을 이용하여 실제 문서를 검색한다. 생성한 가상 문서는 검색을 위한 표현으로 사용되며, 답변을 뒷받침하는 실제 자료와는 구분된다. 본 연구에서는 이 접근을 한국어 질문에 대응하는 영어 논문 근거를 찾는 과정에 적용한다. 원 연구의 검색 성과가 본 연구의 언어 조합과 학술논문에서도 유지되는지는 적용 실험을 통해 확인해야 한다. 또한 검색 결과의 변화가 최종 답변에 어떤 영향을 주는지 함께 살펴본다.

검색 근거를 반영한 답변 생성

Shi 등은 모델이 주어진 문맥보다 기존에 학습한 지식에 의존하여 문맥에 충실하지 않은 답변을 생성하는 문제를 다루었다[3]. 이들이 제안한 CAD는 같은 모델에 문맥을 제공했을 때와 제공하지 않았을 때의 다음 토큰 점수를 대조한다. 이 방법은 교차언어 환경에 한정되지 않으며, 본 연구에서도 논문 근거를 답변에 반영하기 위한 목적으로 적용한다. 다만 문서 내용의 반영을 유도하는 것과 한국어 출력을 유지하는 것은 서로 다른 목표이므로, CAD의 효과만으로 출력 언어 문제까지 해결된다고 볼 수는 없다.

다국어 문맥에서의 출력 언어 유지

Li 등은 다국어 RAG에서 답변이 의도한 언어를 벗어나는 현상을 분석하고 SCD를 제안하였다[4]. SCD는 생성 과정에서 토큰의 언어 구분에 따라 점수를 조정하는 방법이다. 본 연구는 이를 한국어가 목표 언어이고 영어 논문이 근거로 주어지는 조건에 적용한다. 한국어 출력이 늘어나는 것과 논문 내용에 충실한 답변이 생성되는 것은 구분하여 평가한다. 원 연구의 언어 제어 결과를 본 연구의 답변 품질 향상으로 곧바로 해석하지 않고, 한국어 출력과 내용 품질의 변화를 각각 확인한다.

언어별 RAG 적용과 평가

矢野 등은 일본어 문장 임베딩의 문서 검색 성능을 비교하고, 이를 RAG에 적용했을 때의 답변 성능을 평가하였다[5]. 이 연구에서는 검색에 성공해도 오답이 발생했으며, 검색 성능의 변화와 답변 성능의 변화가 항상 같은 방향으로 나타나지는 않았다. 이는 검색 모듈의 성능과 최종 답변의 성능을 함께 확인할 필요성을 보여준다. 본 연구도 이러한 평가 관점에서 검색과 생성의 결과를 구분하여 살펴본다. 다만 해당 연구는 일본어 문서를 대상으로 한 연구이므로, 한국어 질문과 영어 논문 사이의 검색 문제를 직접 입증하는 근거로 사용하지 않는다.

본 연구에서 확인하려는 문제

이상의 연구는 본 연구의 응용에서 활용할 수 있는 검색과 생성 기법, 그리고 평가 관점을 제공한다. 본 연구에서 확인할 것은 이들 기법이 한국어 사용자의 영어 학술논문 질의응답에서 어떤 효과를 보이는가이다. 검색을 바꾸었을 때 질문에 더 적절한 답변이 나오는지, 문맥 반영을 유도했을 때 논문 근거에 더 충실해지는지, 한국어 출력을 유도했을 때 내용 품질에도 변화가 생기는지를 살펴본다. 이를 위해 기존 기법을 하나의 시스템에 적용하고, 적용 여부에 따른 차이를 비교한다. 이 연구의 기여는 대상 응용에 맞춘 시스템 구현과 적용 효과의 분석에 있다.

그림 1. 영어 학술논문 질의응답에서 기존 기법의 적용 위치

한국어 질문 ──> HyDE: 가상 문서 생성 ──> 검색 ──> 실제 영어 근거 문단
                                             ↑
                                       영어 논문 집합

한국어 질문 + 실제 영어 근거 문단
                    ↓
       LLM: 다음 토큰 점수 계산 <──────────────────┐
                    ↓                            │
 CAD: 근거가 있는 점수와 없는 점수 대조           │
                    ↓                            │
 SCD: 목표 언어에 따른 토큰 점수 조정             │
                    ↓                            │
             다음 토큰 선택 ── 생성 중이면 반복 ──┘
                    ↓ 종료 시
          최종 답변 (목표 언어: 한국어)

그림 설명: HyDE[2]는 답변 생성에 앞선 검색 과정에 적용하고, CAD[3]와 SCD[4]는 답변을 생성하는 동안 매 단계의 토큰 점수 계산에 적용한다. CAD의 무문맥 계산에는 같은 질문과 같은 생성 이력을 사용하되 검색 근거를 제외한다. 본 구현에서 두 생성 기법을 함께 적용할 때는 CAD 다음에 SCD를 적용한다. HyDE를 끄면 질문으로 검색하고, CAD 또는 SCD를 끄면 해당 점수 조정을 건너뛴다. 화살표는 적용 위치를 나타내며, 세 기법의 동시 적용이나 한국어 정답의 생성을 보장한다는 의미는 아니다. 도식은 본 시스템의 흐름을 정리하여 작성한 것으로, 개별 기법의 출처는 각각 [2]–[4]이다.

교정 메모 (논문 본문에 포함하지 않음)

이 초안은 기존 기법의 출처와 응용 연구의 범위를 분명히 하기 위한 것이다. '최초의 조합', '기존 연구가 전혀 다루지 않았다'는 우선권 주장은 하지 않았다. 언어 차이로 인한 검색 성능 저하의 크기는 이 초안에서 확인된 실험 결과로 주장하지 않는다. 기존 결과의 표본은 4개 영어 논문과 19개 질문이므로 일반적인 학술논문 전체나 실제 사용자의 독해 향상으로 확대 해석할 수 없다. 사용자 연구를 통한 편의성이나 독해 효과는 별도 검증이 필요하다. SCD는 이번에 확인한 arXiv 원문 기준으로 표기하였으며 제출본에서는 학회 출판본의 서지와 내용을 대조해 통일한다. 참고문헌 번호는 전체 원고 통합 시 다시 매긴다.
