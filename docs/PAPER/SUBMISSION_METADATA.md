# 논문 제출 메타데이터 체크리스트

국·영문 본문은 저장소 근거로 작성했지만 다음 정보는 저장소에서 확인할 수 없어 임의 입력하지 않았다. 학교 또는 학회 템플릿을 적용하기 전에 제출자가 확정해야 한다.

- 저자 국문명 / 영문명
- 학번
- 대학 / 대학원 / 학과 / 전공
- 학위 종류
- 지도교수 국문명 / 영문명
- 제출 연월 및 심사 연월
- 국문·영문 논문 제목의 학교 승인 표기
- 학교 로고와 표지 양식
- 심사위원 서명·인준 페이지 요구 여부
- 연구윤리·AI 도구 사용 고지 문구
- 개인정보·연락처 공개 범위
- 페이지 크기, 여백, 글꼴, 줄간격, 참고문헌 스타일

## 현재 생성 가능한 중립 산출물

- `THESIS.md`: 영문 전체 원고
- `THESIS_KO.md`: 국문 전체 원고
- `output/M_RAG_THESIS_EN.docx` 및 PDF: 일반 학술 원고 형식
- `output/M_RAG_THESIS_KO.docx` 및 PDF: 일반 학술 원고 형식

학교 고유 표지는 위 정보를 받은 뒤 최종 적용한다. 본문 결과를 바꾸지 않고 표지·인준·서식만 교체해야 한다.
